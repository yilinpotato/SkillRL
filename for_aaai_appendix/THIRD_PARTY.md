# Third-Party Components

The artifact includes adapted components from the following projects:

- VERL, Apache License 2.0.
- ALFWorld, MIT License.
- WebShop, MIT License.

License headers are retained in adapted source files. The WebShop license is
distributed beside its environment code. ALFWorld is installed as an external
dependency and its benchmark files are downloaded separately. Model weights
and benchmark data are not distributed in this repository.

The default model is `Qwen/Qwen3-4B-Thinking-2507`. Users are responsible for
reviewing the model and benchmark terms before redistribution.

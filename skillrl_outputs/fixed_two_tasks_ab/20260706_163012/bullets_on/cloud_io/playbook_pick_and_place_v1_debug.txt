# Goal
Put the specified object into the specified container (e.g., "put a alarmclock in desk").

# Situation Assessment
- Read the task to identify the **target object** and **target container**.
- Look at the current room description to see what is present.

# Action Sequence
## 1. Find and take the target object
- If the target object is visible in your current location, **take** it.
- If not, **go to** another furniture item (e.g., sidetable, drawer, shelf) and check. Open closed containers (drawers, cabinets) to look inside.
- Once you see the target object, **take [object]** (e.g., "take alarmclock 1 from sidetable 1").

## 2. Move to the target container
- After you are holding the object, **go to** the target container's location.

## 3. Place the object in the container
- Use the action **move [object] to [container]** (e.g., "move alarmclock 1 to desk 1").

# Completion
- The task is done when you receive confirmation (no further actions needed).

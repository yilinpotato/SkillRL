# Goal
Put the required number of target objects into the specified container.

## Explore
First, look at open surfaces (sidetable, desk, etc.) – the objects may be visible directly. If the target objects are not in plain sight, then move to and open every container (drawers, shelves, etc.) to search inside. Note the location of any found targets.

## Pick up
Once you locate a target object, take it. If you need multiple, pick them up one at a time; carry only one if your inventory cannot hold multiple (check with `inventory` if unsure).

## Deliver
After picking up a target object, go to the destination container (the place where it must be put) and use `move <object> to <container>` to place it (the environment uses `move`, not `put`). Repeat for each remaining target object.

## Completion
When you have put the required number of target objects into the container, the task is done. Stop taking further actions.

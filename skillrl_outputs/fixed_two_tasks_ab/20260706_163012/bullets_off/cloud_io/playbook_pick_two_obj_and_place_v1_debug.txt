# Goal
Put the required number of target objects into the specified container.

## Explore
First, move to and open every visible container (drawers, shelves, etc.) to see if the target objects are inside. If found, note their location; otherwise, look on open surfaces (sidetable, desk, etc.).

## Pick up
Once you locate a target object, take it. If you need more than one, pick them up one at a time; carry only one if your inventory cannot hold multiple (check with `inventory` if unsure).

## Deliver
After picking up a target object, go to the destination container (the place where it must be put) and use `put <object> in <container>` to place it. Repeat for each remaining target object.

## Completion
When you have put the required number of target objects into the container, the task is done. Stop taking further actions.

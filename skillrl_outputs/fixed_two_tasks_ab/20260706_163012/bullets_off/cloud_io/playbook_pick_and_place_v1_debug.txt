# Goal: complete the pick-and-place task.

## 1. Understand the task
- Read the task description (e.g., "put a alarmclock in desk"). Identify the object to pick and the destination (surface or container).

## 2. Find the object in the room
- From the initial room description, look for the target object on surfaces or in open containers.
- If the object is listed on a surface (like a sidetable), go directly to that location.
- If the object is not visible, it may be inside a closed container. Explore containers systematically (open them and check inside).

## 3. Take the object
- Once at the object's location, use "take [object] from [location]" (e.g., "take alarmclock 1 from sidetable 1").

## 4. Go to the destination
- Navigate to the destination location (e.g., desk 1).

## 5. Place the object
- Use "move [object] to [destination]" or "put [object] in/on [destination]". If the destination is closed, open it first.

## 6. Done
- No further actions are needed after successful placement.

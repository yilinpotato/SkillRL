# Strategy for pick-and-place tasks

## Goal
Find the required object, pick it up, carry it to the target location, and place it there.

## Steps
1. **Parse the task.** Identify the object to move (e.g., "alarmclock") and the target container (e.g., "desk").
2. **Get initial layout.** Use the observation at the start to list all furniture and their names.
3. **Decide where to search.** Prefer open surfaces (sidetable, desk, shelf) over closed containers (drawer, cabinet) because they are quicker to inspect. Start with the most likely surface.
4. **Move to a candidate location** (e.g., `go to sidetable 1`). After arriving, read the observation to see what objects are there.
5. **Take the object** if it is present (e.g., `take alarmclock 1 from sidetable 1`). If the object is not there, move to another candidate and repeat.
6. **Go to the target location** (e.g., `go to desk 1`).
7. **Place the object** (e.g., `move alarmclock 1 to desk 1`).
8. **Confirm** that the task is complete (no further action needed).

# Skill Tree for Language-Model Agent

## 1. Assess the Task
- Read the task description. Identify: **target object**, **required action** (clean, cool, heat, examine, pick-and-place, pick-two-and-place), and **target location** (where to put it after action).
- If the task involves two objects, note both.

## 2. Locate the Target Object
- Begin searching the most likely containers first:
  - **Fridge** if the target is a fresh food item (tomato, apple, winebottle, etc.).
  - **Cabinets / Drawers** for utensils, cups, pots, plates, etc.
  - **Desk** for small items like mugs, tissuebox, desklamp (for examine tasks).
  - **Countertops / Tables / Sidetables / Shelves** as secondary surfaces.
- **Search systematically**: go to a container, open it, and look inside. If not found, move to next container in logical order. Do not skip to random containers.
- ### Comprehensive Container Search
  - When searching, open **every container** listed in the room description (cabinets, drawers, shelves, etc.) in numerical order. Do not stop after only a few – continue until all visible containers of that type have been checked.
  - If a container fails to open (observation says "The fridge 1 is closed" despite your open action), move on to the next container rather than retrying the same one. Use `look` or `examine` to verify container state only if needed.
- **Do NOT pick up any object** unless it is confirmed to be the target (or a required tool, e.g., desklamp for examine tasks). Picking up irrelevant items wastes steps and can cause loops.
- **If you cannot find the object after checking fridge, all cabinets, drawers, shelves, and visible surfaces, re-check the task – you may have misinterpreted the target.

## 3. Execute the Required Action on the Target
### Clean
- Go to **sinkbasin**.
- Clean the target object (use "clean [object] with sinkbasin").

### Cool
- Go to **fridge** (if not already there).
- Open fridge, then cool the object (use "cool [object] with fridge").

### Heat
- Go to **microwave** or **stoveburner**. (Check which is available; microwave is more common.)
- Place object inside microwave/stoveburner and heat (use "heat [object] with microwave" or similar).

### Examine
- Go to the location that contains the object (often **desk**).
- If the task mentions **desklamp**, first turn it on (use "use desklamp").
- Then examine the specific object (use "examine [object]"). Do not just examine the desk – always target the object itself.

### Pick-and-Place
- Once you have the target object, go directly to the **target location** stated in the task.
- Place it there (use "put [object] in/on [target location]").
- Do **not** move the object elsewhere or put it back where you found it.

### Pick-Two-Objects-and-Place
- Pick the first object, then the second object (in any order, but avoid dropping one).
- Then go to the target location and place both (use two separate "put" actions if needed).
- Keep both objects in inventory until you reach the destination.

## 4. Stop When Task Is Complete
- After placing the target object (or after examine action), the environment will signal success. **Do not continue moving or interacting.**
- If you receive a success message, stop immediately. If not, re-read the task to ensure all steps were done.

## 5. Recovery from Common Mistakes
- **If you picked the wrong object**: put it back where you found it, then resume searching for the correct one.
- **If you are stuck in a loop** (repeating same moves): stop, re-assess the task, and choose a different next action.
- **If you cannot find an object after a thorough search**: check countertops and other surfaces – they are often overlooked.
- ### Handling Failed Open Actions
  - When you attempt to open a container and the observation shows it remains closed (e.g., "The cabinet 5 is closed"), do **not** repeat that same open action. Instead, move to the next container in your search order. The action may have been misinterpreted due to position or state – a different container is more productive.
  - If multiple open actions fail on different containers, use `look` to refresh the room description, then resume searching systematically.

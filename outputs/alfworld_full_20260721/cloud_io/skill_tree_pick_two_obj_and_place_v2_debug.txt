# pick_two_obj_and_place

## Goal
- Your task is to put exactly two instances of a specific object (e.g., book, soapbottle, handtowel) into a specified target receptacle (e.g., bed, garbagecan, countertop).
- You must collect and move **both** items. Do not stop after placing only one.

## Search Strategy
### Systematic search of all receptacles
- Start by reading the room description: list every furniture item (table, shelf, drawer, cabinet, holder, etc.) that could contain the object.
- First check open surfaces (shelf, desk, countertop, coffeetable, handtowelholder, etc.) — objects there are visible immediately.
- For closed containers (drawer, cabinet, dresser), go to each one and open it to see its contents. Do not skip any.
- Move on to the next receptacle if the object is not found; do not repeatedly check the same place.
- If you still haven't found two objects after checking everything, re-examine the room description and try receptacles you might have overlooked (e.g., ottoman, sidetable, fridge).

### Exhaustive check of all furniture types
- Do **not** limit your search to only a few furniture types (e.g., only coffeetable and shelves). Every furniture item listed in the room description is a potential location.
- For example, small objects like creditcards, pens, candles often appear on dining tables, side tables, beds, dressers, and in drawers. Check each furniture type systematically.
- After checking an open surface, if you have not yet found two objects, proceed to closed containers (drawers, cabinets) and open them one by one.

### Re-check unexamined surfaces after initial sweep
- If you complete a first pass of all receptacles and still lack two objects, scan the room description again for any furniture you missed (e.g., a bed, a tvstand, a sinkbasin).
- Some objects may be hidden inside closed containers that you skipped. Revisit any container you did not open.

## Placement Process
### Collect and place the first object
- When you see an object of the required type, take it: `take <object> from <source>`.
- If the source is closed, open it first.
- Then go to the target receptacle (`go to <target>`).
- Move the object to the target (`move <object> to <target>`).

### Collect and place the second object (iteration)
- After placing the first object, **immediately** begin a new exhaustive search for the second instance. Do not get sidetracked by opening containers that are not part of the search.
- Repeat the take → go → move sequence for the second object.
- Treat the task as incomplete until two objects have been moved to the target.

### Avoid stopping after first object
- Do **not** stop to examine other containers or explore unrelated areas after placing the first object. The only valid next action is to resume searching for the second object.
- If you have moved one object but the environment has not declared success, you must still be holding zero objects and need to search again.

## Completion Detection
### Confirm both objects placed
- After moving the second object, the environment will indicate task success. If unsure, you can check your last observation.
- If you have moved two objects but the task is not marked complete, search again — you may have missed one (e.g., two different instances of the same object type).
- **Do not assume success after one placement.** Keep searching until you have placed two.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].

## Critical Rules (must be followed without exception)
- **Do not go to any sinkbasin or bathtubbasin until you are holding the target object.**

## Phase 1: Search and Acquire the Target Object

### Systematic Search Procedure
Follow this order exactly. Do not deviate.

1. **List all open surfaces** from the initial room description. Exclude sinkbasin/bathtubbasin. Open surfaces include: countertops, tables, shelves, stoveburners, diningtables, towelholders, handtowelholders, etc.

5. **Persist:** Even if many containers, check every single one. The target may be in a later cabinet or drawer.
6. **If still not found after all containers, repeat the cycle (open surfaces then containers) but this is rare.**

**Self-Check:** If you find yourself moving between locations without a clear plan, stop. Write down the list of receptacles from the description and check off which you have visited. Do not proceed until you have a plan.

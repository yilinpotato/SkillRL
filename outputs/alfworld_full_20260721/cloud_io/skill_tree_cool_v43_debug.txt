# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Search Strategy (strict order)
1. **Check the current location** (you always start at countertop 1). If the target object is there, take it and go to Phase 2.
2. **Continue searching countertops** in increasing number (countertop 2, countertop 3, ...) until you get an error message (invalid location). At each, read the observation; if the target is present, take it and stop.
3. **Then search diningtables** (diningtable 1, 2, ...) in the same way.
4. **Then sidetables, shelves, sinkbasins, stoveburners** – each type in order, all instances.
- **Never skip a type** – do not go to diningtable before finishing all countertops.
- **Never revisit a searched location** (keep a mental list).
- **If you catch yourself at a wrong location, immediately return to the correct next surface type.**

### Heuristic for likely object locations
- **Food items** (potato, lettuce, apple, etc.) are commonly on countertops, diningtables, or **inside the fridge**. Non-food items (mug, bowl, pan, etc.) may also be in cabinets/drawers.
- If you have checked all surface types and still not found the object, proceed to closed containers in this order: **fridge → cabinet → drawer → microwave**. For each container instance: go to it, open it (if closed), look inside, take the object if present; if not, close it and move to the next.

### Object verification
- Read the exact name from the observation. Only take an object that matches the task's target (e.g., task says "mug" – take only "mug 1", not "cup").

## Phase 3: Move the cooled object to the target location

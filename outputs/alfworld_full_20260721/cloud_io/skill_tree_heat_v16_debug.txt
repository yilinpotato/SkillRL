# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is the microwave.

## 2. Locate the object
### 2.1 Initial check: fridge and countertops
- Start at the fridge (already opened) – look inside. If the target object is present, take it and proceed to heating.
- If not, go to **each countertop** you can see (use a `look` to see which countertops are present). Examine its contents. Take the object if found.
- **Do not skip any countertop** you see in the room description.

### 2.2 If object still not found – survey all other flat surfaces
- After checking all countertops (and not finding the object), perform a `look` action to refresh the room description.
- Identify every flat surface mentioned: **diningtable, sidetables, shelves, desk, coffee table, etc.**
- Go to each one, look at it, and take the object if present.
- **You must visit every flat surface before moving on to containers.**

### 2.3 Openable containers (cabinets, drawers, sinkbasin, garbagecan, microwave, coffeemaker)
- **Only after checking all flat surfaces**, proceed to openable containers. You must check **every** container in a systematic order:
  1. Open and look inside **all cabinets** (go to each cabinet, open it, look inside). Do not stop until every cabinet has been checked.
  2. Then open and look inside **all drawers** (go to each drawer, open it, look inside).
  3. Then open and look inside **the sinkbasin**.
  4. Then open and look inside **the garbagecan**.
  5. Then open and look inside **the microwave** (even though it is the heating appliance, it can hold objects).
  6. Then open and look inside **any other openable container** (e.g., coffeemaker).
- **Do not skip any category.** If you stop after only a few containers, you will miss the object. The object may be hidden in a drawer or sinkbasin that you have not yet checked.

### 2.4 Persistence and retry
- If the object is still not found **after completing the full list** (all flat surfaces + all openable containers above), perform a `look` action again. If new receptacles appear, repeat the entire search from step 2.1.
- Otherwise, re-read the task to confirm the object type. If there is another room available, go there and repeat the search.

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If direct heat fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to section 2 and perform the exhaustive search again.

- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (`examine <receptacle>`) and check inventory (`inventory`). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- **Termination rule**: Once placed at the target, stop all actions immediately.

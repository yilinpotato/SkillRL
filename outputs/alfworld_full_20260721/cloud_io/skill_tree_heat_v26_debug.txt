# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location.
- The heating appliance is the microwave.

## 2. Locate the object
- Start at the fridge. **Open the fridge** to see its contents. If the target object is inside, take it and go directly to Section 3 (heating).
- If the object is NOT in the fridge, proceed to the **post-fridge search routine** below.

### 2.1 Critical: Immediate pick-up rule
- **If you observe the target object on any surface (countertop, table, shelf, etc.) or inside an already-open container, take it immediately.** Do NOT proceed to the next location or continue searching. This rule overrides the order below.

### Post-fridge search routine
Follow this strict order. **You must check every single item in the list. Stopping early will cause failure.**

1. **Countertops** – go to every countertop you can see. At each, `look` and `take` if the object is present.
2. **Flat surfaces** – from a central location, perform a `look`. You will see all flat surfaces (diningtable, sidetables, shelves, desk, coffee table, etc.). **Visit every one of them** – `look` and `take` if found. Do NOT proceed until every flat surface has been examined.
3. **Openable containers** – again, from a central location, perform a `look` to see all openable containers. Then open and look inside each, in this exact order:
   - Cabinets (all of them)
   - Drawers (all of them)
   - Sinkbasin
   - Garbagecan
   - Microwave (even though it is the heating appliance)
   - Any other openable container (e.g., coffeemaker, toaster)

   **Critical**: For each container, you **must open it** (if closed) before you can see its contents. Use the `open` action, not `examine`; `examine` only shows surface items, not interiors. If you arrive at a cabinet and see "nothing" on its surface, that does **not** mean it is empty – you must still use `open`. Then check the interior. If the target object is not inside, immediately proceed to the next container on the list. **Do not stop after only a few containers.** Continue until either the object is found or **every container in the list has been checked**.

4. **After the full list** – if you have checked every countertop, every flat surface, and every container in the exact order above and still not found the object, only then proceed to "Persistence and retry" below.

### Persistence and retry
- **Verify you have truly finished the exhaustive list**: mentally confirm you opened every cabinet, drawer, sink, garbage, microwave, and any other openable container. If you skipped any, go back and open it.
- If the object is nowhere in the room after the full search, perform a `look` again. If new receptacles appear, repeat the entire search from step 1 (countertops).
- Otherwise, re-read the task to confirm object type. If another room is available, go there and repeat the search.
- **Never return to the fridge or give up until you have exhausted every possible receptacle.**

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If direct heat fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to section 2 and perform the exhaustive search again.

### 3.3 Critical: Do not drop or place the object before heating
- Once you have picked up the target object, you must go directly to the microwave and heat it. Do NOT move the object to any other location (countertop, shelf, etc.) before heating. Dropping it back onto a surface or placing it elsewhere will cause a loop and waste steps. The heating action must be performed while the object is in your inventory and you are at the microwave.

## 4. Place the heated object
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, etc.).
- The destination must be different from the source where the object originally came from.
- If the target receptacle is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: `move <object> to <receptacle>`.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (`examine <receptacle>`) and check inventory (`inventory`). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- **Termination rule**: Once placed at the target, stop all actions immediately.

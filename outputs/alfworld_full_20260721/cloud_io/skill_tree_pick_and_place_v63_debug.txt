# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle.

## Sub-Goal Flow
1. Identify the target object and target receptacle from the task description.
2. Systematically search all receptacles (starting with the target) until the object is found.
3. Take the object and place it in/on the target receptacle.
4. Stop immediately after the move action.

## Systematic Search (mandatory)

### Step 1: Extract the full list of all receptacles
- From the initial observation (before any movement), note every noun+number furniture item (e.g., bed 1, drawer 2, cabinet 3, sinkbasin 1, handtowelholder 1). This includes all flat surfaces (sidetable, countertop, sofa, armchair, etc.) and closed containers (drawer, cabinet, safe, etc.).
- If the observation is truncated (ends abruptly), use `look` once to get the full list. Otherwise, do **not** use `look` again.
- Create a mental list in the exact order they appear.

### Step 2: Visit every receptacle on that list, one by one, without skipping or revisiting
- **Start with the target receptacle.** Go to it. If it is closed, open it immediately (next action must be `open`). Read the observation to see if the target object is there. If yes, take it and go to Placement.
- If not, **then go to the first receptacle in your list** (the very first item you wrote down). Proceed through the entire list in order, skipping only the target receptacle if it was already visited.
- For each receptacle:
  - If closed, `open` it **immediately** upon arrival. Do not `examine`, `look`, or `inventory` first.
  - Read the observation. If the target object is present, take it (`take <object> from <receptacle>`) and go to Placement.
  - If not present, **immediately** proceed to the next receptacle. Do not `examine` or `close` anything.
- **Continue until you have visited every single receptacle on the list.** Do not stop earlier, even if you think the object might be elsewhere.
- **If you catch yourself repeating the same actions (looping), stop and re-read your list. You must be visiting a new receptacle each time.**

### Critical rules to avoid failure
- **Do not stop early** – you must finish the entire list. The object could be on a surface or in a container you haven't checked yet. In the failed examples, agents stopped after only a few cabinets or drawers and missed the target.
- **Include all surface types** – flat surfaces like countertops, sidetables, armchairs, sofas, diningtables, etc. are equally valid receptacles. Do not skip them even if you have already checked many containers.
- **Include all container types** – open every drawer, cabinet, safe, etc. you encounter. Do not assume the object is only in one kind of furniture.
- **No `look` or `inventory` during search** – it wastes actions and can cause you to lose track. The only allowed `look` is the single initial one if the observation was truncated.

## Object Verification
Before taking any object, **verify that the base noun matches exactly** the target object from the task description.
- Example: target "soapbottle" is not "soapbar". Target "pillow" is not "cushion".
- If the name does not match, do **not** take it. Continue searching.
- This check must be done for every pickup attempt, even if the object looks plausible.

## Object Acquisition
- Action: `take <object> from <receptacle>` only after verification passes.
- If the object name is ambiguous (e.g., "spraybottle" vs "bottle"), use the exact words from the observation.

## Placement
- Go to the target receptacle. If closed, open it. Then `move <object> to <receptacle>`.
- **Stop immediately** after the move action. Do not perform any further actions.

## Final Reminder
- The agent must **follow the systematic search exactly** – do not deviate, do not skip, do not stop early.
- Object verification prevents placing the wrong object. Always check the name before taking.

# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Surface Search Order (strictly enforced)
1. **Countertops** – start at countertop 1, then check countertop 2, 3, etc. Do NOT move to the next surface type until all countertops have been examined.
2. **Diningtables** – check each diningtable instance.
3. **Sidetables** – check each sidetable.
4. **Shelves** – check each shelf.
5. **Sinkbasins** – check each sinkbasin.
6. **Stoveburners** – check each stoveburner.
- At each location, read the observation. If the target object is present, take it and go to Phase 2.
- **Never skip a surface type.** If you have not visited every surface type listed above, you are NOT done with surfaces. Do NOT go to any container until all surface types have been exhausted.
- Keep a mental list of locations already visited; do not revisit.
- If you find yourself at a container before finishing surfaces, that is a mistake. Immediately return to the next unvisited surface type.

### Closed Container Search (only after all surfaces are exhausted)
After checking every surface type above and still not finding the object, proceed to closed containers in this exact order. For each container type, check every instance:
1. **Fridge** – open it (if closed), look inside. If the target object is present, take it and go to Phase 2. If not present, close the fridge and move to the next container instance (or next type).
2. **Cabinet** – for each cabinet instance: open, look, if target present take it and go to Phase 2; if not, close and move to next cabinet.
3. **Drawer** – same process.
4. **Microwave** – same process.
- After finishing all containers of all types and still not finding the object, backtrack through the surface list again; you may have missed a location.

### Object Verification Rule
- Before taking any object, carefully read its exact name from the observation (e.g., "cup 1", not "mug 3"). Only take an object whose name matches the target object type exactly. If you see a similar object with a different name, leave it and continue searching.
- **If you are already carrying an object that does not match the task**, put it down immediately (use `put <object> on <surface>`) and resume searching. Do not proceed to cooling with a wrong object.

## Phase 2: Cool the object using the fridge

### Immediate Cooling Action
- As soon as you have taken the target object, your next action MUST be to go to a fridge, open it, and use `cool <object> with fridge`.
- Do NOT examine the object, move anywhere else, or perform any other action in between. Any detour (e.g., looking, moving to another room) is a failure.
- If you are not carrying the object, go back to Phase 1.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, microwave).
- If the target is a closed container (like a microwave or cabinet), open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Critical Rules (must be followed without exception)
- **Pick up the target object immediately when you see it.** Do not explore any other location until you are holding the target.
- **Always finish checking ALL open surfaces before opening any closed container.** Open surfaces include: countertops, tables, shelves, stoveburners, diningtables, towelholders, handtowelholders, and any other receptacle that is not a closed container (cabinet, drawer, fridge, microwave, oven, etc.). Do not skip any.
- **Persist through every closed container.** Open each cabinet, drawer, fridge, microwave, etc. in order. Do not stop after a few empty ones; the object may be in a later container.

## Phase 1: Search and Acquire the Target Object
**⚠️ CRITICAL RULE: Do NOT go to any sinkbasin, bathtubbasin, or any cleaning source until you are holding the target object. Do NOT go to the destination receptacle until Phase 3 (after cleaning).**
- **This phase ends only when you are holding exactly the target object.** Do not attempt to clean or place until then.
- If you are already holding something that is not the target, put it down immediately (e.g., `put [object] on/into [receptacle]`).

### Object Name Matching
- Compare the object name from the task with names in your observations. Only an exact string match counts.
- Do not pick up similar items (e.g., cloth vs towel, pan vs pot). If the name differs, keep searching.

### Adapting search when the environment lacks a kitchen countertop (e.g., bathroom)
- The consensus prefix is "go to countertop 1" – but if the initial room description does NOT contain any countertop 1, **skip the consensus prefix** and start your search directly from the listed receptacles.
- In such rooms, still follow the same systematic search procedure (open surfaces first, then closed containers) using the receptacles given in the room description.
- Do NOT wander aimlessly; list all receptacles from the description and check them one by one.

### Systematic Search Procedure
#### Mandatory order: open surfaces first, then all closed containers (no skipping)
- **Step 1 – All Open Surfaces** (e.g., countertops, tables, shelves, stoveburners, diningtables, towelholders, handtowelholders, etc.)
  - **IMPORTANT: Do NOT include sinkbasin or bathtubbasin in this search – they are cleaning sources reserved for Phase 2. Skip them entirely.**
  - Visit every individual open surface instance listed in the room description (excluding cleaning sources). Do not skip any.
  - At each, examine its contents. If you find the target, pick it up and proceed to Phase 2.
  - **Do not move to Step 2 until every open surface instance has been visited.**
- **Step 2 – All Closed Containers** (only after Step 1 is complete)
  - **If the target object is a food item (e.g., egg, tomato, apple, lettuce, potato), go to the fridge first – it is a high-probability location. Otherwise, proceed in the fixed order below.**
  - **You must open every single closed container that was listed in the initial room description. Do not stop after opening only one or two.**
  - Open them in this fixed order: all cabinets first (in numerical order if numbered), then all drawers, then the fridge (if not already checked for food), then the microwave, then any other closed container (e.g., oven). **Do not deviate from this order.**
  - For each container: `open [container]`, then look inside (observation shows contents). If the target is inside, pick it up. If not, move to the next container.
  - **Do not go back to open surfaces or to the cleaning source until you have checked every closed container.**
  - **Persist through large numbers of containers.** For example, if the initial description lists cabinets 1 through 16, you must open each one in order. Do not stop after a few empty ones; the object may be in a later cabinet or drawer.
  - If you have checked all closed containers and still haven't found the object, you may repeat the cycle (open surfaces again, then containers) in case the environment changed, but that is rare.

#### Self-Check to Avoid Skipping
- If you ever find yourself moving between receptacles without a clear order, stop. **List all receptacles you have seen in the initial room description and check off which ones you have visited.** Do not proceed until you have a plan.
- The most common failure is stopping after checking only a few open surfaces or a handful of cabinets. **Force yourself to continue until every single receptacle has been examined.**
- Another common failure is jumping to closed containers before finishing open surfaces. Always finish Step 1 first.
- **After the consensus prefix (go to countertop 1), do NOT immediately go to sinkbasin or bathtubbasin. Search open surfaces first (excluding cleaning sources).**

## Phase 2: Clean the Object
- **Prerequisite: You must be holding the target object.** If you are empty-handed, return to Phase 1.
- **Immediately after picking up the target, do not examine it or check inventory.** Go directly to [cleaning_source] (sinkbasin or bathtubbasin).
- Use `clean [object] with [cleaning_source]`.
- Confirm the observation says you cleaned it.

## Phase 3: Place the Clean Object at Destination
- Go to the [destination] specified in the task.
- If the destination is a closed container (e.g., microwave, fridge, drawer, cabinet), open it first.
- Use `move [object] to [destination]` to place it.
- Confirm the observation shows the object is now at the destination.
- **Do not go to the destination before cleaning – only now in Phase 3.**

## Completion
- The task ends as soon as you have placed the clean object. Stop all other actions.
- Do not continue searching or moving other objects.

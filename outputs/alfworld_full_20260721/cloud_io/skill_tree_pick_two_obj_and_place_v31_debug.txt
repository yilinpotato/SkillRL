# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

### Count Tracking
- Keep a mental counter of objects placed: start at 0. After each successful placement, increment by 1.
- **Never stop until counter == 2.** If counter == 1, you must immediately search for and place the second object.
- If after two complete passes through all furniture you still have only 1 placed, the task may be impossible — but only then may you stop.

### Critical Rule (Overrides All Others)
- **After taking any matching object, immediately go to the target and place it. Do not take any other action (including searching for the second object) until this placement is complete.**
- **When you arrive at the target receptacle, if it is closed (e.g., drawer, cabinet, fridge), open it first, then place the object.**
- **Whenever you see a matching object during any search, take it immediately before anything else (except if you are already carrying an object that must be placed first).**

### Object Type Verification
- Before taking any object, compare its exact name to the required type. Only take exact matches.
- Do **not** assume similar objects (e.g., mug vs cup, soapbottle vs soapbar) are acceptable. If the name differs, skip it and continue the search.
- If you accidentally take a non-matching object, do not waste actions moving it; use `inventory` to check, then drop it or leave it and resume search immediately.

### Systematic Object Search
1. **Create Master List**: After the initial room description, write down every furniture item exactly as listed. This includes all surfaces (countertops, tables, sidetables, etc.) and containers (drawers, cabinets, fridge, etc.). Do not miss any item.
2. **Visit Each Furniture Item Systematically**: Pick any unvisited item from your master list. Go to it. If closed, open it. Examine its contents (inside if container, on top if surface). If you see an object whose exact name matches the required type, **take it immediately**. Check off that item as visited. Repeat for every item on the list.
3. **Immediate Placement**: With a matching object in hand, go directly to the target receptacle. If the target is closed, open it. Use `move <object> to <target>` immediately. No other actions in between. After placing, increment your mental counter.

### Multi-Object Placement Loop
- Collect and place two objects. After placing the first, mental counter = 1.
- **Immediately begin a second systematic search** (repeat the Systematic Object Search steps from scratch, including reopening all previously opened containers).
- If during the first search you saw a second matching object at the same location (e.g., on same countertop or inside same open container), return directly there and take it.
- Otherwise, perform a full second pass of the master list. Do not skip any furniture item.
- If after completing two full passes you still have only one object placed, you may stop (task likely impossible).

### Common Failure Patterns (Avoid These)
- **Premature stop after taking first object without placing it**: You must place it immediately before doing anything else.
- **Stopping after first placement**: Immediately restart the search loop. Do not wander or explore unrelated items.
- **Incomplete master list**: Omitting any furniture item leads to missing objects. Ensure you list every item from the initial observation.
- **Not reopening containers during second pass**: New objects may appear inside.
- **Stopping early due to frustration**: Complete at least two full passes before concluding impossibility.
- **Picking wrong object**: Verify exact name before taking (see Object Type Verification).
- **Skipping surfaces (countertops, sidetables, etc.)**: Visit every furniture item in the master list, including surfaces. Do not assume an object is only inside containers.
- **Not opening the target receptacle before placing**: If the target is a closed container, you must open it before moving the object in.

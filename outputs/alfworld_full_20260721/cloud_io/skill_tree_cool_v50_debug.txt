# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Search Heuristic – prioritize common locations
- Most household objects are found on **countertops** or inside the **fridge**.
- Always start by checking every countertop instance. If the target is there, take it immediately and go to Phase 2.
- If not found on any countertop, **check the fridge** before moving to other surfaces. Open it, look inside. If target present, take it (→ Phase 2). If not, close the fridge and proceed.
- Only after checking all countertops and the fridge, continue to the other surface types in the strict order below.
- **Do not** visit stoveburners or sinkbasins early—they rarely hold coolable objects. Stick to the order.

### Surface Search – strictly follow this order, do not skip any type
1. **Countertops** – check every countertop instance (already done as part of heuristic).
2. **Diningtables** – check every diningtable.
3. **Sidetables** – check every sidetable.
4. **Shelves** – check every shelf.
5. **Sinkbasins** – check every sinkbasin.
6. **Stoveburners** – check every stoveburner.

- At each location, read the observation. If the target object is present, **take it immediately** and go to Phase 2.
- **Never skip a surface type.** If you have not visited every surface type above (including countertops and the fridge), you are NOT done. Do NOT move to other containers until all surface types are exhausted.
- **If you find yourself at a container before finishing surfaces, that is a mistake.** Immediately return to the next unvisited surface type. Do not open the container.

### Closed Container Search – only after all surface types are exhausted
- After checking every surface type above (countertops, fridge, diningtables, sidetables, shelves, sinkbasins, stoveburners) and still not finding the object, you **must** search the remaining closed containers. Do NOT go back to surfaces before checking these.
- Search containers **in this exact order**. For each type, check every instance:
  1. **Cabinet** – open each cabinet, look, if target present take it; if not, close and move to next cabinet, then next container type.
  2. **Drawer** – same process.
  3. **Microwave** – same process.
- **Critical: You must open every container to see its contents.** Simply looking at a closed container reveals nothing.
- **After each container type, do NOT return to surfaces.** Continue to the next container type in the list. Only after you have checked **all** container types and still not found the object, then backtrack through the surface list again – you may have missed a location earlier.

### Object Verification Rule
- Before taking any object, carefully read its exact name from the observation. Only take an object whose name matches the target object type exactly.
- If you are already carrying an object that does not match the task, put it down immediately (use `put <object> on <surface>`) and resume searching.

## Phase 2: Cool the object using the fridge
- As soon as you have taken the target object, your next action **MUST** be to go to a fridge, open it (if closed), and use `cool <object> with fridge`.
- Do NOT examine the object, move anywhere else, or perform any other action in between.
- If you are not carrying the object, go back to Phase 1.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, garbagecan).
- If the target is a closed container, open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

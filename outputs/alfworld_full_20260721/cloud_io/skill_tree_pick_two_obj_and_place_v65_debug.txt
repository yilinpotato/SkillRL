   - If closed, **open** it.
   - Examine contents. If you see the **exact target object name**, **take it immediately**. Do NOT pick up any other object.
   - If you accidentally take a wrong object, `drop` it and continue.

- Execute `look` to form the search list.

- Then **immediately** `go to target receptacle`, open if closed, `place` the object. Increment counter to 1.

## Phase 2 – Second Object (counter = 1)

  1. Execute `look` (fresh observation).

  3. When you find a second target, take it, go place it. Stop.

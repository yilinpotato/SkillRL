# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

## First Object Search
### Exhaustive Search Procedure
- From the **initial room description**, compile a mental list of **every visible furniture item** (cabinets, drawers, countertops, tables, shelves, dressers, fridge, microwave, sinkbasin, etc.).
- Visit each furniture item in the list **one by one**.
- If the item is closed (e.g., drawer or cabinet), open it immediately.
- Examine **both the contents inside** (if a container) and **on top** (if a surface).
- If you find an object whose exact name matches the required type, **take it** (do not take non-exact matches).
- Continue until you have visited every item on the list, even if you already found one object.

## Exact Type Matching
- Before taking any object, compare its exact name to the required type. Do not take if they differ (e.g., soapbottle vs soapbar). Only take exact matches.

## Placement (First Object)
- With a matching object in hand, go directly to the target receptacle and use `move <object> to <target>` immediately. No other actions in between.

## Critical: After Placing the First Object, Start the Second Search Immediately
### Second Search Procedure
- **DO NOT STOP.** You must place a second matching object.
- If you already know where the second object is (e.g., you saw it earlier), go directly to that location, take it, and place it.
- Otherwise, **repeat the exhaustive search** exactly as in the first search: compile the same list of furniture items from the initial observation, visit each one, open if closed, examine contents, and take any matching object.
- Do not skip any furniture or assume it is empty. Open every closed container again.
- Continue until you have placed the second object. If you find none after a full systematic search, the task may be impossible.

## Completion
- Keep a counter. After placing the first, set counter=1. After placing the second, set counter=2 and stop.

## Common Failure Pattern (Avoid This)
- **Premature stop**: Placing one object and not continuing. Always perform the second systematic search as soon as the first is placed.
- **Incomplete search**: Not listing all furniture from the initial observation leads to missing objects. Always enumerate every item you see at the start.

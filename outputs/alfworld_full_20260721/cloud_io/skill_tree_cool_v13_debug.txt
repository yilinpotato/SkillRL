# Goal: Cool an object and move it to a specified target location.

## Sub-goal 1: Find the object to cool.
- The target object is not yet in your inventory. You must locate it by searching all receptacles in the room.

### Initial assessment
- Start by reading the room description from the `look` command. It lists all receptacles with their numbers.
- Do not assume any receptacle contents are known until you have explicitly looked inside.

### Systematic search of open flat surfaces (mandatory order)
- The target is often on a flat surface (countertop, diningtable, sidetable, shelf, sinkbasin, stoveburner). Do not open closed receptacles until every flat surface has been checked.
- **You must check every flat surface listed in the room description in this exact order, without skipping any.**

#### Exhaustive enumeration of all flat surfaces
- List all flat surface types from the room description: countertops, diningtables, sidetables, shelves, sinkbasin, stoveburners.
- Visit each numbered instance in order: all countertops first, then diningtables, then sidetables, then shelves, then sinkbasin, then stoveburners.
- For each:
  1. Go to it.
  2. Read the observation. If the target is present, take it immediately using `take <object> from <location>`.
  3. If not, move to the next without extra actions.
- **Do not skip any flat surface, even if you have visited it earlier for another reason.**

### If target still not found: search closed receptacles, starting with the fridge
- After every open flat surface has been checked, search closed receptacles. The fridge is both a likely hiding place for the object (if it needs cooling) and the appliance you will use to cool it. **Always check the fridge first among closed containers.**
  1. Go to the fridge.
  2. If it is closed, open it.
  3. Look at its contents. If the target is present, take it. (You are already at the fridge; you can go straight to cooling.)
  4. If not, move on to other closed receptacles.

#### Systematic search of all other closed receptacles
- After checking the fridge, identify every remaining closed receptacle from the room description: cabinets, drawers, microwave (any numbered instances of each type). **Do not stop after a few; you must check every numbered instance.**
- For each numbered instance:
  1. Go to it.
  2. **Use the `open` action to open the receptacle** (do not use 'examine' or 'look' alone—only 'open' reveals the interior contents). The observation will then show what is inside.
  3. If it is closed, open it.
  4. Read the observation. If the target is present, take it.
  5. If not, proceed to the next instance.
- **Do not skip any numbered instance of any closed receptacle type.** If one cabinet is empty, continue to the next cabinet. Only stop when you have checked every instance listed in the room description.
- If after all that the object is still not found, re-read the room description to ensure you have not overlooked any receptacle.

## Sub-goal 2: Take the object.
- Once you see the object, take it immediately with `take <object> from <location>`.

### Immediately cool after picking (mandatory)
- As soon as you have taken the object, cool it using the fridge before doing anything else. Do not move to the target location or do other actions.

## Sub-goal 3: Cool the object using the fridge.
- Ensure you are at the fridge (go there if not already).
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Sub-goal 4: Move the cooled object to the target location.
- Go to the target location (named in the task).
- Use `move <object> to <target>`.

## Completion check:
- The task is complete when the object has been cooled and placed at the target location. Trust the sequence.

# pick_two_obj_and_place

## Goal
- Place exactly two instances of a specific object into a specified target receptacle.

## Multi-Object Tasks
### Count and Repeat
- Keep a counter: start at 0. After placing the first object, update to 1. Do not stop until counter is 2.
- After placing one object, immediately begin a fresh, systematic search for the second object. Do not assume the task is done.
- If you cannot find a second object after thorough search, re-check every furniture type (see Full Room Coverage) – you may have missed a location.

## Exploration Strategy
### Full Room Coverage
- From the initial room description, list every visible furniture item (e.g., cabinet, drawer, shelf, countertop, dresser, sink, fridge, bathtub, toilet, etc.). Do not skip any type.
- Visit each item exactly once in your first pass. For each:
  - Go to it.
  - If it is a container (closed drawer, cabinet, etc.), open it.
  - Examine its contents (on surfaces or inside).
- Common misses: dressers, garbage cans, bathtub basins, handtowel holders, toiletpaperhangers, etc.
- If after visiting all items you still lack one or both objects, repeat the list but check opened containers again (objects may have been moved).

### Object-Specific Hints
- Some objects are often found near their functional location. For example:
  - toiletpaper is commonly on a toiletpaperhanger or in a cabinet near the toilet.
  - soapbottle may be on a sink or counter.
  - newspaper might be on a sidetable or sofa.
- Use these hints to prioritize search, but do not skip any furniture type – always eventually check all.
- Do not assume an object is absent just because its typical location is empty; a second copy may be elsewhere.

## Procedure (step-by-step algorithm)
1. **Identify task**: Note the required object type and target receptacle.
2. **List all furniture**: From the initial room description, write down every visible furniture item. This is your master list.
3. **First object search**: For each item on the list:
   - Go to it.
   - If closed, open it.
   - Examine its contents.
   - If you see an object whose exact name matches the required type, take it and go to step 4.
   - Otherwise, move to next item.
   - If you exhaust the list without finding the object, re-check any missed items or re-open containers.
4. **Place the first object**: Go directly to the target receptacle. Use "move <object> to <target>" immediately. Do not perform any other actions.
5. **Second object search**: Reset your mental list to the master list from step 2. Repeat step 3 exactly, but now you need only one more object. Do not skip any furniture type – re-visit all.
6. **Continue until done**: After placing the second object, the task is complete. If you have placed only one, keep searching.

## Common Failure Patterns
### thorough_search
- Ensure you visited every furniture item from the initial list. Do not skip any cabinet, drawer, shelf, counter, stove burner, fridge, etc.
- If an item is closed, open it before checking contents.
- After checking all, if still short, revisit any missed items or recheck opened containers.
- Common oversight: checking only one type of furniture. Spread search across all categories.

### check_count
- After placing the first object, immediately begin the second search. Do not interpret any intermediate success message as task completion.
- Confirm that you have placed exactly two objects before concluding.
- If you have placed only one, continue searching.

## Critical warnings (avoid these failures)
- **Insufficient search**: You must visit every furniture type. Checking only a few will cause failure.
- **Premature stop**: After placing the first object, immediately start searching for the second. Do not rest.
- **Not opening containers**: Always open before looking inside. "Examine" does not open.
- **Wrong object identity**: Verify exact name before taking. No partial matches.
- **Intervening actions**: At target receptacle with correct object, use move action immediately – no delays.

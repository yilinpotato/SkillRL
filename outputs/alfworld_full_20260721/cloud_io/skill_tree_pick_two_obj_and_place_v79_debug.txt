# pick_two_obj_and_place

## Goal
Place exactly two instances of the target object type into the target receptacle. Stop when counter == 2.

## Critical Rules (violating any means failure)
- **Always start with `look`** to get the full list of furniture in the room. Never move before looking.
- **At every furniture item**: if it is closed, open it before examining its contents.
- **After placing the first object, immediately transition to finding the second.** Do not pause.
- **Never perform the same action twice in a row without moving** – that is a loop. If you notice the same verb twice, force a move to the next item on your current search list.
- **Follow the search list exactly in order. Do not skip any furniture item.** Even if you think it's unlikely, check every item.
- **Constantly track your counter (0 or 1).** After each placement, increment counter.

## Multi‑Object Tracking
- **Counter starts at 0.** After each successful placement, increment counter. If counter == 2, stop. If counter < 2, you **must** continue searching for the next object.
- **After placing the first object (counter=1), your only goal is to find the second object.** Do not pause, look around, or inspect non-target furniture. Immediately follow one of the two paths in Phase 2.

## Systematic Search
### Initial List
- The first `look` gives you an ordered list of all furniture in the room. This is your master search list. Write it down mentally.
### Search Execution
1. **Go to the first item** on the list.
2. **If it is closed, open it.**
3. **Examine the description** – if you see the target object, take it and go to Phase 1 (first object) or Phase 2 (second object) depending on counter.
4. **If you do not see the target object**, immediately **go to the next item** on the list. Do not stay, do not repeat the same action, do not `look` again.
5. Continue this process until you have visited **every item** on the list. If you have visited all and still need the target, start again from the top of the list **(repeat the list once more)**. After two full passes with no target, the object is absent – stop.
- **Do not skip any furniture.** For example, if the target is a cup, you must check countertops, shelves, tables, drawers, cabinets – every item on the list.

## Confirm Object Identity Before Picking
- **Re-read the target object name** from the task description before each pick.
- Only pick up an object whose name **exactly matches** the target type (e.g., "statue" not "peppershaker").
- If unsure, use `look` to see the name again.
- If you accidentally take a wrong object, `drop` it immediately and resume search.

## Phase 1 – First Object (counter = 0)
- Execute the **Systematic search** to find and take the first target object.
- After taking it, **go directly to the target receptacle**. Do not place anywhere else.
- At the target receptacle: open if closed, then use `move` to place the object. Counter becomes 1.
- **While holding the object, do not drop it, move it elsewhere, or interact with any other object.**

## Phase 2 – Second Object (counter = 1)
**Immediately after placing the first object, find and place the second. Do not stop.** Choose one of two paths:

### Shortcut – Only If Multiple Copies Were at the Same Source
- **Condition:** You saw **more than one** instance of the target object at the exact location where you took the first one (e.g., multiple plates on the same table). If only one copy was there, do **not** use this shortcut.
- **Action:** Go back to that same location, take the next copy, go to the target receptacle, and place it. Counter becomes 2. Stop.

### Mandatory Fresh Look After First Placement (unless Shortcut)
- **If Shortcut does not apply, your very first action after placing the first object must be `look`.** This gives you a new, ordered list of furniture to search. Do not go to any furniture before this look.
- After the look, immediately go to the **first item** on that new list. Follow the **Systematic search** exactly to find the second target.
- When you find it, take it, go to the target receptacle, and place it. Counter becomes 2. Stop.
- If you complete two full passes of the fresh list without finding a second target, task impossible – stop.

## Loop Detection & Recovery (global)
- **Symptoms of a loop:** Two consecutive actions of the same verb (e.g., `look`, `look` or `open`, `open`) without moving, or repeatedly failing to move to the next item.
- **Action:** As soon as you detect a loop, **force a change**:
  - If you have a current search list, go to the next unvisited item on that list.
  - If no list exists (e.g., you just finished a look), re-read the `look` observation and go to the first item.
  - Do not repeat the same action more than once without moving.
- **Prevention:** Before every action, verify that it is different from your previous action. If it is the same, replace it with a `go to` to the next item.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
- **You may go to sinkbasin or bathtubbasin to search for the target object.** If the target object is there, pick it up. Once you are holding it, you can clean it immediately using the same sinkbasin/bathtubbasin. Do not go to the sinkbasin solely to clean until you are holding the object.
- **Do not go to the destination receptacle until after cleaning.**
- **Search open surfaces first, then closed containers. Do not skip any open surface** – including stoveburners, countertops, diningtable, shelves, towelholders, carts, garbagecans, sinkbasins, bathtubbasins, and any other receptacle that is not a closed container (cabinet, drawer, fridge, microwave, oven, etc.).
- **If you are already holding something that is not the target, put it down immediately.**
- **After arriving at the cleaning source, perform the clean action immediately** – do not examine, look, or inventory before cleaning.
- **Before picking any object, confirm its name matches the target exactly.** Do not pick similar-named objects (e.g., soapbottle vs soapbar).
- **Do not stop searching until you have checked every single receptacle listed in the initial `look` description.** Stopping early causes failure.

## Phase 1: Search and Acquire the Target Object
**Prerequisite: None – begin with a fresh `look` to get the room description.**

### Object Identity Verification
- When you see an object that might be the target, stop and compare the exact name from the task.
- Do not pick up any object whose name is different (e.g., soapbar ≠ soapbottle, fork ≠ spoon).
- If unsure, do not pick; continue searching.

### Systematic Search (follow this loop exactly)
1. **After receiving the initial room description (the first `look` or the welcome message), make a mental list of every receptacle** – both open surfaces and closed containers. Keep this list in mind throughout the search.
2. **Visit each open surface exactly once** in any order, but do not skip any. At each, examine contents. If the target is present, pick it up (after verifying name) and go to Phase 2.
   - After leaving a receptacle, **mentally check it off your list**.
   - If you ever find yourself revisiting a checked receptacle, stop and use `look` to refresh your list. Then go to the next unchecked open surface.
3. **After every open surface has been checked off, if the target is still not found, proceed to closed containers.**
   - **Do not open any closed container before all open surfaces are exhausted.**
   - **Self-check before opening the first container:** Recall your mental list of open surfaces. If any are unchecked, go to that open surface immediately.
4. **Closed container search order:**
   - **If the target is a food item** (e.g., lettuce, potato, tomato, apple, bread, egg, etc.): go directly to the fridge first. Open it, look inside, and take the target if present.
     - If not found in the fridge, continue to cabinets (numerical order), then drawers (numerical order), then microwave, oven, etc.
   - **For non‑food targets:** check all cabinets (numerical order), then all drawers (numerical order), then the fridge, then microwave, oven, etc.
   - **Execution rules for all closed containers:**
     - Open each one, look inside. If the target is not inside, immediately close it (if necessary) and move to the next container in numerical order.
     - Do not skip any container. If you open a container and it is empty or contains other objects, close it and move on.
     - If still not found after all closed containers, repeat the cycle (open surfaces then containers) – this is rare, but do it.
5. **If you ever feel stuck or start wandering, immediately use `look` to re-read the room description and reconstruct your mental list. Then resume the loop from the first unchecked receptacle.**

### Critical Rule: Do Not Stop Early
- **If you open a receptacle and the target is not there, you are NOT done. Continue to the next receptacle in your list immediately.**
- **Stopping after checking only a few cabinets or drawers is a guaranteed failure. You must check every single open surface and closed container listed in the initial `look`.**

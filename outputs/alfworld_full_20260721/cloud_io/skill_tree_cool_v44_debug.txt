# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Search Strategy (strict order)
You MUST check every surface type in the order listed below before opening any closed containers.
1. **Countertops** (countertop 1, 2, 3, ...) – start at the current location (usually countertop 1). If the target object is there, take it and go to Phase 2.
2. **Diningtables** (diningtable 1, 2, ...)
3. **Sidetables** (sidetable 1, 2, ...)
4. **Shelves** (shelf 1, 2, ...)
5. **Sinkbasins** (sinkbasin 1, 2, ...)
6. **Stoveburners** (stoveburner 1, 2, ...)
- At each location, read the observation. If the target is present, take it and stop.
- Never skip a type – do not go to diningtable before finishing all countertops.
- Never revisit a location you have already searched (keep a mental list).
- If you find yourself at a wrong location, immediately return to the correct next surface type.

### Closed Container Search (only after all surfaces are exhausted)
If you have checked every surface type and still not found the object, proceed to closed containers in this exact order:
1. **Fridge**
2. **Cabinet**
3. **Drawer**
4. **Microwave**
For each container instance:
- Go to it.
- Open it (if closed).
- Look inside and read the observation.
- If the target object is present, take it.
- If not, close the container (if you opened it) and move to the next container.

### Object verification
- Read the exact name from the observation. Only take an object that matches the task's target (e.g., task says "mug" – take only "mug 1", not "cup").

## Phase 2: Cool the object using the fridge
- **Prerequisite:** You must be carrying the target object. If not, go back to Phase 1.
- Go directly to fridge (any instance). Open it if closed. Then use `cool <object> with fridge`.
- **No detours** – do not perform any other action between taking the object and cooling it.

## Phase 3: Move the cooled object to the target location
- Go to the target location. If it is closed (e.g., microwave, oven), open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

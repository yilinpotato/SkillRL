# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is the microwave.

## 2. Locate the object
### 2.1 Initial check: fridge and countertops
- Start at the fridge (already opened) – look inside. If target object present, take it and proceed to heating.
- If not, go to each countertop you can see and examine its contents. Take the object if found.

### 2.2 Flat surfaces (diningtable, sidetables, shelves)
- If still not found, visit every flat surface the room description mentions: diningtable, sidetables, shelves, etc. Go to each, look at it, and take the object if present. Do not skip any.

### 2.3 Openable containers (cabinets, drawers, sinkbasin, garbagecan, microwave, coffeemaker)
- **Mandatory**: You must open and look inside each of the following, in any order, until the object is found:
  - All cabinets (open each one, look inside)
  - All drawers (open each one, look inside)
  - Sinkbasin (open, look inside)
  - Garbagecan (open, look inside)
  - Microwave (open, look inside) – even though it is the heating appliance, it can hold objects.
  - Any other openable container (e.g., coffeemaker) – open and look.
- **Do not stop** after checking only cabinets or only drawers. You must open all the above before concluding the object is missing.

### 2.4 Persistence and retry
- After completing the full list, if the object is still not found, perform a `look` action to refresh the room description. If new receptacles appear, repeat the entire search from step 2.1.
- Otherwise, re-read the task to confirm the object type. If needed, go to a different room (if available) and repeat the search.

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If direct heat fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to section 2 and perform the exhaustive search again.

## 4. Place the heated object
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, etc.).
- The destination must be different from the source where the object originally came from.
- If the target receptacle is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: `move <object> to <receptacle>`.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (`examine <receptacle>`) and check inventory (`inventory`). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- **Termination rule**: Once placed at the target, stop all actions immediately.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- The cleaning source is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
1. **Never go to the cleaning source unless you are already holding the target object.** If you arrive there accidentally, leave immediately and resume search.
2. **Once you are holding the target object, do not put it down or interact with any other object until after you have cleaned it and placed it at the destination.**
3. **Do not go to the destination receptacle until after cleaning.**
4. Before picking any object, confirm its name matches the target exactly.

## Search Phase
### Initial Look
- Use `look` immediately to get the full room description. List all receptacles (both open surfaces and closed containers) mentally. Do not skip this step.

### Open Surface Search
- Open surfaces include: countertops, diningtable, stoveburners, shelves, sinkbasin, bathtubbasin, garbagecan, handtowelholder, towelholder, carts, etc.
- Visit **each open surface exactly once** in any order. At each, examine contents. If the target is present (verify name), pick it up and exit search (go to Cleaning Phase).
- After each open surface, proceed immediately to the next. Do not look, examine, or perform any other action between open surfaces.
- After visiting the last open surface, if the target was not found, go to Closed Container Search.

### Closed Container Search
- Closed containers include: cabinets, drawers, fridge, microwave, oven, etc. (any receptacle not an open surface).
- **Order:** For non-food targets: all cabinets (numerical order), then drawers (numerical), then fridge, then microwave, oven, etc. For food targets (lettuce, potato, tomato, apple, bread, egg, etc.), go to fridge first, then cabinets, then drawers, etc.
- At each closed container: Immediately `open [container]`. Look inside. If the target is inside, take it and exit search (go to Cleaning Phase). If not, close it and immediately go to the next container in the prescribed order. Do not perform any other action between containers.
- **You must open and look inside every single closed container listed in the room description.** Do not skip any. If you lose track, use `look` to refresh your list of remaining containers.

### Exhaustive Search Rule
- If you have checked all open surfaces and all closed containers and still have not found the target, **repeat the entire search cycle** (open surfaces again, then closed containers). This is rare but possible.
- **Never stop searching until the target is found.** If you find yourself in a loop or unsure, use `look` to refresh your checklist and continue.

## Cleaning Phase
### Prerequisite: You must be holding the target object
- If empty-handed, return to Search Phase. If holding a different object, put it down first then return to Search Phase.

### Go to Cleaning Source
- Once holding the target, immediately go to the cleaning source (sinkbasin or bathtubbasin).

### Clean Immediately
- **Upon arrival at the cleaning source, the only valid next action is `clean [object] with [cleaning_source]`.** Do NOT look, examine, inventory, or move anywhere else. If you ever arrive at the cleaning source and are not immediately cleaning, you have made a mistake. Correct it by performing the clean action now.
- Confirm the observation says "You clean the [object] using the [cleaning_source]." Only then proceed to Placement Phase.

## Placement Phase
- Go to the destination receptacle. If it is a closed container, open it first.
- Use `move [object] to [destination]`.
- Confirm the object is now at the destination (observation will indicate placement).

## Completion
- Stop as soon as you have placed the clean object. Do not continue.

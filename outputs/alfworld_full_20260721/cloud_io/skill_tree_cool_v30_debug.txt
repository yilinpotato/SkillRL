# Goal: Cool an object and move it to a specified target location.

## Object Search and Retrieval

### Surface Search
- Start at **countertop** instances. Visit **every single countertop** one by one (do not skip any). For each, go to it and look at the objects listed. If the target object is present, take it and proceed to Phase 2.
- After **all** countertops have been checked, move to **diningtable** instances – visit every one.
- Then **sidetable** instances – every one.
- Then **shelf** instances – every one.
- Then **sinkbasin** instances – every one.
- Finally **stoveburner** instances – every one.
- **Strict order:** You must exhaust each surface type completely before moving to the next. Do not skip to a later type or to closed containers until all surface types have been fully searched.
- If you finish all surfaces and still have not found the object, proceed to Closed Container Search.

### Closed Container Search
- Only start this phase AFTER you have inspected every single instance of every surface type listed above and the object was not found.
- Search closed receptacles in this order:
  1. **fridge** (all instances)
  2. **cabinet** (all instances)
  3. **drawer** (all instances)
  4. **microwave** (all instances)
- For each category, visit **every single instance** without exception.
- For each instance: go to it, open it if closed, then look inside. If the target object is present, take it and proceed to Phase 2.
- Do not stop prematurely – continue until all categories and all instances have been checked.

## Phase 2: Cool the object using the fridge
- After picking up the object, go directly to the fridge.
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Phase 3: Move the cooled object to the target location
- Go to the target location.
- If the target receptacle is closed, open it first.
- Use `move <object> to <target>`.

## Completion check
- Object is cooled and placed at the target location – task complete.

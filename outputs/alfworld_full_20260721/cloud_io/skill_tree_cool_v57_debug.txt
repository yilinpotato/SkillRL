# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Systematic surface search
- Use the 'go to' action to move to each surface instance. After arriving, read the observation to see what is on that surface.
- First, check all countertops (every instance you saw in the initial look). If the target is not on any, proceed to check all diningtables, then sidetables, then shelves, then sinkbasins, then stoveburners, then the fridge (open it, look inside).
- For the fridge: if target found inside, take it and go to Phase 2. If not, close the fridge before moving on.
- **After finishing all surface types**, if the target is still missing, search inside containers:
  - Open each cabinet one by one, look inside. Take target if present, then close cabinet.
  - Then check each drawer (same process).
  - Then check the microwave (open, look inside).
- **Important**: Do not use the 'examine' action to check a location. You must be at the location to see its contents. 'examine' only shows a description, not the items on it.
- **Stay on track**: If you ever find yourself at a location that is not the next unvisited type in the search order above, return to the correct next type. Do not skip any type.

### Object verification
- Before taking, read the exact name. After taking, verify again. If wrong, put it back on the exact surface you took it from and resume searching from that location.

## Phase 2: Cool the object using the fridge
- As soon as you are carrying the correct target object, go to a fridge, open it (if closed), and use 'cool <object> with fridge'.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, garbagecan). If it is a closed container, open it first.
- Use 'move <object> to <target>'.

## Completion check
- The object is now cooled and placed at the target. Task complete.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle. Stop only when counter == 2 or after two exhaustive passes with no second object found.

## Critical Rules (Must Follow Immediately)
- **Counter:** Start at 0. After each placement, increment by 1. If counter == 1, you are in Phase 2. If counter == 2, task complete.
- **After placing the first object, immediately begin Phase 2 search.** Do not wander, explore unrelated items, or stop. The only valid stop after first placement is finding and placing the second.
- **Do not stop after taking or placing only one object.** Even if you took an object but haven't placed it, you must still place it first, then search for the second.
- **After every placement, re-read the initial room observation and rebuild a full ordered list of all furniture items (surfaces and containers).** This list is your search plan.

## Phase 1: Find and Place the First Object
1. Read the initial observation. Write down the **master list** of every furniture item in the order they appear. Include the target receptacle.
2. Visit each item on the master list **in exact order**.
3. For each item: if closed, open it. For surfaces (countertop, table, bed, sofa, etc.), simply observe the visible objects. For containers, open if closed and examine contents.
4. If you see an object whose exact name matches the required type, **take it immediately**. Then go to the target receptacle, open if needed, and place the object. Increment counter to 1.
5. If no matching object found, move to the next item. Do not revisit any item in this pass.
6. After placement, **immediately proceed to Phase 2** — do not inspect anything else.

## Phase 2: Find and Place the Second Object
1. **Re-read the initial room observation and rewrite the master list** from scratch. Include every furniture item again.
2. Visit every item **in exact order** again. Use the same inspect-take logic as Phase 1.
3. If you already saw a second matching object during Phase 1 (e.g., two together), return directly to that location. Otherwise, do a full systematic pass.
4. If you find the second object: take it, go to target receptacle, open if needed, place it. Increment counter to 2. Stop.
5. If you finish the entire list without finding the second object, **start a second full pass** from the top of the list. Do not stop after one pass.
6. Only after **two complete passes** with counter still at 1 may you conclude the task is impossible.

## Systematic Search Requirements
- The master list must include **all** furniture types: surfaces (countertop, table, bed, sofa, shelf) and containers (cabinet, drawer, fridge, dresser). Do not skip any category.
- For each item, perform correct inspection: surfaces need no opening; containers need opening if closed.
- After placing the first object, re-verify the list includes every item again. Do not assume you have seen everything.

## Failure Prevention (Avoid These Mistakes)
- **Premature stop after one placement:** After placing the first object, you must immediately begin Phase 2. If you catch yourself not searching, re-read the initial observation and restart Phase 2 from the first item.
- **Looping between a few locations:** If you revisit the same two or three items without taking a target object, you are in a loop. Stop, re-read the initial observation, rebuild the master list, and start Phase 2 from the first item.
- **Skipping furniture types:** The target object may be on a surface or inside a container. Stick to the master list order; do not only open drawers or only check surfaces.
- **Not opening the target receptacle before placing:** If it is closed (e.g., drawer, cabinet), open it first, then place.
- **Taking a wrong object:** Compare exact names. If you accidentally take a non-matching object, drop it from inventory and resume search from where you were.
- **Stopping after only one pass:** One full pass is not enough. Complete two passes before concluding impossibility.

## Loop Detection and Recovery
- If you catch yourself moving between the target receptacle and another location without having an object (or without placing), stop immediately. Re-read the initial observation, rebuild the master list, and restart Phase 2 from the first item.
- If you have opened several consecutive containers and all were empty, continue to the next furniture type from your master list—do not get stuck on one type.

## Stop Condition Verification
- After each placement action, immediately check counter. If counter == 1, begin Phase 2. Do not explore anything else until the second object is placed.
- Valid stop signals: counter == 2, or after two complete passes (Phase 2 done twice) with counter == 1 and no matching object found anywhere.

# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- Search the surfaces you can see at your current location for a desklamp. If you see one, note its location and move there if necessary.
- If no desklamp is visible, move to another surface receptacle (e.g., desk, dresser, sidetable, shelf, bed, etc.) and check its contents. Continue moving among receptacles until you find a desklamp.
- Once you are at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- Important: You may encounter the target object before finding the lamp. If that happens, remember where it is and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Phase 2: Locate and take the target object
- After the lamp is on, your next task is to find the target object. Do **not** waste actions on 'look' or exploring without moving – instead, systematically visit every receptacle you know about.

### Object name verification before picking
- When you read the observation at a receptacle, look carefully for the exact name of the target object (e.g., "box" not "tissuebox", "book" not "newspaper"). Do **not** take an object unless its name matches the task exactly. If you are unsure, re-read the task description. A mistake here means you will examine the wrong object and fail.

### Comprehensive Receptacle Search
1. **List all receptacles** from the initial room description. Write them down mentally (e.g., bed, desk, dresser, sidetable, coffeetable, shelf, drawer, cabinet, garbagecan, etc.). Every item you can go to is a receptacle.
2. **Start with the receptacle that holds the desklamp** – the target may be there. If not, take note of its location and continue.
3. **Visit every other receptacle in the order they appear in the initial description** (or any order as long as you cover each one exactly once). For each receptacle:
   - Go to it.
   - Read the observation.
   - If the target object's exact name appears among the items on the surface, take it (action: take <object> from <receptacle>).
   - If the target is not on the surface, check if this receptacle has any containers (e.g., a drawer built into a dresser). Open each such container and check its contents.
   - Note: Drawers listed separately in the initial description are independent receptacles. You will visit them as separate items in this list – do not skip them.
4. **After visiting all surface receptacles and opening all containers that are part of them**, proceed to any remaining free-standing containers (e.g., drawers, cabinets) that you have not yet visited. Go to each one, open it, and check its contents.
5. **Do not repeat receptacles** – once you have visited a receptacle (and opened any containers on it), move on. If you had already spotted the target object earlier, go directly to its location and take it.
6. **Exhaustive fallback**: If you have visited every receptacle from the initial list and opened every container, and the target is still missing, re-read the initial room description. You may have overlooked a container or a receptacle that was not initially listed (e.g., a safe, a cabinet, a drawer on a dresser). Go back and open every container you haven't opened, even if you think it's empty. Persistence is key – do not stop until the target is found.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required.
  (If you wish, you may use the examine action on the object, but it is not necessary for success.)

# Goal: Cool an object and move it to a specified target location.

## Sub-goal 1: Find the object to cool.
- The target object is not yet in your inventory. You must locate it by searching all receptacles in the room.

### Immediately check the fridge for cooling tasks
- Because the goal involves cooling, the target object is often stored in the fridge. Before searching many cabinets, go to the fridge and check its contents (open it if closed).
- If the target is not in the fridge, then proceed to systematically check all other receptacles.

### Systematic Inspection Protocol (mandatory steps)
- List every receptacle from the initial room description. Note that there may be multiple instances of the same type (e.g., countertop 1, countertop 2, diningtable, sidetable, shelf, etc.). Visit each one without skipping any.
- **Priority order**: First, check all open flat surfaces (countertops, tables, shelves, sidetables) because they are visible and often contain the target. Then check closed receptacles (cabinets, drawers, microwave, etc.) one by one.
- For each receptacle:
  1. Go to it.
  2. If it is closed (e.g., cabinet, drawer, fridge, microwave), immediately open it using `open <receptacle>`.
  3. After opening (or if already open), look at its contents. The observation will list items on/in it.
  4. If the target object is present, take it right away using `take <object> from <location>`. Do not move to the next receptacle until you have taken it.
  5. If the target is not present, move on to the next receptacle without lingering. Do not use extra actions like 'look' or 'examine' – they waste steps.
- Do not assume the target is missing after checking only a few locations. Continue until you have visited every receptacle.

### Prioritize pickup of visible target
- When you arrive at any location (countertop, sinkbasin, etc.), immediately check the observation text for the target object's name. If it is present, take it right away before moving elsewhere.

## Sub-goal 2: Take the object.
- Once you see the object, use `take <object> from <location>` (e.g., `take bread 2 from countertop 2`).
- Confirm you are holding it (the action response will say "You pick up the ...").

## Sub-goal 3: Cool the object using the fridge.
- Go to the fridge (if not already there).
- If the fridge is closed, open it.
- Then use `cool <object> with fridge` (e.g., `cool bread 2 with fridge 1`).
- The response will confirm the object has been cooled.

## Sub-goal 4: Move the cooled object to the target location.
- Go to the target location named in the task (e.g., diningtable, cabinet, microwave, countertop).
- Use `move <object> to <target>` (e.g., `move bread 2 to diningtable 1`).
- The response will confirm the object is placed.

## Completion check:
- The task is complete when the object has been cooled and placed at the target location.
- If you have done all steps, the environment may not give explicit success feedback; trust the sequence.

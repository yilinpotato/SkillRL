# pick_two_obj_and_place

## Goal
- Place exactly two instances of a specific object into a specified target receptacle.

## Procedure (step-by-step algorithm)
1. **Identify task**: Note the required object type (e.g., newspaper) and the target receptacle (e.g., sofa).
2. **Initial exploration**: Read the room description and list every furniture item. For each closed container (drawer, cabinet, safe, fridge, etc.), open it immediately. Do not assume any container is empty.
3. **First object search**: Visit each furniture item from your list exactly once. For each item:
   - Go to it.
   - If it is a container and is closed, open it.
   - Examine its contents (on surfaces or inside).
   - If you see an object whose exact name matches the required type, take it. Then go directly to step 4.
   - If not, move to the next item on the list.
   - After visiting all items, if you still have not found the object, you may re-visit items (objects may have been moved by earlier actions).
4. **Place the first object**: Go directly to the target receptacle. Immediately use the action "move <object> to <target>". Do not perform any other actions (look, inventory, move elsewhere) before moving.
5. **Second object search**: **You are not done.** Reset your mental list of furniture items and repeat step 3 exactly. Do not assume the second object is in the same type of location as the first — check all furniture types.
6. **Place the second object**: Use the same sequence as step 4. After moving, the environment will indicate success.

## Critical warnings (avoid these failures)
- **Insufficient search**: You must visit every furniture item on your list. Checking only a few items (e.g., only sidetables or only drawers) will cause failure. If you find yourself revisiting the same type repeatedly, stop and check a different type.
- **Premature stop**: After placing the first object, immediately begin searching for the second. Do not rest or assume the task is done.
- **Not opening containers**: Always use "open" before looking inside. The action "examine" does not open containers.
- **Wrong object identity**: Before taking any object, verify its exact name against the required type. Do not take if there is any mismatch.
- **Intervening actions**: When you are at the target receptacle with the correct object in hand, issue the move action immediately. Any delay (looking, inventory, going elsewhere) wastes steps and leads to failure.

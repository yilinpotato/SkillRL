# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is typically the microwave.

## 2. Locate the object
- Search systematically across all receptacles you can see.
- List all visible receptacles in the current room (e.g., countertop, sidetable, diningtable, shelf, cabinet, drawer, fridge, garbagecan, sinkbasin, etc.).
- Prioritize likely locations based on object type:
  - Food items (e.g., tomato, egg, apple, lettuce, bread) are often stored in the fridge.
  - Non-food items (e.g., cup, mug, bowl, plate) may be in cabinets, drawers, or on countertops.
- Start with the fridge (go there, open it, check contents). If object is inside, take it.
- If not found, check each countertop (go to each, look at its contents).
- Then check shelves, sidetables, diningtables, and other flat surfaces.
- Then check cabinets and drawers (open each, look inside).
- Do not skip any receptacle; use 'look' to see what is in the room if you lose track.
- ### Complete Systematic Search: If you have checked every receptacle you see and still not found the object, perform a 'look' action to refresh the list of all receptacles, then continue searching each one you haven't visited. Do not stop until you have found the object or exhausted all receptacles.

## 3. Heat the object
- Once you have the object in inventory, go to the microwave.
- Open the microwave.
- Move the object from inventory into the microwave (action: 'move <object> to microwave').
- Close the microwave to start heating.
- Open the microwave again; the object is now heated.
- Take the heated object from the microwave (action: 'take <object> from microwave').
- ### Do Not Stop After Heating: After taking the heated object, immediately proceed to place it in the target location. Do not perform any other actions (e.g., go elsewhere, examine) until placement is complete.

## 4. Place the heated object in the target location
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, sidetable, coffeemachine, etc.).
- ### Different Destination Requirement: Ensure the target receptacle is different from the source receptacle where the object originally came from. Returning the object to its original location is not a valid placement.
- If the receptacle is a container that can be opened (e.g., cabinet, fridge, drawer, garbagecan, etc.), open it first.
- Put the object into/onto the receptacle (action: 'move <object> to <receptacle>').
- ### Post-Placement Verification: After the move, check your inventory (it should be empty) and examine the target to confirm the object is there. If not, try again or consider if the receptacle is closed.

## 5. Completion check and termination
- Once you have placed the heated object at the target location, **do not pick it up again**. Resist any impulse to take it back.
- ### Terminate after placing at target: After a successful placement, stop all actions. Do not go back to the microwave or any other location.
- ### If you are unsure, perform a final verification: check inventory (should be empty) and examine the target to see the object. If it is there, the task is complete.
- Do not continue searching, heating, or moving the object.

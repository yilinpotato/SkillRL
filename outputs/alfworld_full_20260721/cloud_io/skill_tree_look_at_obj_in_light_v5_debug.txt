# Goal: Examine a target object using a light source (e.g., desklamp)

## Phase 1: Locate the light source
- Identify a desklamp from the objects visible on surfaces in your current location. If you see a desklamp, note its receptacle.
- If no desklamp is visible at your current location, systematically search all receptacles you observed in the initial room description.
  ### Systematic search for desklamp
  - List each receptacle (e.g., desk, dresser, sidetable, shelf, bed, etc.) from the room description.
  - Move to each receptacle (action: go to <receptacle>) and examine its contents.
  - Stop as soon as you find a desklamp. That receptacle is now the lamp's location.
- Once you know a receptacle that contains a desklamp, move there if not already present.

## Phase 2: Turn on the light
- Ensure you are at the same receptacle as the desklamp (if not already, go there).
- Use the desklamp (action: use desklamp <number>). The observation will confirm: "You turn on the desklamp".
- The light is now on. This precondition must be satisfied before examining the target object.

## Phase 3: Locate the target object
- After turning on the lamp, first check the lamp's receptacle for the target object. If present, proceed to Phase 4.
- If not, recall the initial room description (the first observation) and list every receptacle it mentioned (e.g., bed, desk, dresser, sidetable, shelf, armchair, sofa, etc.). Do not rely on memory of what you have already seen; use the full list.
  ### Search all desks and shelves for target
  - Include all surface types from the initial list: desks, shelves, sidetables, dressers, cabinets, etc. Do **not** restrict your search to only one type (e.g., only shelves).
  - If you have visited several similar receptacles (like multiple shelves) without success, pause and re-check the initial description for any surfaces you may have omitted (e.g., a desk that was mentioned).
  - Exclude the lamp's receptacle (already checked). Then visit each remaining receptacle in any order. For each, use the 'go to <receptacle>' action and examine its contents.
- If you find the target object on any receptacle, proceed to Phase 4.
- After visiting all listed receptacles (surfaces) and not finding the target, then and only then consider opening closed containers (drawers, cabinets, etc.). For each closed container, go to it, open it, and examine its contents.
- If you have exhausted all containers without success, you may have missed a receptacle; re-check the initial description for any receptacles you omitted.

## Phase 4: Take and examine the target object
- Take the target object from its receptacle (action: take <object> from <receptacle>).
- The task is considered complete once the object is in your inventory and the light is on.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Object Manipulation / Pick Object
- **Before taking any object, confirm its name matches the task target exactly.** Do not pick up similar objects (e.g., towel vs cloth, pan vs pot). Only the exact match can be cleaned and placed.
- Once verified, take the object (e.g., `take [object] from [receptacle]`).
- If you are already holding an object and it is not the target, put it down before searching for the correct one.

### Object Type Check
- Compare the object name as shown in the observation (e.g., "cloth", "knife", "kettle") against the target object from the task.
- If they are identical, proceed to take it. If they differ — even slightly — do not take it. Continue searching.
- Do not rely on functional similarity; only exact string match is acceptable.

## Exploration / Search Strategy
### Search Phase (until you are holding the target object)
- **You are in the search phase until you are holding the correct target object.** Do not attempt to clean until you have the object.
- **First, extract all open receptacles from the initial room description.** The initial description lists every receptacle present. Open receptacles include: countertops, diningtables, sidetables, shelves, sinkbasins, bathtubbasins, stoveburners, toilets, garbage cans, carts, handtowel holders, towel holders, and any other receptacle you see. Sinkbasins and bathtubbasins are normal open receptacles for searching – ignore any earlier instruction that told you to avoid them during search. That was a mistake.
- **Go to each individual receptacle instance listed in the initial description.** For example, if the description says "stoveburner 4, stoveburner 3, stoveburner 2, stoveburner 1", you must visit stoveburner 1, then 2, then 3, then 4. Do not skip any instance because you think it might be empty or because you already checked a similar one. Every instance is a separate search location.
- Inspect the contents of each open receptacle. Do not skip any.
- Only after you have checked **all** open receptacle instances from the initial description and the target object is not found, proceed to closed containers.

### Systematic Container Search
- If the object was not on any open surface, systematically check every closed container you observed in the initial description. The recommended order:
  1. All cabinets – go to each, open, inspect.
  2. All drawers – go to each, open, inspect.
  3. Fridge (if present) – go to it, open, inspect.
  4. Microwave (if present) – go to it, open, inspect.
- **Do not return to open surfaces or any other location until you have examined every closed container.**
- After exhausting all closed containers, if the object is still missing, re-read the initial description to ensure you did not overlook any receptacle.

### Object-Specific Location Priors (hints, not constraints)
- Pots, pans, kettles, and cookware are often on stoveburners, but also on countertops or in cabinets.
- Food items (lettuce, tomato, apple, potato, etc.) frequently appear on diningtables, countertops, or in the fridge.
- Utensils (knife, fork, spoon, ladle) are commonly on countertops, diningtables, or in drawers.
- Cleaning items (soapbar, sponge, dishsponge) may be near sinkbasins, on countertops, on shelves, or in cabinets.
- Dishes and bowls can be in cabinets or on open surfaces.
- Use these as guides, but always check all surfaces first.

## Phase 2: Clean the Object
- **Before walking to the cleaning source, confirm you are holding exactly the target object.** If you are empty-handed, you are in the wrong phase – go back to searching.
- While holding [object], go to [cleaning_source] (sinkbasin or bathtubbasin).
- Use `clean [object] with [cleaning_source]`.
- Confirm the observation says you cleaned it.

## Phase 3: Place the Clean Object at Destination
- Go to the [destination] specified in the task.
- If the destination is a closed container (e.g., microwave, fridge), open it first, then place the object inside.
- Use `move [object] to [destination]` to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

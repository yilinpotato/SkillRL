# pick_and_place skill tree

## Goal
Pick up a specific object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search every visible receptacle systematically.
3. **Verify and take** – only take the object if its type matches the task (ignore numerals).
4. **Navigate to target receptacle** and move the object there.
5. **Terminate** after placement.

## Systematic Search for Target Object (mandatory)
### Complete Receptacle Check
- From the initial observation, **mentally list every receptacle name exactly as shown** (all furniture, containers, surfaces). This is your master checklist.
- Visit each receptacle on your list exactly once before concluding. You may choose any order, but **do not skip any**.
- For each receptacle:
  - `go to <receptacle>`.
  - If it is closed (drawer, cabinet, safe, fridge, microwave, oven, dishwasher, etc.), first `open <receptacle>`, then read its contents.
  - If the target object is present, immediately `take <object> from <receptacle>`. Do nothing else first.
  - Tick it off your mental list.
- After visiting every receptacle on your list and not finding the object, **repeat the entire list again**. The object is always somewhere; keep searching until found.

### Search Order to Save Time
- **Check surfaces first** (tables, countertops, shelves, armchairs, sofas, dressers, beds, bathtubs, toilets, etc.) before opening closed containers.
- After all surfaces, open each drawer and cabinet systematically. Then check other closed containers like fridge, microwave, oven, dishwasher.

### Common Mistakes to Avoid
- **Skipping any receptacle** – all must be inspected, including beds, dressers, desks, countertops, shelving, drawers, cabinets, sinks, bathtubs, toilets, sofas, etc.
- **Using wrong actions** – never `examine` or `look`; use `go to` to move, `open`/`close` for containers.
- **Taking wrong object** – verify the object's type matches the task exactly (base noun level; ignore numerals).
- **Stopping early** – only stop after you have checked every receptacle on your initial list (and repeated if needed) and still not found the object. The object will be found; keep searching.

## Object Acquisition
Once you locate an object whose type matches the target, immediately `take <object> from <receptacle>`. Do not perform any other action first.

### Object Type Verification
- Compare the object's name (as shown in observation) with the target object type from the task. They must match at the base noun level (e.g., "glassbottle" vs. "winebottle" are different). Ignore numerals (e.g., "book 2" matches "book").

## Placement
After taking the object, go to the target receptacle and `move <object> to <receptacle>` (or `open <receptacle>` first if it is closed). Then terminate.

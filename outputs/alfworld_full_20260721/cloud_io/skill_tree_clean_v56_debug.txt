# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
- You may go to sinkbasin or bathtubbasin to search for the target object. If the target object is there, pick it up. Once you are holding it, you can clean it immediately using the same sinkbasin/bathtubbasin. Do not go to the sinkbasin solely to clean until you are holding the object.
- Do not go to the destination receptacle until after cleaning.
- **Once you are holding the target object, do not put it down or interact with any other object until after you have cleaned it and placed it at the destination.**
- If you are already holding something that is not the target, put it down immediately.
- After arriving at the cleaning source, perform the clean action immediately – do not examine, look, or inventory before cleaning.
- Before picking any object, confirm its name matches the target exactly. Do not pick similar-named objects.

## Object Search (Phase 1)
### Initial Look
- Immediately after the first observation (or any time you need to refresh), use `look` to get the full room description. Make a mental list of **all receptacles** (both open surfaces and closed containers).

### Open Surface Search
1. Identify all open surfaces from the room description (e.g., countertops, diningtable, stoveburners, shelves, sinkbasin, bathtubbasin, garbagecan, handtowelholder, towelholder, carts, etc.).
2. Visit **each open surface exactly once** in any order. At each, examine contents. If the target is present (verify name), pick it up and go to Phase 2.
3. **After visiting the last open surface, if the target was not found, you must immediately and without exception proceed to the first closed container. Do not revisit any open surface, even if you think you missed something. Do not wander.**
4. Mentally check off each open surface as you go. Never go back to a checked open surface.

### Closed Container Search
1. Closed containers include: cabinets, drawers, fridge, microwave, oven, etc. Any receptacle that is not an open surface (look for words like "cabinet", "drawer", "fridge", "microwave", "oven").
2. **Order for non-food targets:** all cabinets (numerical order), then drawers, then fridge, then microwave, oven, etc. For food targets (lettuce, potato, tomato, apple, bread, egg, etc.), go to fridge first, then cabinets, drawers, etc.
3. **At each closed container:** Immediately open it using `open [container]`. Do not look, examine, or move away first. After opening, look inside. If the target is inside, take it and go to Phase 2. If not, close it (if needed) and move to the next container in order.
4. **You must open and look inside every single closed container listed in the room description.** Do not skip any. If you are unsure which remain, use `look` again.
5. After checking all closed containers without finding the target, **repeat the entire search cycle from open surfaces again** (rare but possible).

### Prevent Revisiting Trap
- **If you ever arrive at a receptacle you have already visited (either open or closed), you have made a mistake.** Stop immediately. Use `look` to refresh your list, then go to the next unchecked closed container (if any remain) or the next unchecked open surface only if all closed containers have been exhausted. Never revisit an open surface before finishing all closed containers.

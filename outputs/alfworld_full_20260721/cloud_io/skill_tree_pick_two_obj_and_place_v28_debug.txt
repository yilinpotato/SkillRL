# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

### Critical Rule (Overrides All Others)
- **After taking any matching object, immediately go to the target and place it. Do not take any other action (including searching for the second object) until this placement is complete.**
- You need exactly two placed objects. After first placement, mental counter = 1. Then restart search for the second. Never stop at counter = 1.

### Multi-Object Collection Protocol
- You must collect and place two objects. After placing the first, immediately begin a second search. Do **not** wander or explore unrelated items.
- If during the first search you saw a second matching object at the same location (e.g., on same countertop or inside same open container), return directly there and take it.
- Otherwise, perform a full systematic search (see Persistent Search Loop) again.

### Persistent Search Loop (Repeat Until Two Placed)
This loop is your core control flow. Run it once for the first object, then immediately repeat it for the second.

#### Step 1: Create Master List
- After the initial room description, **write down every furniture item** exactly as listed (e.g., cabinet 3, countertop 1, sinkbasin 1). This is your checklist. Do not miss any item.

#### Step 2: Visit Each Furniture Item Systematically
- Pick any unvisited item from your master list. Go to it.
- If it is closed (drawer, cabinet, fridge, etc.), **open it**.
- **Examine its contents** (inside if container, on top if surface).
- If you see an object whose exact name matches the required type, **take it immediately**.
- Check off that item as visited.
- Repeat for every item on the list. Do not skip any even if you already found one object; you need to find all possible sources.

#### Step 3: Immediate Placement
- With a matching object in hand, go directly to the target receptacle and use `move <object> to <target>` immediately. **No other actions in between.**
- After placing, increment your mental counter. (After first placement, counter=1; after second, counter=2.)

#### Step 4: Second Object Search (Critical)
- **After placing the first object, you must immediately begin the Persistent Search Loop again.**
- If you earlier observed a second matching object at the same location (e.g., on the same countertop or inside the same open container), go directly back to that location and take it.
- If you did not notice a second object at any visited location, **execute Step 1 and Step 2 again from scratch**, including reopening all previously opened containers.
- Do not stop after visiting only a few items. You must visit **every** furniture item on your master list again (a second complete pass).
- If after a full second pass you still find only one object, the task may be impossible – but do not give up before finishing both passes. If counter is still 1 after both passes, you may stop (task likely impossible).

### Common Failure Patterns (Avoid These)
- **Premature stop after taking first object without placing it**: You must place it immediately before doing anything else.
- **Stopping after first placement**: Immediately restart the loop. Do not wander or explore unrelated items.
- **Incomplete master list**: Omitting any furniture item leads to missing objects. Ensure you list every item from the initial observation.
- **Not reopening containers during second pass**: New objects may appear inside.
- **Stopping early due to frustration**: Complete at least two full passes before concluding impossibility.
- **Picking wrong object**: Verify exact name before taking.
- **Skipping surfaces (countertops, sidetables, etc.)**: Visit every furniture item in the master list, including surfaces. Do not assume an object is only inside containers.

### Exact Type Matching Reminder
Before taking any object, compare its exact name to the required type. Only take exact matches. Ignore objects with similar names (e.g., soapbottle vs soapbar).

## 1. Interpret the task

## 2. Locate the object
### Search Strategy for Heat Tasks
- Perform a **complete systematic search** of every receptacle in the current room. Do not stop after checking only a few items.
- **Required order** (do not skip any step; after each step, if the object is not found, proceed immediately to the next):
  1. **Fridge**: go to it, open, look inside. Take the target object if present. Close after.
  2. **All countertops**: go to each one, look at contents, take if found.
  3. **All other flat surfaces**: sidetables, diningtables, shelves – go to each, look.
  4. **All cabinets**: open each cabinet, look inside. Do not skip any.
  5. **All drawers**: open every drawer individually and look inside. Drawers are a frequent location for small objects (mugs, cups, etc.).
  6. **Garbagecan**: open and look inside.
  7. **Sinkbasin**: open and look inside.
  8. **Microwave**: open it and look inside – it can contain objects even though it is the heating appliance.
  9. **Any other openable container** (e.g., coffeemachine): open and look.
- After completing the full list, if still not found, do a `look` action to refresh the room description. If new receptacles appear, repeat the entire sequence from step 1. Otherwise, re-read the task to confirm the object type.
- **Persistence rule**: Do not assume an object is missing until you have opened every drawer, the sinkbasin, the garbagecan, and the microwave. Many failures occur because the agent stops after cabinets without checking these critical spots.

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If direct heat fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to section 2 (Locate the object) and perform the full exhaustive search again.

## 4. Place the heated object
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, etc.).
- The destination must be different from the source where the object originally came from.
- If the target receptacle is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: `move <object> to <receptacle>`.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (`examine <receptacle>`) and check inventory (`inventory`). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- **Termination rule**: Once placed at the target, stop all actions immediately.

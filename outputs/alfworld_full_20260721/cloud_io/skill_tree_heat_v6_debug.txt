# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is typically the microwave.

## 2. Locate the object
- Start with a 'look' action to see all receptacles in the room. Write down every receptacle name you see.
- Systematically check each receptacle in this order:
  1. Fridge (go, open, look inside). If object is there, take it.
  2. Countertops (go to each, look at contents, take object if present).
  3. Sidetables, diningtables, shelves, and other flat surfaces (check each).
  4. Cabinets, drawers, garbagecan, sinkbasin, and other containers (open each, look inside).
- If you have checked every receptacle you saw initially and still haven't found the object, perform a 'look' again to refresh the list. New receptacles may appear (e.g., coffee machine, dresser). Continue searching any you missed.
- Do not skip any receptacle. If you lose track of what you have visited, use 'look' and recount.

## 3. Heat the object
- Once the object is in your inventory, go to the microwave.
- Open the microwave.
- Move the object from inventory into the microwave (action: 'move <object> to microwave').
- Close the microwave.
- **Now open the microwave again.**
- **Take the object out of the microwave** (action: 'take <object> from microwave').  
  Do not try to heat the object while it is still inside — that does not work.
- **Heat the object while holding it**: perform action 'heat <object> with microwave'. This is required; closing alone does not heat it.
- **Do not move the object back into the microwave after taking it out.** Move directly to the target location after heating.
- *If you ever find yourself holding the object after heating, proceed immediately to the target location.*

## 4. Place the heated object in the target location
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, sidetable, coffeemachine, etc.).
- **Destination must be different** from the source receptacle where the object originally came from. Returning the object to its original location is invalid.
- If the receptacle is a container that can be opened (e.g., cabinet, fridge, drawer, garbagecan), open it first.
- Put the object into/onto the receptacle (action: 'move <object> to <receptacle>').
- **Critical: Do not take the object back after placing it. Stop.**

## 5. Completion check and termination
- After placing the object, verify that it is at the target: examine the receptacle (action: 'examine <receptacle>') and check your inventory (action: 'inventory'). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, **the task is complete. Do not perform any further actions.**
- Resist any impulse to pick up the object again. If you ever find yourself holding the object after having placed it, that is a mistake — do not continue; stop and end the episode.
- **Termination rule**: Once placed at the target, stop all actions immediately. No more moving, heating, or searching.

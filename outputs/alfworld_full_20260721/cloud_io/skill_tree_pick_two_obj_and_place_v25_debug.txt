# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

## Systematic Search Procedure (Repeat for Each Object)
### Master List Creation
1. Immediately after the initial room description appears, **write down every furniture item** exactly as listed (e.g., cabinet 3, countertop 1, handtowelholder 2, sinkbasin 1, etc.). Do not omit any item.
2. This master list is your checklist for all searches. Keep it in memory throughout the task.

### Visiting Each Item
1. Pick any item from the master list. Go to it.
2. If it is closed (drawer, cabinet, fridge, microwave, etc.), **open it**.
3. **Examine its contents** (inside if a container, on top if a surface).
4. If you see an object whose exact name matches the required type, **take it** immediately. Do not take non-exact matches.
5. **Check off** that item as visited so you know you have not missed any.
6. Repeat for every item on the list. Do not skip any, even if you already found one object. You need to find all possible sources.

### Exact Type Matching
- Before taking any object, compare its exact name to the required type. Only take exact matches.

### Object Identification Check
- Before executing any `take` action, mentally verify that the object's name exactly matches the target type. 
- If the name differs (e.g., `soapbottle` vs `soapbar`, `towel` vs `toiletpaper`), do not take it.
- If you are unsure, re-read the task description and compare character by character.

## Placement
- With a matching object in hand, go directly to the target receptacle and use `move <object> to <target>` immediately. No other actions in between.

## Repeat Until Complete
- After placing an object, **immediately restart the search for the second object**. Do not wander or explore unrelated items.
- If you earlier observed a second matching object at the same location (e.g., on the same countertop or inside the same open container), go directly back to that location and take it.
- If you did not notice a second object at any visited location, **perform the full Systematic Search Procedure again**, including reopening all previously opened containers.
- Keep a counter: after first placement, set counter=1; after second, set counter=2 and stop.
- Do not stop before counter=2, even if you think you have searched everywhere. Only stop after placing the second object or after confirming every item on the list (twice) contains no second match.

### Iterative Object Retrieval
- After placing the first object, your immediate next action must be to return to the location where you found that object (if you saw another copy there) or to the next likely source. Do not start exploring new furniture unless you have exhausted that immediate source.

### Post-Placement Search for Second Object
- If the immediate source does not yield the second object, systematically visit every furniture item on your master list again, including those you already checked. Reopen all containers that you opened before (they may now contain the second object).

### Container Search for Second Object
- When searching for a second object after placement, **prioritize closed containers** (drawers, cabinets, etc.) that you have not yet opened or that you opened but did not fully inspect. Objects can be hidden inside.

### Object Counting and Completion Check
- Maintain a mental counter of how many objects you have placed. After each placement, increment the counter. If counter < 2, you must continue searching. If counter == 2, you are done.
- Do not assume that because you have visited every item once, the task is impossible. You may need to revisit items or open previously closed containers a second time.

## Common Failure Patterns (Avoid These)
- **Premature stop**: Placing one object and not continuing. Always perform the systematic search again immediately.
- **Incomplete master list**: Omitting any furniture item from the initial list leads to missing objects. Every item in the initial observation must be included.
- **Not reopening containers**: After placing the first object, re-open every closed container you previously opened. New objects can be inside.
- **Stopping early due to frustration**: Even if you have visited all items and found only one, the task may be impossible. But do not give up before two complete passes.
- **Wrong object taken**: Always verify the exact name before taking. Taking a wrong object wastes time and can lead to task failure.

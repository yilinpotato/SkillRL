# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Surface Search Order – strictly follow this sequence
1. **Countertops** – check every countertop instance (e.g., countertop 1, 2, 3, ...) before moving to the next type.
2. **Diningtables** – check every diningtable.
3. **Sidetables** – check every sidetable.
4. **Shelves** – check every shelf.
5. **Sinkbasins** – check every sinkbasin.
6. **Stoveburners** – check every stoveburner.

- **At each location**, read the observation. If the target object is present, **take it immediately** and go to Phase 2.
- **Never skip a surface type.** If you have not visited every surface type above, you are NOT done. Do NOT move to containers until all surface types are exhausted.
- **Keep a mental list** of every location you have visited (e.g., countertop 1, countertop 2, ...). Do NOT revisit a location unless you are backtracking later.
- **If you find yourself at a container before finishing surfaces, that is a mistake.** Immediately return to the next unvisited surface type.

### Closed Container Search – only after all surfaces are exhausted
- After you have checked every surface type above and still not found the object, you **must** search closed containers. Do NOT go back to surfaces before checking all containers.
- Search containers in this exact order. For each type, check every instance:
1. **Fridge** – for each fridge instance:
   - If the fridge is closed, **must open it** (use `open fridge <instance>`).
   - Look inside. If the target object is present, **take it** and go to Phase 2.
   - If not present, **close the fridge** and move to the next container type.
2. **Cabinet** – for each cabinet instance: open, look, if target present take it; if not, close and move to next cabinet.
3. **Drawer** – same process.
4. **Microwave** – same process.

- **Critical: You must open every container to see its contents.** Simply arriving at a container and using `look` does NOT reveal what is inside if it is closed. Always open first.
- After finishing all containers and still not finding the object, **backtrack through the surface list again** – you may have missed a location earlier.

### Object Verification Rule
- Before taking any object, **carefully read its exact name** from the observation (e.g., "potato 2", not just "potato"). Only take an object whose name matches the target object type exactly. If you see a similar object with a different name, leave it and continue searching.
- **If you are already carrying an object that does not match the task**, put it down immediately (use `put <object> on <surface>`) and resume searching. Do not proceed to cooling with a wrong object.

## Phase 2: Cool the object using the fridge

### Immediate Cooling Action
- As soon as you have taken the target object, your next action **MUST** be to go to a fridge, open it (if closed), and use `cool <object> with fridge`.
- **Do NOT examine the object, move anywhere else, or perform any other action in between.** Any detour (e.g., looking, moving to another room) is a failure.
- If you are not carrying the object, go back to Phase 1.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, microwave).
- If the target is a closed container (like a microwave or cabinet), open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

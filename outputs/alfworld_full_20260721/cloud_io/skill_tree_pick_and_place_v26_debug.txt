# pick_and_place skill tree

## Goal
Pick up a specific object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search every visible receptacle systematically.
3. **Verify and take** – only take the object if its type matches the task (ignore numerals).
4. **Navigate to target receptacle** and move the object there.
5. **Terminate** after placement.

## Object Search – Mandatory Systematic Inspection
### Critical Rule: You must visit every receptacle in the initial observation exactly once before concluding the object is missing. Do not skip any, even if it seems unlikely.
1. From the first room observation, **mentally list every receptacle name** exactly as it appears (all furniture, containers, surfaces). This is your master checklist.
2. **Start your search.** For each receptacle on your list:
   - Go to it: `go to <receptacle>`.
   - If it is closed (e.g., drawer, cabinet, safe, fridge, microwave, oven, dishwasher), first `open <receptacle>`, then read contents.
   - If the target object is present, immediately `take <object> from <receptacle>`. Do not perform any other action first.
   - Tick it off your mental list.
3. **If you finish the list and did not find the object, repeat the entire process starting from the first receptacle again** – do not give up. Re-read the initial observation to ensure you did not miss any receptacle.

### Common Mistakes
- **Skipping any receptacle** – all must be inspected, including tables, chairs, shelves, drawers, cabinets, sinks, bathtubs, toilets, etc.
- **Focusing only on one type** – e.g., only shelves or only closed containers. You must check every type.
- **Using wrong action** – never `examine` or `look` to move; use `go to`.
- **Taking wrong object** – verify the object's type matches the task exactly (ignore numerals).
- **Forgetting to open closed containers** before reading their contents.
- **Stopping early** – only stop after you have checked every receptacle (and repeated if necessary) and still not found the object. But in this environment the object will be found; keep searching until you find it.

## Object Acquisition
Once you locate an object whose type matches the target, immediately `take <object> from <receptacle>`. Do not perform any other action first.

## Placement
After taking the object, go to the target receptacle and `move <object> to <receptacle>` (or `open <receptacle>` first if it is closed). Then terminate.

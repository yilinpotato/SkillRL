# pick_and_place skill tree

## Goal
You must pick up a specific object and place it into or onto a specified receptacle. The task description states both the object and the target (e.g., "put a book in sofa").

## Sub-Goal Flow
### 1. Parse the task
Identify two entities: the **target object** (what to pick) and the **target receptacle** (where to place it). Keep these in mind throughout.

### 2. Locate the target object
#### 2.1 List all receptacles
- **Use ONLY the initial room observation** to create your list of receptacles. The very first observation after "Your task is to: ..." shows every receptacle in the room. Write down every name exactly as it appears. Do **not** add any receptacles that you encounter later (e.g., sidetables not mentioned initially). That initial list is your complete search set.
- Include ALL types: cabinets, drawers, shelves, tables, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubbasins, handtowelholders, towelholders, toilet, toiletpaperhanger, garbagecan, beds, and any other furniture mentioned. **Include the target receptacle itself** – the object might already be on it.
- Common overlooked receptacles: desks, dressers, armchairs, beds, sidetables, tvstands, countertops, sinkbasins, bathtubbasins, handtowelholders, toilet, garbagecan. Make sure you list every one you see.

#### 2.2 Execute a prioritized search
- Create a mental queue of all receptacles from step 2.1. Visit them in the following order to find the object faster:
  1. **Target receptacle** – the object might already be on it. Go there first.
  2. **Other open surfaces** – tables, desks, shelves, countertops, beds, armchairs, sofas, sidetables, etc. These are visible without opening.
  3. **Closed containers** – drawers, cabinets, safes, fridges, etc. Open each before examining.
  Within each category, any order is fine.
- For each receptacle:
  - Go to it (`go to <receptacle>`).
  - If closed, open it (`open <receptacle>`) before examining.
  - Read the observation. It lists objects inside or on the receptacle.
  - If you see the target object, use `take <object> from <receptacle>`. Then proceed immediately to step 3 (placement). **Do not continue searching.**
  - If not found, mark the receptacle as checked and move to the next.
- If you have visited every receptacle on your list (in the priority order) and still not found the object, re-read the initial room observation to ensure you didn't miss any.
- **Do not** wander to receptacles that were not on your initial list.

#### 2.3 Use object type to guess likely locations
- Some objects are more commonly found in certain types of receptacles. Use this knowledge to narrow your search, but do **not** skip any receptacle entirely – if your initial guess fails, continue searching all.
  - **Electronics** (cellphone, alarm clock, laptop, tablet): often on desks, shelves, tables, or dressers.
  - **Utensils** (butterknife, spoon, fork, knife): typically in drawers or cabinets.
  - **Toiletries** (toiletpaper, soap, spraybottle, toothpaste): usually in bathroom cabinets, drawers, or near sinks, toilet paper hanger, towel holder.
  - **Clothing** (towel, cloth, handtowel): on towel holders, laundry hamper, beds, dressers.
  - **Paper/office** (book, cd, creditcard, pen, pencil, keychain): anywhere – surfaces, drawers, shelves.
- When you begin searching, start with categories that match the object's type, then proceed to the others. This reduces search steps.

### 3. Verify and pick up
- Before picking up any object, **confirm that its name exactly matches the target object** (e.g., if task says "cloth", do not pick "handtowel"; if task says "spraybottle", do not pick "soapbottle"). If there is any mismatch, do not take it.
- **Exact match is required** – synonyms are not acceptable. For example, "handtowel" is not "cloth", "towel" is not "cloth", "soapbar" is not "soapbottle", "winebottle" is not "glassbottle". When in doubt, re-read the task description and the observed object name.
- Once confirmed, use `take <object> from <receptacle>` to pick it up.
- If you are already carrying something else and it is not the target, you may drop it (not typical, but avoid carrying wrong items).

### 4. Navigate to the target receptacle
- After successfully picking up the target object, move to the target receptacle (e.g., "sofa 1", "toilet 1", "garbagecan 1") using `go to <receptacle>`.

### 5. Place the object
- When you arrive at the target receptacle, immediately execute `move <object> to <receptacle>`.
- Do **not** perform any other actions (like examining or going away) before placing; placing is the final required action.

### 6. Termination
- After the `move` action, the task is complete. No further actions are needed.

## Common Mistakes to Avoid
- **Wrong object pickup:** Always re-verify the object name in the observation before using `take`. Never take an object unless its name is an exact match.
- **Incomplete search:** Do not skip any receptacle type or instance. The target object may be on any surface, in any drawer, or inside any cabinet. Check all furniture listed in the initial room observation – including desks, dressers, beds, armchairs, and other surfaces often missed.
- **Skipping the target receptacle as a search location:** The object might already be on the target receptacle. Always check it first (per the prioritized order).
- **Not using object type to prioritize:** If the object is a utensil, focus on drawers and cabinets; if an electronic, check desks and shelves first. This speeds up search and prevents overlooking likely containers.
- **Using receptacles not in the initial list:** The initial room observation is the only source of all receptacles. If you start going to a receptacle that was not in that first description (e.g., a sidetable that appears only after moving), you are wasting steps. Stick to your initial list.
- **Giving up too early:** If you have not found the object after checking many receptacles, do not stop until you have visited every single one on your list. Patience is required.
- **Missing the placement step:** Arriving at the target is not enough; you must explicitly `move` the object.

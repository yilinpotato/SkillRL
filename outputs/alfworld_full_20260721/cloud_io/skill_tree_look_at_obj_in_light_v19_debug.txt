# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- Search surfaces at your current location for a desklamp. If seen, move to that receptacle if needed.
- If not visible, move to another surface receptacle (e.g., desk, dresser, sidetable, shelf, bed, etc.) and check contents. Continue until you find a desklamp.
- Once at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- If you encounter the target object before the lamp, remember its location and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Phase 2: Locate and take the target object (after lamp is on)

### Systematic Search
1. **Recall the initial room description** — it lists every furniture/receptacle with numbers (e.g., drawer 1, drawer 2, …). Write down each one individually (including numbers). This is your **complete list** of places to search.
2. **For each receptacle on that list (in any order, but do not skip any):**
   - Go to it.
   - Read the arrival observation. If the target object's exact name appears among the items on the surface, take it (action: take <object> from <receptacle>).
   - If the target is not on the surface, check if this receptacle has any containers (e.g., a drawer built into a dresser, a cabinet). Open each container (action: open <container>) and inspect its contents.
3. **Continue until every receptacle from your list has been visited and all containers opened.**
4. **Exhaustive fallback:** If after visiting all receptacles and opening all containers the target is still missing, re-read the initial description to verify you did not overlook any receptacle or container. Go back and open any containers you missed. Persist.
5. **Do not waste actions on 'look' or 'inventory'** — arrival observations give sufficient information. Move efficiently.

### Action Precondition Check
- **Only take an object that is explicitly listed in the current observation.** Never guess or assume an object's location. If the observation does not show the target, do not attempt to take it from that receptacle — continue searching.
- If you try to take an object not present, you will waste an action and potentially break the task. Always verify before acting.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required. (Optionally use examine, but not necessary.)

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".

- You may go to sinkbasin or bathtubbasin to search for the target object. If the target object is there, pick it up. Once you are holding it, you can clean it immediately using the same sinkbasin/bathtubbasin. Do not go to the sinkbasin solely to clean until you are holding the object.

### Systematic Open Surface Search
1. After receiving the initial room description, make a mental list of **all open surfaces** (receptacles that are not closed containers: e.g., countertops, diningtables, stoveburners, shelves, sinkbasins, bathtubbasins, garbagecans, handtowelholders, towelholders, carts, etc.). Keep this list.
2. Visit each open surface exactly once in any order. At each, examine contents. If the target is present (verify name), pick it up and go to Phase 2.
3. After each open surface, mentally check it off. **Do not revisit any checked open surface.**
4. When the last open surface is checked and the target is not found, **immediately proceed to closed containers** – do not revisit any open surface.

### Transition to Closed Containers
- **When you have exhausted all open surfaces, go to the first closed container in the room description (lowest-numbered cabinet, then drawer, etc.)**.
- If you are at a closed container and it is time to search closed containers, **open it and look inside immediately** – do not walk away without opening.
- Do not skip any closed container. Open each one, look inside, and if target is not there, close it (if necessary) and move to the next container in the order below.

### Closed Container Search Order
- **If the target is a food item** (e.g., lettuce, potato, tomato, apple, bread, egg, etc.): go directly to the fridge first. Open it, look inside, and take the target if present.

- **Execution rules for all closed containers:**

  - Do not skip any container.

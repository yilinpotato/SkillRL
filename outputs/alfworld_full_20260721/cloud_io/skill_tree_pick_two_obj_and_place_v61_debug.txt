# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop when counter equals 2.

## Counter & Completion Rules
- Start counter at 0.
- After each successful placement, increment counter by 1.
- If counter == 2, task complete – stop immediately.
- If counter < 2, you MUST continue searching for the next object. Never stop after a single placement.
- After two exhaustive full passes (in either Phase 1 or Phase 2) without finding a needed object, task is impossible – stop.

## Critical Rules (Must Follow)
- **Object name must match exactly.** Compare character by character. Do not take mismatched objects.
- **Before any movement, you MUST perform `look`** to get the current observation. Then list every furniture item in the order they appear. This list is your search plan. Deviating from this plan leads to loops and missing objects.
- **After taking a matching object, next action must be `go to [target receptacle]`.** No exceptions.
- **After placing an object, immediately restart search for the next object.** Do not loop in place or repeat non‑productive actions.
- **If you see the target object at your current location, take it immediately before moving away.**

## Phase 1: First Object Search
1. Execute `look` immediately. Do not move until you have listed all visible furniture. Then visit each in that exact order.
2. When you arrive at a furniture item:
   - If the item is closed (e.g., cabinet, drawer, fridge), **open it** first.
   - Examine its contents for the target object.
3. For each object seen, check exact name match. If yes, **take it** immediately.
4. After taking, go to target receptacle. Open if closed, then place the object. Increment counter.
5. **Exhaustive Search:** If you finish the list without taking any object, perform a second full pass (repeat step 2 from first item). After two full passes and counter still 0, task impossible – stop.

## Phase 2: Second Object Search (After First Placement)
### Immediate Action After Placement
- Increment counter. If counter == 2, stop – success.
- If counter == 1, you **must** find the second object. Do not stop or loop.

### Decision: Where to Look Next
1. **Assess whether you saw multiple instances at the pickup location** (e.g., "cellphone 3, cellphone 4"). If yes, go back to that same location immediately and take the next instance. Then go place it.
2. **Otherwise, perform a Full Restart:**
   - Execute `look` to get a **fresh** observation. List every furniture item in the order they appear.
   - Do not revisit only the previous location or a few spots. Follow the list exactly.
   - Visit each item in that exact order, opening closed receptacles and checking contents.
   - When you find a second target object, take it, go to target receptacle, open if needed, place it. Increment counter to 2. Stop.
3. If you complete the full restart list without finding a second object, perform a second full pass. If after two full passes counter is still 1, task impossible – stop.

### Important
- If you return to the original pickup location and find no second object there, continue with the full restart list – do not stop.

## Failure Prevention
### Systematic Search
- Before any search, list all furniture from the current `look` output. Then visit each in order.
- **Open all closed receptacles** when you visit them. Do not skip any.
- Check every furniture type – surfaces, containers, shelves, tables, basins, stoveburners, armchairs, beds, etc.
- If you have visited all items and found nothing, do a second full pass before giving up. Double‑check that you included all types.
- If unsure, re‑read the observation to ensure you have the complete list.

### Object Type Verification
- Before taking any object, read its exact name. Compare to the target type character by character. Only take if they match exactly.
- If you take a non‑matching object by mistake, drop it immediately (`drop [object]`) and resume searching from the same furniture item.

### Multi‑Object Count Completion
- After placing one object, you must find a second. Do not stop until counter == 2, or until two full searches after the first placement yield nothing.
- If you have placed one object and then complete two full passes without finding a second, task impossible – stop.

### Immediate Action on Visible Target
- Whenever you are at a furniture item and see an object whose name exactly matches the target, take it immediately. Do not move away before picking it up.

### Loop Detection and Breaking
- If you find yourself repeatedly visiting the same few furniture items without covering the full list, you are in a loop. Stop immediately and perform a fresh `look` to rebuild your search plan.
- Always ensure your search covers all furniture types – not just one category (e.g., only cabinets or only drawers).

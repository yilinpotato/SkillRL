# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location.
- The heating appliance is the microwave.
- The object must be heated before placing; do not place raw.

## 2. Locate the object
- Start at the fridge and open it. If the target object is inside, take it and go directly to Section 3.
- If the object is NOT in the fridge, you must conduct a **complete systematic search** (Section 2.2). Do not stop until every receptacle type has been exhausted.

### 2.1 Immediate pick-up rule
- **If you see the target object on any surface or inside an already-open container, take it immediately.** But do **not** let a lucky find cut the search short — only stop when the object is in your hand.

### 2.2 Exhaustive Search Protocol (Mandatory – follow exactly, no shortcuts)
**Critical: The #1 cause of failure is stopping too early. You must continue until the environment returns an error for each receptacle type. Do not assume the object is absent after checking only a few items.**

1. **Check all countertops first.** Start with `countertop 1`, then `countertop 2`, etc. At each, look and take if found. Continue until you get an error (e.g., "That location does not exist").
2. **Then check all dining tables** (`diningtable 1`, `diningtable 2`, ...) in the same way – do not skip this step even if none appeared in your initial look.
3. **Then check all cabinets.** Start with `cabinet 1`, then `cabinet 2`, etc. **You must try each number in sequence until you get an error.** For each, open it, look inside, and take if found. Do not stop after opening only two or three cabinets – continue until the environment says that cabinet number does not exist.
4. **Then check all drawers** (`drawer 1`, `drawer 2`, ...). Open each, look inside, take if found. Continue until error.
5. **Then check other openable containers** (sinkbasin, garbagecan, microwave, coffeemachine, toaster, etc.) – try each type incrementally (e.g., `sinkbasin 1`, `garbagecan 1`) until error.
6. **If you still have not found the object, perform a `look` again.** If new receptacles become visible, repeat the entire sequence from step 1. If another room is accessible, go there and repeat.

**Important:** Do **not** go to the target placement location during this search. Only go there after heating the object. If you return to the target location without the heated object, you have failed.

### 2.3 Object-specific search hints (use only as a guide – always fall back to the exhaustive search)
- **Plates, cups, mugs, bowls, utensils**: often in cabinets or on dining tables. Check those early after the fridge.
- **Food items (apple, tomato, potato, egg, bread, etc.)**: often in the fridge or on countertops.
- **Small objects (peppershaker, saltshaker, etc.)**: can be anywhere – do not rely on heuristics alone.
- If you have checked likely locations and still not found the object, do **not** assume it is absent – continue the exhaustive search from step 1.

### 2.4 Avoid premature movement to the target location
- Do not go to the target placement location (e.g., sidetable, fridge, cabinet) while searching for the object. The target location is only for placing the heated object.

## 3. Heat the object
### 3.1 Direct heating from inventory
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If that fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to Section 2 and perform the exhaustive search again.

### 3.3 Critical: Do not drop or place the object before heating
- Once you have picked up the target object, go directly to the microwave and heat it. Do NOT move the object to any other location before heating.

## 4. Place the heated object
- Go to the receptacle specified in the task.
- If it is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: `move <object> to <receptacle>`.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, do **not** perform any unnecessary actions. Follow the termination detection procedure below.

### 5.1 Termination detection

- Your inventory must be empty, and the receptacle must contain the target object.
- **If both conditions hold, the task is complete. Immediately stop all actions. Do not take any further steps — not even another examine or inventory check.**
- If the conditions do not hold, re-evaluate: the object may have been placed incorrectly or not at all. In that case, return to Section 4 and try again.
- **Important:** Do not loop on verification. Once you have confirmed the object is placed, terminate.

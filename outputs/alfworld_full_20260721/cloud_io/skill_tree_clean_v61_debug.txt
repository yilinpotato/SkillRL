# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- The cleaning source is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
1. **Never stay at or interact with the cleaning source unless you are holding the target object or you are searching for it there.** If you arrive at the cleaning source during search, immediately check whether the target is present. If yes, pick it up and proceed to the Cleaning Phase (you are already at the source). If not, leave immediately and resume the search. Do not clean, place, or examine unrelated items while there.
2. **Once you are holding the target object, do not put it down or interact with any other object until after you have cleaned it and placed it at the destination.**
3. **Do not go to the destination receptacle until after cleaning.**
4. **Before picking any object, verify its name matches the target exactly.** If the name differs (e.g., "handtowel" vs "cloth"), do not pick it up.

## Search Phase
### Systematic search for target object
- The goal is to locate the exact target object. You must visit **every** receptacle listed in the initial `look` output. Do not skip any.

#### Initial Look
- Use `look` immediately to get the full room description. Mentally list every receptacle name you see (e.g., countertops, cabinets, drawers, sinkbasin, bathtubbasin, diningtable, stoveburners, shelves, garbagecan, handtowelholder, towelholder, fridge, microwave, oven, toilet, etc.). This list is your search checklist.

#### Open Surface Search
- Open surfaces include: countertops, diningtable, stoveburners, shelves, garbagecan, handtowelholder, towelholder, sinkbasin, bathtubbasin, carts, and any other receptacle that is not a closed container (cabinet, drawer, fridge, microwave, oven, etc.).
- Visit **every** open surface from your checklist exactly once in any order. At each, examine its contents. If the target is present (verify name), pick it up and exit search (go to Cleaning Phase). If the target is not there, move immediately to the next open surface. Do not look, examine, or perform any other action between open surfaces.
- **Cleaning sources (sinkbasin, bathtubbasin) are open surfaces and must be visited during this phase** – but follow Critical Rule 1 when at them.

#### Closed Container Search
- After exhausting all open surfaces without finding the target, proceed to closed containers: cabinets, drawers, fridge, microwave, oven, etc. (any receptacle that requires opening).
- **Order:** For non-food targets: all cabinets (numerical order if numbered), then drawers (numerical), then fridge, then microwave, oven, etc. For food targets (lettuce, potato, tomato, apple, bread, egg, etc.), go to fridge first, then cabinets, then drawers, etc.
- At each closed container: Immediately `open [container]`. Look inside. If the target is inside, take it and exit search (go to Cleaning Phase). If not, close it and immediately go to the next container in the prescribed order. Do not perform any other action between containers.
- **You must open and look inside every single closed container listed in your initial checklist.** Do not skip any. If you lose track, use `look` again to refresh your list of remaining containers.

#### Exhaustive Search Rule
- If you have checked all open surfaces and all closed containers and still have not found the target, **repeat the entire search cycle** (open surfaces again, then closed containers). This is rare but possible.
- **Never stop searching until the target is found.** If you find yourself in a loop or unsure, use `look` to refresh your checklist and continue.

### Object Name Verification Before Picking
- This is a separate check: before executing `take [object]`, mentally confirm that the name of the object in the observation exactly matches the target name from the task. If it does not match, do not pick it up – continue searching.

## Cleaning Phase
### Prerequisite: You must be holding the target object
- If empty-handed, return to Search Phase. If holding a different object, put it down first then return to Search Phase.

### Go to Cleaning Source
- Once holding the target, immediately go to the cleaning source (sinkbasin or bathtubbasin). If you are already there (from search), proceed directly to cleaning.

### Clean Immediately
- **Upon arrival at the cleaning source, the only valid next action is `clean [object] with [cleaning_source]`.** Do NOT look, examine, inventory, or move anywhere else. If you ever arrive at the cleaning source and are not immediately cleaning, you have made a mistake. Correct it by performing the clean action now.
- Confirm the observation says "You clean the [object] using the [cleaning_source]." Only then proceed to Placement Phase.

## Placement Phase
- Go to the destination receptacle. If it is a closed container, open it first.
- Use `move [object] to [destination]`.
- Confirm the object is now at the destination (observation will indicate placement).

## Completion
- Stop as soon as you have placed the clean object. Do not continue.

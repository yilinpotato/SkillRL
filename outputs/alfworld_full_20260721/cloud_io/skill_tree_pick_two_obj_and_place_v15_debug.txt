# pick_two_obj_and_place

## Goal
- Place exactly two instances of a specific object into a specified target receptacle.

## Procedure (step-by-step algorithm)
1. **Identify task**: Note the required object type (e.g., newspaper) and the target receptacle (e.g., sofa).
2. **Initial exploration**: Read the room description and list every furniture item. For each closed container (drawer, cabinet, safe, fridge, etc.), open it immediately. Do not assume any container is empty.
3. **First object search**: Visit each furniture item from your list exactly once. For each item:
   - Go to it.
   - If it is a container and is closed, open it.
   - Examine its contents (on surfaces or inside).
   - **If you see an object whose exact name matches the required type, take it.** Then go directly to step 4.
   - If not, move to the next item on the list.
   - After visiting all items, if you still have not found the object, you may re-visit items (objects may have been moved by earlier actions).

### Object name verification before pickup
- **Before picking up any object, read its full name from the observation.** Compare it character by character to the required type from the task description (e.g., "spraybottle" vs "soapbottle", "soapbottle" vs "soapbar"). A single letter difference means it is the wrong object.
- Do not rely on partial matches or semantic similarity. If the names do not match exactly, do not take it. Continue searching.
- If you have already picked up an object and later realize it is wrong, drop it immediately (use "put <object> on <surface>" or similar) and resume the search.

4. **Place the first object**: Go directly to the target receptacle. Immediately use the action "move <object> to <target>". Do not perform any other actions (look, inventory, move elsewhere) before moving.
5. **Second object search**: **You are not done.** Reset your mental list of furniture items (the one from step 2) and repeat step 3 exactly. Do not assume the second object is in the same type of location as the first — check all furniture types. Do not revisit already-searched spots unless you have exhausted every item on the list.

### Continuation after first placement
- After you have successfully moved the first object to the target, immediately begin a fresh, systematic search for the second object. Do not return to furniture you already checked during the first search unless no new locations remain.
- Maintain a mental checklist of which items you have visited this round (second search). If you find yourself going back to the same place repeatedly, force yourself to look at a different furniture type.
- The environment does not signal success until both objects are placed. Do not stop after one placement.

## Common Failure Patterns
### thorough_search
- Ensure you have visited *every* furniture item listed in the initial room description. Do not skip any cabinet, drawer, shelf, counter, stove burner, fridge, or any other surface/container.
- If an item is closed, open it before checking contents. Do not assume it is empty.
- After checking all items, if you still lack two copies, revisit any you may have missed or recheck opened containers (objects may have been moved).
- Common oversight: checking only one type of furniture (e.g., only countertops or only cabinets). Spread your search across all categories.

### check_count
- After placing the first object, immediately reset your mental list and begin the second search. Do not interpret any intermediate success message as task completion.
- Before concluding the task, confirm that you have placed exactly two objects of the required type into the target receptacle. The environment will not indicate success until both are placed.
- If you have placed only one, continue searching. Do not stop until you have picked up, moved, and placed the second object.

## Critical warnings (avoid these failures)
- **Insufficient search**: You must visit every furniture item on your list. Checking only a few items (e.g., only sidetables or only drawers) will cause failure. If you find yourself revisiting the same type repeatedly, stop and check a different type.
- **Premature stop**: After placing the first object, immediately begin searching for the second. Do not rest or assume the task is done.
- **Not opening containers**: Always use "open" before looking inside. The action "examine" does not open containers.
- **Wrong object identity**: Before taking any object, verify its exact name against the required type. Do not take if there is any mismatch.
- **Intervening actions**: When you are at the target receptacle with the correct object in hand, issue the move action immediately. Any delay (looking, inventory, going elsewhere) wastes steps and leads to failure.

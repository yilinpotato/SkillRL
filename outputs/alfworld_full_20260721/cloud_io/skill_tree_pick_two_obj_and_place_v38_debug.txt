# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle. Do not stop until both are placed (counter == 2).

## Core Rules
- After taking a matching object, immediately go to the target and place it. Do nothing else until placed.
- If the target receptacle is closed (e.g., drawer, cabinet), open it first, then place.
- Keep a mental counter: start at 0, increment by 1 after each successful placement.
- Never stop while counter < 2.
- Only stop if counter == 2, or after two full passes through all furniture items you have placed exactly 1 and cannot find another matching object anywhere.

## Object Type Verification
- Before taking any object, compare its exact name to the required type. Only take exact matches. Do not assume similar objects (e.g., mug vs cup, soapbottle vs soapbar) are acceptable. If the name differs, skip it.
- If you accidentally take a non-matching object, check inventory, then drop it or leave it; resume search immediately.

## Search Protocol

### Search all possible container locations
- **Include the target receptacle in your master list.** The objects may already be inside the target, so examine it like any other furniture: go to it, open if closed, look inside.
- **Surfaces, containers, and appliances are all valid locations.** Do not restrict your search to only cabinets or drawers. Countertops, tables, shelves, and the target itself can hold objects.
- **Systematic visitation:** After creating the master list, visit every item in the exact order they appeared in the initial room description. Go to the first item, examine it (open if closed, look inside), then move to the next item. Do not skip any item, and do not linger on one type of furniture. Continue until you have visited every item on the list.
- **If you find a matching object during scan, take it immediately and go place it. After placing, resume scanning from the next unvisited item on the list (Phase 2 will restart from the beginning of the list).**

### Phase 1: First Object
1. **Create Master List**: After the initial room description, write down every furniture item exactly as listed (all surfaces and containers). Include the target receptacle in this list. Do not miss any.
2. **Visit each item in the exact order of your list**: Go to the first item. If closed, open it. Examine its contents. If you see an exact-matching object, **take it immediately** (then go place it). Then proceed to the next item on the list. Do not skip any item. Continue until all items are visited OR a matching object is found (take it, place it, then stop Phase 1).
3. After placing the first object, begin Phase 2.

### Phase 2: Second Object (After placing the first)
1. **Immediately resume searching. Do not explore unrelated items.**
2. **Re-read the initial room observation** and write down the same master list again. Include the target receptacle.
3. **Visit every item again in the exact order** – do not skip any, including the target receptacle. For each item:
   - If closed, open it.
   - Examine contents.
   - If you see a matching object, **take it immediately** (then go place it).
   - Mark item as visited.
4. If you saw a second matching object during Phase 1 (e.g., two together), return directly to that location instead of a full scan.
5. Continue until list exhausted or second object taken. If taken, place it and stop (counter == 2).
6. If you have visited all items and found no second object, the task may be impossible – but only after two full passes (Phase 1 + Phase 2).

## Stop Condition Verification
- After each placement action, immediately check your counter. If counter == 1, you **must** start Phase 2 search. Do not explore or examine anything else until the second object is placed.
- Do not stop after placing the first object. Do not wander. Do not assume the task is done.
- The only valid stop signals are: counter == 2, or after two complete passes you have exactly 1 placed and no matching object remains.

## Common Failure Patterns (Avoid These)
- Premature stop after first placement without beginning Phase 2.
- Taking a non-matching object or the wrong type.
- Skipping any furniture item in Phase 2 (surfaces and containers) – visit every item from the master list in order.
- Not opening the target receptacle before placing.
- Stopping after only one pass when counter is still 1.
- **Not checking the target receptacle as a possible source of objects.**
- **Assuming objects are only in closed containers; surfaces and appliances are equally important.**

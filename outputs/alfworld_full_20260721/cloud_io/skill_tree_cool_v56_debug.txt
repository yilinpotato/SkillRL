# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### locate_object
- Follow this exact surface order: countertops → fridge → diningtables → sidetables → shelves → sinkbasins → stoveburners → cabinet tops → drawer tops.
- For each surface type, visit **every instance** one by one. Start with the first instance you are at (already countertop 1 from consensus prefix). If the target is not on that instance, go to the next instance of the same type (e.g., countertop 2, countertop 3…). Continue until all instances of that type are checked.
- Only after finishing all instances of the current type, move to the next surface type in the order.
- At each instance, if you see the target object, take it and proceed to Phase 2.
- When checking the fridge: open it, look inside. If target found, take it → Phase 2. If not, close the fridge before moving on.
- **Do not skip any surface type** and **do not visit a type out of order**. If you find yourself at a location that is not the next in order, return to the correct next unvisited surface type.

### Then search inside containers (only after all surfaces exhausted)
- Open each cabinet one by one, look inside. If target present, take it → Phase 2. Close each cabinet after checking.
- Then check each drawer (same process).
- Then check the microwave (if any).
- Only after all container types, if still not found, backtrack to surfaces (you may have missed a location).

### Object verification
- Before taking, read the exact name. After taking, verify again. If wrong, put it back on the exact surface you took it from and resume searching from that location.

## Phase 2: Cool the object using the fridge
- As soon as you are carrying the correct target object, go to a fridge, open it (if closed), and use `cool <object> with fridge`.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, garbagecan). If it is a closed container, open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

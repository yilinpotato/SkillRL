# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
- You may go to sinkbasin or bathtubbasin to search for the target object. If the target object is there, pick it up. Once you are holding it, you can clean it immediately using the same sinkbasin/bathtubbasin. Do not go to the sinkbasin solely to clean until you are holding the object.
- Do not go to the destination receptacle until after cleaning.
- Search open surfaces first, then closed containers. **Never revisit an open surface** after you have checked it off. If you ever find yourself at a receptacle you already visited, stop and use `look` to refresh your mental list, then go to the next unchecked receptacle.
- If you are already holding something that is not the target, put it down immediately.
- After arriving at the cleaning source, perform the clean action immediately – do not examine, look, or inventory before cleaning.
- Before picking any object, confirm its name matches the target exactly. Do not pick similar-named objects.

## Phase 1: Search and Acquire the Target Object
**Prerequisite: None – begin with a fresh `look` to get the room description.**

### Object Identity Verification
- When you see an object that might be the target, stop and compare the exact name from the task.
- Do not pick up any object whose name is different.
- If unsure, do not pick; continue searching.

### Systematic Open Surface Search
1. After receiving the initial room description, make a **complete mental list** of **all open surfaces** (receptacles that are not closed containers: e.g., countertops, diningtables, stoveburners, shelves, sinkbasins, bathtubbasins, garbagecans, handtowelholders, towelholders, carts, etc.). Include every one that appears in the description.
2. Visit each open surface **exactly once** in any order. At each, examine contents. If the target is present (verify name), pick it up and go to Phase 2.
3. After each open surface, mentally check it off. **Do not revisit any checked open surface.**
4. When the last open surface is checked and the target is not found, **immediately proceed to closed containers** – do not revisit any open surface.

### Transition to Closed Containers
- **When you have exhausted all open surfaces, go to the first closed container in the room description (lowest-numbered cabinet, then drawer, etc.)**.
- If you are at a closed container and it is time to search closed containers, **open it and look inside immediately** – do not walk away without opening.
- **Do not skip any closed container.** You must open and look inside every single closed container listed in the room description. If you are unsure which ones remain, re-read the room description using `look` and continue.

### Closed Container Search Order
- **If the target is a food item** (e.g., lettuce, potato, tomato, apple, bread, egg, etc.): go directly to the fridge first. Open it, look inside, and take the target if present.
  - If not found in fridge, continue to cabinets (numerical order), then drawers (numerical order), then microwave, oven, etc.
- **For non-food targets:** check all cabinets (numerical order), then all drawers (numerical order), then the fridge, then microwave, oven, etc.
- **Execution rules for all closed containers:**
  - Open each one, look inside. If the target is not inside, immediately close it (if necessary) and move to the next container in numerical order.
  - **You must check every single container of that type** – do not stop after a few. If you have not found the target after checking all closed containers, you have not exhausted all possibilities.
  - If still not found after all closed containers, **repeat the entire search cycle from open surfaces again** – this is rare, but do it. Never give up.

### If Stuck or Lost
- Use `look` to re-read the room description and reconstruct your mental list. Then resume from the first unchecked receptacle (if any) or continue with closed containers. If you have checked everything and still lack the target, repeat the whole cycle from open surfaces.

## Phase 2: Clean the Object
- **Prerequisite: You must be holding the target object.** If empty-handed, return to Phase 1. If holding a different object, put it down first.
- Immediately go to [cleaning_source] (sinkbasin or bathtubbasin).
- Upon arrival, immediately execute `clean [object] with [cleaning_source]`. Do not examine, look, inventory, or move elsewhere until you have performed the clean action and confirmed the observation says cleaned.
- Confirm observation says cleaned.

## Phase 3: Place the Clean Object at Destination
- Go to [destination]. If it is a closed container, open it first.
- Use `move [object] to [destination]`.
- Confirm the object is now at destination.

## Completion
- Stop as soon as you have placed the clean object. Do not continue.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop only when counter == 2.

## Counter
- Start at 0.
- Increment after each successful placement.
- If counter == 2, task complete – stop. Never stop earlier.
- If counter < 2, you **must** search for the next object.

## Core Search Plan
1. **Always start with `look`** to get the full list of all furniture items in the room. This is your **search list** – remember its order.
2. **Immediately after `look`**, go to the first item on the list. This is your next action; do not `look` again.
3. Visit each item **in that exact order**. Do not skip any – cabinets, drawers, counters, shelves, tables, beds, etc.
4. At each item:
   - If closed, **open** it.
   - Examine contents. If you see the **exact target object name**, **take it immediately**. Do NOT pick up any other object.
   - If you accidentally take a wrong object, `drop` it and continue.
5. If you complete the entire list without taking anything, **repeat the list once more**. After two complete passes with no target found, the object is absent – task impossible, stop.

## Phase 1 – First Object (counter = 0)
- Execute `look` to form the search list.
- Follow the core search plan until you find and take the first target object.
- Then **immediately** `go to target receptacle`, open if closed, `place` the object. Increment counter to 1.

## Phase 2 – Second Object (counter = 1)
After placing the first object, counter becomes 1. **You must now search for the second object.** Do not stop until counter == 2.

### Shortcut Available?
- **If you saw multiple copies of the target at the location where you took the first object**, go back to that same location, take the next copy, go place it. Counter becomes 2. Stop.

### Full Restart (no shortcut)
- Execute `look` to get a fresh search list.
- **After that `look`, immediately go to the first item on the new list.** Do not perform any other action in between.
- Follow the core search plan exactly.
- When you find a second target, take it, go place it. Counter becomes 2. Stop.
- If you complete two full passes of the fresh search list without finding a second target, task impossible – stop.

## Avoid Taking Non-Target Objects
- **Only touch objects whose name exactly matches the target type.** Do not pick up cloth, soapbar, book, candle, or anything else – they waste actions and disorient you.
- If you already hold an irrelevant object, `drop` it immediately and resume the search plan.

## Loop Detection & Recovery
- **If you ever perform three consecutive actions of the same type** (e.g., `look`, `look`, `look` or `open`, `open`, `open` without moving), you are in a loop.
- **Force a change**: immediately go to the next item on your current search list (or if you have no list, do a fresh `look` then go to the first item). Never repeat the same action more than twice in a row.
- If you have no search list, do a fresh `look` and start from the first item.

## Exhaustive Container & Surface Search
- Your search list includes **all** furniture types – containers (cabinets, drawers, shelves) **and** surfaces (countertops, tables, desks, beds, etc.).
- After opening several containers of one type and finding nothing, do **not** keep opening more of that type; move to the next furniture type on the list.
- **Always check surfaces** – objects are often placed on countertops, desks, or beds, not just inside closed containers.
- If the target is an object typically found in a specific fixture (e.g., toiletpaper on toiletpaperhanger, soap in sinkbasin), search that fixture too – it is part of the furniture list.

## Critical Action Rules
- After taking an object, **next action must be `go to target receptacle`** – no exceptions.
- After placing the first object, **immediately decide** whether to use the shortcut or perform a Full Restart. Do not delay.
- If you ever find yourself stuck or unsure, execute `look` and then **immediately go to the first item on that list** – do not `look` again until you have visited that item.

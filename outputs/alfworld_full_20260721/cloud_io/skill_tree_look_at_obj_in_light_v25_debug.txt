# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- As soon as you see the initial room description, **mentally note every furniture item that can hold objects** (desks, shelves, dressers, sidetables, armchairs, sofas, drawers, garbage cans, etc. – each numbered entity is a separate receptacle). You will need this list later to ensure you search everywhere.
- Start by moving to a surface receptacle (e.g., desk, dresser, sidetable) to see its contents. Check each surface you arrive at for a desklamp. If seen, that receptacle now holds the lamp.
- If not visible on the first surface, move to another surface receptacle from the initial room description and check its contents. Continue until you find a desklamp.
- Once you are at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- If you encounter the target object before the lamp, remember its location and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Navigation and Exploration (after lamp is on)
### Systematic Container Search
- **Crucial: Do not stop after checking only a few receptacles. You must visit every single receptacle listed in the initial description. If you have not checked all, continue. Use 'look' to refresh the list if you are unsure.**
- Start by re-reading the initial description (use 'look' if needed) to get the complete list of all receptacles. Write them down mentally.
- Pick a receptacle from the list (any order, but be exhaustive – do not skip any receptacle, even if you think it unlikely to hold the target).
- Go to it (action: go to <receptacle>).
- Read the arrival observation. If the target object's exact name appears among the items **on the surface**, take it (action: take <object> from <receptacle>) and stop – the task is done after taking.
- If the receptacle is a container (like a drawer, cabinet, safe) and it is closed, open it (action: open <receptacle>). Then inspect its contents. If the target object is inside, take it and stop.
- If the receptacle is not a container (e.g., desk, shelf, bed, sidetable), there are no sub-containers to open; just check the surface items. Move to the next receptacle.
- After finishing that receptacle, move on to the next one in the list. **Do not revisit** any receptacle unless you missed opening a container there; then go back and open it.
- **Avoid wasteful actions:** Do not use 'look', 'examine', or 'inventory' unless the observation is unclear (e.g., after opening a container you need to see what changed). Arrival observations already show all surface items. Unnecessary actions waste turns and may break the task.
- **Persist:** Continue this process until you have visited every receptacle and opened every container. If you finish the list and still haven't found the target, re‑read the initial room description to verify you did not overlook any receptacle. Go back and open any containers you missed. Never give up until every receptacle from the initial description has been checked.

## Phase 2: Locate and take the target object (after lamp is on)

### Step 1: Check the lamp's surface first
- If the target object is on the same receptacle where you turned on the lamp, take it immediately (action: take <object> from <receptacle>).

### Step 2: Systematic search (if not found at lamp's surface)
- Follow the procedure described in **Navigation and Exploration > Systematic Container Search** above. That section contains the detailed step‑by‑step for exhaustively checking all receptacles.

### Action Precondition Check
- **Only take an object that is explicitly listed in the current observation.** Never guess or assume an object's location. If the observation does not show the target, do not attempt to take it from that receptacle – continue searching.
- If you try to take an object not present, you will waste an action and potentially break the task. Always verify before acting.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required. (Optionally use examine, but not necessary.)

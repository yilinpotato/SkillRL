# Goal: Cool an object and move it to a specified target location.

## Object Search and Retrieval

### Exhaustive Search Rule
**You must try every possible instance of a surface type before moving to the next type.** After arriving at a location, look at the observation: if it shows contents (e.g., "On the countertop 2, you see ..."), that instance exists and you have not exhausted it yet. Only stop incrementing the number when you receive an error message like "That is not a valid location." Do **not** guess that only a few instances exist — always continue until you get an error.

### Systematic Search Protocol (follow strictly in order)
1. **Countertops** – Start with countertop 1, go to it and look. If the target object is present, take it and go to Phase 2. If not, try countertop 2, then countertop 3, etc. Continue incrementing the number until you receive an error message. Do not stop after only one countertop.
   #### Skipping Prevention
   - After trying countertop 1 and 2, you must try countertop 3 next — do not jump to diningtable. The only valid reason to leave countertops is receiving an error (e.g., "That is not a valid location.").
   - If you ever catch yourself at a surface type that is not next in the list (e.g., at diningtable before getting an error on countertops), stop immediately and return to the correct next instance of the current type.
2. **Diningtables** – Same iteration: diningtable 1, diningtable 2, etc.
3. **Sidetables** – Same iteration.
4. **Shelves** – Same iteration.
5. **Sinkbasins** – Same iteration.
6. **Stoveburners** – Same iteration.
**Crucial rule:** Do NOT move to the next type until ALL instances of the current type have been exhausted (i.e., you have tried every number that exists). Do NOT skip any type. Do NOT go to closed containers (fridge, etc.) until you have finished all six surface types.
*If you ever catch yourself at a location that is not the next in the list, stop and immediately return to the correct next surface type.*

### Visited-Set Tracking
- Keep a mental list of every location you have already searched (e.g., countertop 1, countertop 2, diningtable 1, etc.). After visiting a location and not finding the target, mark it as searched.
- Before going to a new location, check your mental list. Do not revisit a location already searched unless you later open a container that might have revealed new objects (containers are separate).
- This prevents redundant loops and ensures you progress forward through the search order.
- **Important:** When returning to a surface type later (e.g., after fridge), do not repeat the same numbers. Instead, check if you missed a higher-numbered instance (e.g., if you only tried countertop 1 and 2, you must try countertop 3 now if you never got an error for it).

### Domain-Specific Object Location Hints
- **Food items** (potato, lettuce, tomato, apple, bread, egg, etc.) are most commonly found on countertops, diningtables, or inside the fridge. Prioritize checking these surface types fully before looking at less likely surfaces (sinkbasins, stoveburners).
- **Non-food items** (mug, bowl, pan, fork, knife, etc.) may also appear on any surface but are common on countertops and in cabinets/drawers. After surfaces, check closed containers in the prescribed order.
- These heuristics are not guarantees; always stick to the full systematic search if the object is not found quickly. Use the heuristics to guide your search order only when you are confident the object should be in a common location.

### Closed Container Search (only after surfaces exhausted)
#### Step-by-Step Procedure
- **Order:** 1. Fridge (all instances) → 2. Cabinet (all instances) → 3. Drawer (all instances) → 4. Microwave (all instances). Do not skip any type.
- **For each container instance:**
  1. Go to the container (e.g., `go to fridge 1`).
  2. If the observation says the container is closed, use the `open` action.
  3. After `open`, check the observation to confirm it now says "open". If not, re-open.
  4. Once open, look inside (the observation will list contents). If the target object is present, take it and go to Phase 2.
  5. If the object is not there, close the container (optional but good practice) and proceed to the next container instance.
- **Important:** Do not give up after one container. Continue through all instances of each type. Only after finishing all four types (all instances) may you consider restarting surface search if object still not found (rare).
- **Verification:** If you are at a container and you do not see its contents in the observation, you have not opened it. Re-apply the open action until you get a description of the interior.

### Object Verification before Picking
- Before taking any object, **read its exact name** from the observation and compare it with the task's target object (e.g., if task says "apple", only take an object named "apple 1" or similar – not "kettle" or "mug").
- If the object's type does not match the target, do not take it. Continue searching.
- This prevents picking the wrong item, which would waste time and fail the task.

## Phase 2: Cool the object using the fridge
- Ensure you are carrying the target object. If you are not carrying it, go back to searching (do not proceed to fridge).
- Go directly to the fridge.
- If the fridge is closed, open it.
- Verify the fridge is open (check observation). If not, re-approach and open again.
- Use `cool <object> with fridge`.

### Strict Order Enforcement
- After taking the target object, **do not perform any other actions** (such as inventory, look, or wandering). Immediately go to the fridge and cool the object. Any detour risks losing track of the task.
- If you accidentally do other actions, stop and return to the fridge step as soon as you realize.

## Phase 3: Move the cooled object to the target location
- Go to the target location.
- If the target receptacle is closed, open it first.
- Use `move <object> to <target>`.

## Completion check
- Object is cooled and placed at the target location – task complete.

# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the object.

### Step 1: Locate the object using systematic search.
- Re-read the room description from the prompt. It lists every receptacle by type and number. Use this to plan your search.
- Do not move until you have noted all surfaces and closed receptacles.

### Step 2: Full Exploration Plan – do not skip any category.
1. **Surface search order** – check every instance of each category in this exact sequence:
   - First: **countertops** (all numbered instances)
   - Second: **diningtables**
   - Third: **sidetables**
   - Fourth: **shelves**
   - Fifth: **sinkbasin**
   - Sixth: **stoveburners**
2. For each instance:
   - Go to it.
   - If the object is visible on the surface, take it immediately and proceed to Phase 2.
   - If the receptacle is open (e.g., sinkbasin), check inside and take if present.
   - If the receptacle is closed, note it for later (do not open it now; closed receptacles are searched after all surfaces).
3. **After finishing all surfaces** (i.e., you have visited every instance of the six categories above and the object is not found), then search **closed receptacles** in this order:
   - fridge
   - cabinets
   - drawers
   - microwave
   Open each one, look inside, and take the object if present.
4. **Critical rules for execution:**
   - After finishing one category, you **must** move to the next category in the list. Do not skip ahead. If you realize you are at a category that is not the next one in sequence, stop and go back to the earliest missed category.
   - Keep a mental checklist of which instances you have visited. Do not move to the next category until you have visited every instance of the current category.
   - When examining a surface, read every object name listed. The target object name must match **exactly** (e.g., "winebottle" is not "glassbottle"). If you see an exact match, take it and go directly to the fridge.
   - If you have searched all surfaces and all closed receptacles and still have not found the object, then and only then may you conclude the object is absent (but this should not happen in valid tasks).

### Step 3: After picking up the object, go directly to the fridge to cool it.
- Do not move to the target location first.

## Phase 2: Cool the object using the fridge.
- Go to fridge. If closed, open it.
- Use `cool <object> with fridge`.

## Phase 3: Move the cooled object to the target location.
- Go to the target location.
- If the target receptacle is closed, open it first.
- Use `move <object> to <target>`.

## Completion check: Object is cooled and placed at target.

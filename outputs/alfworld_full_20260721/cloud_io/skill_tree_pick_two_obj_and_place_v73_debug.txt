# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop only when counter == 2.

## Critical Instructions (must follow exactly)
- **Systematic search**: After every `look`, go to the **first** item on the list, then visit **every** item in **that exact order**. Do not skip any.
- **Never stop early**: After placing the first object, you **must** search for and place the second. Do not loop or idle.
- **Avoid look loops**: If you ever perform the same action twice in a row without moving (e.g., `look`, `look` or `open`, `open`), you are in a loop – immediately go to the next item on your current search list (or do a fresh `look` then go to the first item).

## Counter
- Start at 0.
- Increment after each successful placement.
- If counter == 2, task complete – stop. Never stop earlier.
- If counter < 2, you **must** search for the next object.

### Confirm Object Identity Before Picking
- **Always re-read the target object name from the task description before each pick.**
- Only pick up an object whose name **exactly matches** the target type (e.g., if task says "soapbottle", do not pick "soapbar").
- If you are unsure, use `look` to see the object name clearly or examine the task again.
- If you accidentally take a wrong object, `drop` it immediately and resume search.

## Search Procedure (Use for Every Object)
1. Always start with `look` to get the full list of all furniture items in the room. This is your **search list** – remember its order.
2. Immediately after that `look`, go to the first item on the list. Do **not** `look` again.
3. Visit **every** item on the list **in that exact order**. Do not skip any. All types must be checked:
   - Containers: cabinets, drawers, shelves, fridge, dresser, etc.
   - Surfaces: countertops, tables, desks, beds, sidetables, sofa, armchair, sinkbasin, bathtubbasin, etc.
   - Special fixtures: toiletpaperhanger, towelholder, etc.
4. At each item:
   - If closed, **open** it.
   - Examine contents. If you see the **exact target object name**, **take it immediately**. Do not pick up any other object.
   - If you accidentally take a wrong object, `drop` it and continue.
5. If you complete the entire list without taking anything, **repeat the list once more**. After two full passes with no target found, the object is absent – task impossible, stop.

## Phase 1 – First Object (counter = 0)
- Execute the **Search Procedure** to find and take the first target object.
- **After taking it, go directly to the target receptacle.** Do not place anywhere else.
- At the target receptacle: open if closed, then use `move` to place the object. Counter becomes 1.
- **While holding the object, do not drop it, move it elsewhere, or interact with any other object.**

## Phase 2 – Second Object (counter = 1)
After placing the first object, you need to find and place the second one. Choose exactly one of the following two paths:

### Shortcut – Only If Multiple Copies Were at the Same Source
- **Condition:** You saw **more than one** instance of the target object at the exact location where you found the first one (e.g., multiple plates on the same diningtable). If you saw only one copy there, do **not** use this shortcut – proceed to Full Restart.
- **Action:** Go back to that same location, take the next copy of the target, then go to the target receptacle and place it. Counter becomes 2. Stop.

### Full Restart (Default Path)
- Execute a fresh `look` to get a new search list.
- Immediately go to the first item on that new list. Do not `look` again.
- Follow the **Search Procedure** exactly to find the second target.
- When you find it, take it, go to the target receptacle, and place it. Counter becomes 2. Stop.
- If you complete two full passes of the fresh search list without finding a second target, task impossible – stop.

### Transition After First Placement – Critical Step
- **Immediately after placing the first object, you must decide and act. Do not `look` or move without purpose.**
- Evaluate the shortcut condition: did you see multiple copies where you found the first object? If yes, use the Shortcut. If no, use the Full Restart.
- **If using Full Restart:** Do exactly one `look` to get a new search list, then **immediately** go to the first item on that list. Do not `look` again until you have moved.
- **If you ever do `look` more than once without moving after placing the first object, treat it as a loop – force a move: go to the first item on your most recent `look` list (or do a fresh `look` if you have no list).**

## Avoid Taking Non-Target Objects
- **Only touch objects whose name exactly matches the target type.** Do not pick up cloth, soapbar, book, candle, or anything else – they waste actions and disorient you.
- If you already hold an irrelevant object, `drop` it immediately and resume the search plan.

## Loop Detection & Recovery
- If you ever perform **two consecutive actions of the same type** (e.g., `look`, `look` or `open`, `open` without moving), you are in a loop.
- **Force a change**: immediately go to the next item on your current search list (or if you have no list, do a fresh `look` then go to the first item). Never repeat the same action more than once in a row without moving.
- After placing an object, if you do `look` more than once without moving, treat it as a loop and immediately go to the first item on a fresh `look` list.

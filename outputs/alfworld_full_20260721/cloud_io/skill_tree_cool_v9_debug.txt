# Goal: Cool an object and move it to a specified target location.

## Sub-goal 1: Find the object to cool.
- The target object is not yet in your inventory. You must locate it by searching all receptacles in the room.

### Initial steps (already mastered)
- Go to fridge 1, open it (you have already done this), then go to countertop 1. This is the starting point.

### Immediately after arriving at countertop 1: check for target
- Look at the observation. If the target object is present on countertop 1, take it immediately.
- If not, proceed to systematically search all other **open flat surfaces** before opening any closed receptacles.

### Systematic search of open flat surfaces (mandatory order)
- The target is almost always on a flat surface (countertop, diningtable, sidetable, shelf, sinkbasin, stoveburner). Do not open cabinets or drawers until every flat surface has been checked.

#### Exhaustive enumeration of all flat surfaces
- Before moving, recall the **initial room description** from the `look` command. It lists all receptacles with their numbers. You must visit **every** numbered instance of the flat surface types in the order below.
- List them mentally: e.g., countertop 1,2,3,...; diningtable 1,2,...; sidetable 1,...; shelf 1,2,...; sinkbasin 1; stoveburner 1,2,...
- Then visit each one in this order: first all countertops (excluding countertop 1, which you already visited), then all diningtables, then sidetables, then shelves, then sinkbasin, then stoveburner. If any other open flat surface is named, include it.
- For each:
  1. Go to it.
  2. Read the observation. If the target is present, take it immediately using `take <object> from <location>`.
  3. If not, move to the next without extra actions.
- **Warning: Do not skip any flat surface.** Even if many are empty, you must check each one.
- **Do not return to the fridge** – you already saw its contents and the target is not there (unless you missed it, but trust the initial check). Do not re-check the fridge until after you have visited every flat surface.

### If target still not found: search closed receptacles
- Only after you have visited every open flat surface should you open closed receptacles (cabinets, drawers, microwave). The target may be inside a closed container.
- Open each numbered instance systematically: start with cabinets (1,2,...), then drawers, then microwave. For each:
  1. Go to it.
  2. If closed, open it.
  3. Look at its contents. If target present, take it.
  4. Move to next.
- Do not skip any numbered instance.

## Sub-goal 2: Take the object.
- Once you see the object, take it immediately with `take <object> from <location>`.

### Immediately cool after picking (mandatory)
- As soon as you have taken the object, cool it using the fridge before doing anything else. Do not move to the target location or do other actions.

## Sub-goal 3: Cool the object using the fridge.
- Go to the fridge (if not already there).
- If the fridge is closed (it shouldn't be, but open if needed), then use `cool <object> with fridge`.

## Sub-goal 4: Move the cooled object to the target location.
- Go to the target location (named in the task).
- Use `move <object> to <target>`.

## Completion check:
- The task is complete when the object has been cooled and placed at the target location. Trust the sequence.

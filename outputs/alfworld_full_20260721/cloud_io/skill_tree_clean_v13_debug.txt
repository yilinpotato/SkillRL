# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Phase 1: Locate and Take the Target Object
- You must find and pick up [object] before you can clean it.

### Systematic Search of All Receptacles (Mandatory)
- **Read the initial room description carefully.** List every receptacle type present (e.g., cabinet, drawer, fridge, countertop, sinkbasin, shelf, dresser, diningtable, sidetable, garbagecan, bathtubbasin, towelholder, etc.).
- **Search all closed containers first:** cabinets, drawers, fridge. Open every instance and inspect inside. Do not skip any numbers.
- **Then search all open surfaces:** countertops, diningtables, sidetables, sinkbasins, shelves, etc. These often hold objects directly visible.
- **Continue until every receptacle type in the room has been visited and inspected.** Do not stop after checking only cabinets and a few drawers – you must also check countertops, tables, and any other type mentioned.
- **Commonly missed locations:** countertops, dining tables, side tables, shelves. Always include these.

### Container Interaction
- Always open a closed container (cabinet, drawer, fridge) after arriving to inspect its contents. Do not rely on surface observations – a closed container may have items inside.
- For open surfaces (countertops, sinkbasins, tables), you can see what is on them directly without opening.

### Object Name Verification
- Before taking an object, verify that its name matches the task target **exactly** (e.g., "cup" ≠ "mug"; "apple" ≠ "tomato"). If it matches, take it and proceed to Phase 2. If not, continue searching.

### Persistence – Do Not Stop Early
- **The search is not complete until you have visited every single instance of every receptacle type present.** Stopping before finishing all types is the most common cause of failure.
- If you have searched all closed containers and all open surfaces and still not found the object, re-read the initial description to ensure you did not miss a receptacle type.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (typically sinkbasin 1).
- Immediately use "clean [object] with [cleaning_source]".
- Confirm the observation says you cleaned it; if not retry or check you are at the correct source.
- Do not use "look" or "examine" at the sink – only the clean action works.

## Phase 3: Place the Clean Object at Destination
- After cleaning, go to the [destination] specified in the task (e.g., cabinet, diningtable, microwave, toilet).
- Use "move [object] to [destination]" to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop only when counter == 2.

## Critical Rules (violating any means failure)
- **Always start the task with `look`** to get a full list of furniture. Never move before looking.
- **At every item**: if it is closed, open it before examining contents. Do not skip.
- **After placing the first object, your very next action must be `look`** (unless you saw multiple copies at the same source – then use the Shortcut). Do not go to any furniture before this look.
- **Never perform the same action twice in a row without moving** – that is a loop. Force a move to the next item on your current search list.
- **You must follow the search list exactly in order. Do not skip any furniture item**, even if you think it is unlikely to contain the target.
- **Subgoal tracking**: Constantly remind yourself of the current counter value (0 or 1). After each placement, increment counter and immediately start Phase 2.

## Multi-object tracking
- **Counter starts at 0.** After each successful placement, increment counter. If counter == 2, stop. If counter < 2, you **must** continue searching for the next object.
- **After placing the first object (counter=1), your only goal is to find the second object.** Do not pause, look around, or inspect non-target furniture. Immediately transition to Phase 2 below.
- If you ever find yourself stuck (repeating the same action), re-read the goal: you need **two** objects. Use a fresh `look` to get a new search list and start moving.

## Systematic search
- **Initial `look` gives an ordered list of all furniture in the room.** That is your master search list. Visit **every** item in that exact order. Do not skip any.
- At each item: open if closed, examine contents, take target object if present. If you reach the end without finding the target, repeat the list **once more**. After two full passes, the object is absent – stop.
- **After placing the first object**, if you saw multiple copies at the same location, use the Shortcut path (see Phase 2). Otherwise, do **exactly one fresh `look`** to get a new search list and repeat the systematic search for the second object.
- **Do not skip any furniture.** For example, if the target is a cup, you must check countertops, shelves, tables, and any other furniture on the list – not just cabinets. Every furniture item is a potential source.
- Do not stop searching until you have visited every item on the current list (or found the second target).

## Confirm Object Identity Before Picking
- Re-read the target object name from the task description before each pick.
- Only pick up an object whose name exactly matches the target type.
- If unsure, use `look` to see the name.
- If you accidentally take a wrong object, `drop` it immediately and continue search.

## Phase 1 – First Object (counter = 0)
- Execute the **Systematic search** to find and take the first target object.
- After taking it, **go directly to the target receptacle**. Do not place anywhere else.
- At the target receptacle: open if closed, then use `move` to place the object. Counter becomes 1.
- **While holding the object, do not drop it, move it elsewhere, or interact with any other object.**

## Phase 2 – Second Object (counter = 1)
**Immediately after placing the first object, you must find and place the second. Do not stop.** Choose one of two paths:

### Shortcut – Only If Multiple Copies Were at the Same Source
- **Condition:** You saw **more than one** instance of the target object at the exact location where you took the first one (e.g., multiple plates on the same table). If you saw only one copy there, do **not** use this shortcut.
- **Action:** Go back to that same location, take the next copy, go to the target receptacle, and place it. Counter becomes 2. Stop.

### Mandatory Fresh Look After First Placement (unless Shortcut)
- **If Shortcut does not apply, your very first action after placing the first object must be `look`.** This gives you a new, ordered list of furniture to search. Do not go to any furniture before this look.
- After the look, immediately go to the **first item** on that new list. Follow the **Systematic search** exactly to find the second target.
- When you find it, take it, go to the target receptacle, and place it. Counter becomes 2. Stop.
- If you complete two full passes of the fresh list without finding a second target, task impossible – stop.

### Loop Detection & Recovery
- Two consecutive actions of the same type (e.g., `look`, `look` or `open`, `open`) without moving = loop.
- Force a change: go to the next item on your current search list. If no list, do a fresh `look` and go to the first item.
- Do not repeat the same action more than once without moving.

## Avoid Taking Non-Target Objects
- Only touch objects whose name exactly matches the target type.
- If you hold an irrelevant object, drop it immediately and resume search.

# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location.
- The heating appliance is the microwave.

## 2. Locate the object
- Start at the fridge. **Open the fridge** to see its contents. If the target object is inside, take it and go directly to Section 3 (heating).
- If the object is NOT in the fridge, proceed to the **exhaustive search** below.

### 2.1 Critical: Immediate pick-up rule
- **If you observe the target object on any surface (countertop, table, shelf, etc.) or inside an already-open container, take it immediately.** Do NOT continue searching. This rule overrides the order below.

### Exhaustive search (follow in strict order, check *everything*)
1. **Countertops** – go to every countertop you can see. At each, `look` and `take` if the object is present.
2. **Flat surfaces** – from a central location (e.g., fridge), perform a `look`. This reveals all flat surfaces (diningtable, sidetables, shelves, desk, coffee table, etc.). **Visit every one of them** – `look` and `take` if found. Do NOT proceed until every flat surface has been examined.
3. **Openable containers** – again, from a central location, `look` to see all openable containers. Then open and look inside **each one**, in this exact order:
   - Cabinets (open every single cabinet)
   - Drawers (open every drawer)
   - Sinkbasin
   - Garbagecan
   - Microwave
   - Any other openable container (e.g., coffeemaker, toaster)

   **Critical**: For each container, you **must open it** (if closed) before you can see its contents. Use `open`, not `examine`. If the target object is not inside, immediately proceed to the next container. Do not stop until **every container in the list has been checked**.

4. **If still not found** – after exhausting the full list, perform a `look` again. If new receptacles appear, repeat the entire search from step 1. Otherwise, re-read the task to confirm object type. If another room is available, go there and repeat the search. Never give up until every possible receptacle has been examined.

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- Use action `heat <object> with microwave` while holding it. This works reliably.
- If direct heat fails, you can open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is first choice.
- After heating, the object is ready. Do not return it to the microwave.

### 3.2 Prerequisite: Object must be in inventory
- Before attempting to heat, check your inventory (`inventory`). If you are not holding the exact target object, return to section 2 and perform the exhaustive search again.

### 3.3 Critical: Do not drop or place the object before heating
- Once you have picked up the target object, you must go directly to the microwave and heat it. Do NOT move the object to any other location before heating. Dropping it back onto a surface or placing it elsewhere will cause a loop.

## 4. Place the heated object
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, etc.).
- The destination must be different from the source where the object originally came from.
- If the target receptacle is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: `move <object> to <receptacle>`.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (`examine <receptacle>`) and check inventory (`inventory`). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- **Termination rule**: Once placed at the target, stop all actions immediately.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop when counter equals 2, or after two exhaustive full passes without finding a second instance.

## Critical Rules (Must Follow)
- **Object name must match exactly.** Compare the observed object name character by character with the target type. If they differ (e.g., 'soapbottle' vs 'soapbar' or 'candle'), do NOT take it.
- **After taking a matching object, next action must be `go to [target receptacle]`.** No exceptions.
- **After placing an object, restart search from the first furniture item in the observation.** Do not continue searching from your current location.
- **Counter:** Start at 0. Increment by 1 after each successful placement. Stop when counter == 2.

## Phase 1: First Object Search
### Procedure
1. Re‑read the initial observation and list every furniture item in order (use `look` if needed). Include all types: cabinets, drawers, shelves, counters, tables, fridge, sinkbasin, etc. Do not skip any.
2. Visit each item exactly once, in that order. If closed, open it. Examine contents (surface or interior).
3. For each object seen, check if its exact name matches the required type. If yes, take it.
4. After taking, immediate next action: `go to [target receptacle]`. Open if closed, then place the object. Increment counter by 1.
5. If you accidentally take a non‑matching object, drop it immediately and resume search from the current furniture item.
6. If you finish the list without taking any object, perform a second full pass (repeat step 2 from first item). After two full passes and counter still 0, task impossible – stop.

## Phase 2: Second Object Search (After First Placement)
### Must Restart Full Search
- Immediately after placing the first object, use `look` to get the current observation and list every furniture item again. Include all types.
- Visit every item in that list, exactly as in Phase 1, in order. Do not rely on memory of where you found the first object.
- Continue until counter reaches 2, or until you have completed two full passes after the first placement with no second object.
- If you catch yourself revisiting the same few locations without finding a second object, stop, re‑read the observation, restart the systematic search from the first item.

## Failure Prevention
### Exhaustive Search
- Before any search (first or second object), list all furniture items from the current observation. Then visit each in order, one by one.
- Open all closed receptacles (drawers, cabinets, fridge, etc.) when you visit them. Do not skip any.
- Check every furniture type listed – surfaces, containers, shelves, tables, basins, etc. Do not focus only on one type.
- If you have visited all items and found nothing, do a second full pass before giving up.

### Object Type Verification
- Before taking any object, read its exact name. Compare it to the task's target type character by character. Only take if they match exactly.
- If you take a non‑matching object by mistake, drop it immediately (`drop [object]`) and resume searching from the same furniture item.

### Multi‑Object Count Completion
- After placing one object, you must find a second. Do not stop until counter == 2, or until two full searches after the first placement yield nothing.
- If you have placed one object and then complete two full passes without finding a second, the task is impossible – stop.

### Object Count Tracking
- Keep a mental counter. Start at 0.
- Increment by 1 after each successful placement.
- Stop when counter == 2 – task complete.
- If counter == 0 after two full passes, stop (impossible).
- If counter == 1 after two full passes following first placement, stop (impossible).

## Stop Condition
- counter == 2 → success (task complete).
- counter == 1 after two full passes following first placement → impossible (stop).
- counter == 0 after two full passes in initial search → impossible (stop).

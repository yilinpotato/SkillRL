# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop when counter equals 2.

## Counter & Completion Rules
- Start counter at 0.
- After each successful placement, increment counter by 1.
- If counter == 2, task complete – stop immediately.
- If counter < 2, you MUST continue searching for the next object. Never stop after a single placement.
- After two exhaustive full passes (in either Phase 1 or Phase 2) without finding a needed object, task is impossible – stop.

## Critical Rules (Must Follow)
### Before Every Movement – Look and List
- Perform `look` to get the current observation. List every furniture item in the order they appear. This list is your search plan. Deviating from this plan leads to loops and missing objects.
- If you are already at a location, you still need a plan – if you haven't listed the furniture, do a fresh `look`.

### When You Arrive at a Furniture Item
- If the item is closed (e.g., cabinet, drawer, fridge), **open it** first.
- Examine its contents for the target object.
- **If you see an object whose name exactly matches the target, take it immediately.** Do not move away before picking it up.

### After Taking a Matching Object
- **Next action must be `go to [target receptacle]`.** No exceptions.
- At the target receptacle, open if closed, then place the object. Increment counter.

### After Placing an Object
- Increment counter. If counter == 2, stop – success.
- If counter == 1, you **must** find the second object. Do not stop or loop.
- **Assess whether you saw multiple instances at the pickup location** (e.g., "cellphone 3, cellphone 4"). If yes, go back to that same location immediately and take the next instance. Then go place it.
- **Otherwise, perform a Full Restart:** Execute `look` to get a fresh observation. List every furniture item in the order they appear. Visit each in that exact order, opening closed receptacles and checking contents.
- If you complete the full restart list without finding a second object, perform a second full pass. If after two full passes counter is still 1, task impossible – stop.

### Object Type Verification
- Before taking any object, read its exact name. Compare to the target type character by character. Only take if they match exactly.
- If you take a non‑matching object by mistake, drop it immediately (`drop [object]`) and resume searching from the same furniture item.

### Loop Detection and Breaking
- If you find yourself repeatedly visiting the same few furniture items without covering the full list, you are in a loop. Stop immediately and perform a fresh `look` to rebuild your search plan.
- Always ensure your search covers all furniture types – not just one category (e.g., only cabinets or only drawers).

## Phase 1: First Object Search (Counter = 0)
- Execute `look` immediately. List all visible furniture.
- Visit each item in that exact order. For each:
  - Open if closed.
  - Check contents for target object.
  - If found, take it, go to target receptacle, place it. Increment counter to 1.
- **Exhaustive Search:** If you finish the list without taking any object, perform a second full pass (repeat from first item). After two full passes and counter still 0, task impossible – stop.

## Phase 2: Second Object Search (Counter = 1)
### Immediate Action After Placement
- Increment counter to 1. (If it becomes 2, stop.)
- Now you must find the second object.

### Decision: Where to Look Next
1. **Check if multiple copies were available at the original pickup location.** If yes (e.g., you took "book 1" from a bed that also had "book 2"), go back to that same location immediately and take the next matching instance. Then go place it. Counter becomes 2. Stop.
2. **Otherwise, perform a Full Restart:**
   - Execute `look` to get a fresh observation. List every furniture item in the order they appear.
   - Visit each item in that exact order, opening closed receptacles and examining contents.
   - When you find a second target object, take it, go to target receptacle, open if needed, place it. Increment counter to 2. Stop.
3. If you complete the full restart list without finding a second object, perform a second full pass. If after two full passes counter is still 1, task impossible – stop.

### Important
- If you return to the original pickup location and find no second object there, continue with the full restart list – do not stop.

## Failure Prevention (Reminders)
- **Always open closed receptacles** when you visit them. Do not skip any.
- **Check every furniture type** – surfaces, containers, shelves, tables, basins, stoveburners, armchairs, beds, etc.
- **After placing one object, you must find a second.** Do not stop until counter == 2 or two full searches yield nothing.
- **Take objects immediately when seen.** Do not move away without picking them up.
- **If you ever repeat the same action without covering new ground, do a fresh `look` and restart the list.**

# Goal: Examine a target object using a light source (e.g., desklamp)

## Phase 1: Locate the light source
- Identify the light source (typically a desklamp) from your current observations or initial room description.
- If you are not already at its location, move there (e.g., go to the receptacle containing the desklamp).

## Phase 2: Turn on the light
- Use the desklamp (action: use desklamp) to turn it on.
- Confirm the light is on (observation will say "You turn on the desklamp").

## Phase 3: Locate the target object
- After turning on the lamp, check what is on the same surface (the lamp's receptacle). If the target object is there, proceed to Phase 4.
- If the target object is NOT on the lamp's surface, systematically search all other common furniture in the room (bed, dresser, sidetable, shelf, desk, etc.). 
  ### Systematic search procedure
  - List each piece of furniture you have observed (from the initial room description) that could hold objects. Prioritize surfaces you haven't visited yet.
  - For each candidate surface, go to it (action: go to <receptacle>) and examine its contents.
  - If the target object is found on that surface, proceed to Phase 4.
  - If not, move to the next candidate. Do not open drawers or containers unless no surface holds the object; the task expects the object to be in plain sight on a surface.
- Only after all visible surfaces have been checked should you consider opening closed containers (drawers, cabinets) as a last resort.

## Phase 4: Take and examine the target object
- Take the target object from its receptacle (action: take <object> from <receptacle>).
- The task is considered complete once the object is in your inventory and the light is on.

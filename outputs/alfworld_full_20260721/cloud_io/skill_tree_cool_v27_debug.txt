# Goal: Cool an object and move it to a specified target location.

## Object Search and Retrieval

### Exhaustive Search
1. **Re-read the room description** from the prompt. Note all receptacle types and their instance numbers.
2. **Search surfaces in this fixed order:**
   - countertops (all numbered instances)
   - diningtables
   - sidetables
   - shelves
   - sinkbasin
   - stoveburners
   
   For each instance: go to it, read the objects listed. If you see the exact target object name, take it immediately and proceed to Phase 2. If the receptacle is open (e.g., sinkbasin), check inside. If closed, only note it – do not open yet.
3. **After all surfaces are searched** (you have visited every instance of the six categories above and the object is not found), proceed to **closed receptacles** in this order:
   - fridge
   - cabinets
   - drawers
   - microwave
   
   For **each instance** of each category:
   - Go to it.
   - If it is closed, open it.
   - Look inside and take the object if present.
   - **Do not stop** until you have opened and checked every instance of every category. For example, check cabinet 1, cabinet 2, … all drawers, and the microwave.
4. **If you accidentally go to a category that is not the next one in the sequence**, immediately go to the correct next category (do not backtrack to earlier ones).
5. **If after all surfaces and all closed receptacles you still have not found the object**, it is absent (but this should not happen in valid tasks).

### Prioritize Common Locations
- When searching closed receptacles, start with the fridge (common for perishable items), then cabinets, drawers, microwave. This order reflects typical likelihood based on object type.
- For non-food objects, still follow the same order; the priority is a heuristic, not a rule.

## Phase 2: Cool the object using the fridge
- After picking up the object, go directly to the fridge.
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Phase 3: Move the cooled object to the target location
- Go to the target location.
- If the target receptacle is closed, open it first.
- Use `move <object> to <target>`.

## Completion check
- Object is cooled and placed at the target location – task complete.

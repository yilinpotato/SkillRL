# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop when counter equals 2.

## Completion Counter
- Start counter at 0.
- After each successful placement, increment counter by 1.
- If counter == 2, task complete – stop.
- If counter < 2, you MUST continue searching for the next object.

## Critical Rules (Must Follow)

### Before Every Movement – Build a Complete Search Plan
- Perform `look` to get the current observation. List **every** furniture item in the order they appear. This list includes all types: cabinets, countertops, drawers, tables, shelves, beds, etc.
- This list is your search plan. You must visit each item in that exact order, **including all furniture types**, not just the first few types you see. Deviating leads to loops.
- If you are already at a location and haven't listed, do a fresh `look`.

### When You Arrive at a Furniture Item
- If the item is closed (e.g., cabinet, drawer, fridge), **open it** first.
- Examine its contents for the target object.
- **If you see an object whose name exactly matches the target, take it immediately.** Do not move away.

### After Taking a Matching Object
- **Next action must be `go to [target receptacle]`.** No exceptions.
- At the target receptacle, open if closed, then place the object. Increment counter.

### After Placing an Object
- Increment counter. If counter == 2, stop – success.
- If counter == 1, you **must** find the second object. **Do not stop or loop.**
- Immediately determine the next step:
  1. **If you saw multiple copies at the original pickup location** (e.g., "cellphone 3, cellphone 4"), go back to that same location immediately and take the next instance. Then go place it.
  2. **Otherwise, perform a Full Restart:** Execute `look` to get a fresh observation. List every furniture item in the order they appear. Visit each in that exact order, opening closed receptacles and checking contents. When you find a second target object, take it, go to target receptacle, place it. Increment counter to 2. Stop.
- If you complete the full restart list without finding a second object, perform a second full pass. If after two full passes counter is still 1, task impossible – stop.

### Object Type Verification
- Before taking any object, compare its exact name to the target type. Only take if they match exactly.
- If you take a non‑matching object by mistake, drop it immediately (`drop [object]`) and resume searching from the same furniture item.

### Loop Detection and Breaking
- If you find yourself repeatedly visiting the same few furniture items without covering the full list, you are in a loop. Stop immediately and perform a fresh `look` to rebuild your search plan.
- If you have opened several containers of the same type (e.g., 3 cabinets) and found nothing, you must continue to the next furniture type on your list. **Do not keep opening more of the same type** – the list ensures you cover all types.
- Always ensure your search covers all furniture types – not just one category.

## Phase 1: First Object Search (Counter = 0)
1. Execute `look` immediately. List all visible furniture items. This is your search order.
2. Visit each item in that exact order. For each:
   - Open if closed.
   - Check contents for target object.
   - If found, take it, go to target receptacle, place it. Increment counter to 1.
3. **Exhaustive Search:** If you finish the list without taking any object, perform a second full pass (repeat from first item). After two full passes and counter still 0, task impossible – stop.

### During Phase 1 Search – Adaptive Search
- If you have opened 3 or more containers of the same type (e.g., cabinet, drawer) in a row without finding the target, re-check your list: you must have other furniture types listed. Move to the next type on the list immediately. Do not exhaust all containers of one type before trying others.
- This prevents getting stuck on a long sequence of empty cabinets.

## Phase 2: Second Object Search (Counter = 1)
### Immediate Action After Placement
- Counter becomes 1. (If 2, stop.)
- Now you must find the second object.

### Decision: Where to Look Next
1. **Check if multiple copies were available at the original pickup location.** If yes, go back and take the next instance, then place it. Counter becomes 2. Stop.
2. **Otherwise, perform a Full Restart:**
   - Execute `look`. List every furniture item.
   - Visit each in order, opening and checking.
   - When you find a second target object, take it, go to receptacle, place it. Counter becomes 2. Stop.
3. If you complete the full restart list without finding a second object, perform a second full pass. If after two full passes counter is still 1, task impossible – stop.

### Important
- If you return to the original pickup location and find no second object there, continue with the full restart list – do not stop.
- **Goal quantity tracking:** After placing the first object, your counter is 1. You must actively search for the second. Never assume the task is done or stop after one placement. If you are unsure, re-read the goal.

## Multi-Object Handling
- After placing the first object, you MUST immediately begin searching for the second. Do not return to previous actions or stand still.
- If the original location had only one instance of the target, perform a **Full Restart** as described in Phase 2. Do not attempt to reuse the old list; fresh `look` is mandatory.
- If multiple copies were visible at the original location, go directly back and take the next one. Then place it. Do not search elsewhere.
- After placing the second object, verify counter is 2 and stop. If counter is still 1 after searching all possibilities, declare task impossible.

## Locate Object (Systematic Search)
- When you need to find an object (first or second), always start with a `look` to get a full list of all furniture items in the room.
- Visit each item in the exact order listed. Do not skip any item, even if it seems unlikely.
- For each item: open if closed, then examine its contents. If you see the target object, take it immediately and proceed to place it.
- If you finish the list without finding the target, perform a second full pass. Only after two complete passes should you consider the object absent.
- Do not get stuck on a single type of furniture; the list ensures you cover all types. If you have opened many of one type with no success, move to the next type in the list.

## Failure Prevention (Reminders)
- Always open closed receptacles.
- Check every furniture type – surfaces, containers, shelves, tables, etc.
- Take objects immediately when seen.
- If you ever repeat the same action without covering new ground, do a fresh `look` and restart the list.

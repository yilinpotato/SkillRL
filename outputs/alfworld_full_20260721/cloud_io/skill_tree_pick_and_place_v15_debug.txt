# pick_and_place skill tree

## Goal
You must pick up a specific object and place it into or onto a specified receptacle. The task description states both the object and the target (e.g., "put a book in sofa").

## Exploration Strategy

### Visit All Visible Receptacles
- Use **only the initial room observation** to create your complete list of receptacles. Write down every name exactly as it appears. Do **not** add receptacles encountered later.
- Include ALL types: cabinets, drawers, shelves, tables, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubbasins, handtowelholders, towelholders, toilet, toiletpaperhanger, garbagecan, beds, and any other furniture mentioned. **Include the target receptacle itself.**
- **Follow this strict sequential order. Do not skip any category or receptacle:**
  1. **Target receptacle** – the object might already be on it. Go there first.
  2. **All open surfaces** – tables, desks, shelves, countertops, beds, armchairs, sofas, sidetables, dressers (top), etc. These are visible without opening. **Visit every one of them** before moving to closed containers. Do not skip any, even if the object type suggests a different location.
  3. **All closed containers** – drawers, cabinets, safes, fridges, etc. Open each before examining. **Open and examine every single closed container** on your list. Do not stop after opening a few.
- **Checklist approach:** After each visit, mentally check that receptacle off your list. When you finish all closed containers, verify you have checked every receptacle on your initial list. If any are missing, go back to them immediately.
- For each receptacle:
  - Go to it using `go to <receptacle>` (do **not** use `examine` or `look` – the observation appears automatically upon arrival).
  - If closed, open it (`open <receptacle>`) before reading what is inside/on it.
  - Read the observation. If you see the target object, use `take <object> from <receptacle>`. Then proceed immediately to step 3 (placement). **Do not continue searching.**
  - If not found, mentally check that receptacle off your list and move to the next.
- **After completing all receptacles, if still not found, re-read the initial room observation to ensure you didn't miss any. Then revisit any you might have skipped. Do not give up until every single receptacle on the initial list has been visited.**

### Comprehensive Furniture Check
- **Create a list:** Immediately after reading the initial room observation, write down every receptacle name exactly as it appears. Include all furniture types: cabinets, drawers, shelves, tables, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubbasins, handtowelholders, towelholders, toilet, toiletpaperhanger, garbagecan, beds, and any other mentioned. **Do not miss any.**
- **Visit in order:** Start with the target receptacle, then all open surfaces, then all closed containers. For each receptacle on your list, use `go to <receptacle>`. If closed, open it first. Read the observation. If you see the target object, take it. If not, mentally check it off and proceed to the next.
- **Do not skip:** Even if you think the object is unlikely to be on a particular surface or inside a particular container, visit it anyway. **Every receptacle on the initial list must be checked.**
- **After completing the list:** If you have not found the object, re-read the initial observation to ensure you didn't miss any receptacle, then repeat the entire sequence.

### Container Prioritization within a Category
- When searching open surfaces or closed containers, use object type to **order** your search within that category, but **never skip an entire category or receptacle**.
  - **Electronics** (cellphone, alarm clock, laptop, tablet): often on desks, shelves, tables, or dressers.
  - **Utensils** (butterknife, spoon, fork, knife): typically on countertops or in drawers/cabinets. For open surfaces, check countertops first; for closed containers, check drawers first.
  - **Toiletries** (toiletpaper, soap, spraybottle, toothpaste): usually in bathroom cabinets, drawers, or near sinks, toilet paper hanger, towel holder.
  - **Clothing** (towel, cloth, handtowel): on towel holders, laundry hamper, beds, dressers.
  - **Paper/office** (book, cd, creditcard, pen, pencil, keychain): anywhere – surfaces, drawers, shelves.
- **Remember: the object type guess is only a hint for ordering. You must still visit all receptacles in the category regardless.**

### Container Type Coverage
- You must visit **every type** of receptacle present in the initial observation: cabinets, drawers, shelves, tables, countertops, sinks, bathtubbasins, etc. No type is guaranteed to be empty or irrelevant.
- Common omission: after checking a few drawers, agents skip cabinets; after checking cabinets, they skip drawers. **Do not omit any container type.** The target may be in a type you haven't examined yet.
- Start with the target receptacle, then all open surfaces, then all closed containers. Within each type, go through every instance.

### Iterative Re-examination
- If you have visited every receptacle on the initial list and still not found the object, **repeat the entire sequence** (target, open surfaces, closed containers). You might have overlooked the object in a previous observation.
- Pay special attention to open surfaces: the object may be sitting on a table or shelf that you visited earlier but didn't read carefully.
- If you see a receptacle you skipped (e.g., you forgot to go to a sinkbasin listed in the initial observation), go there now.
- Do **not** settle for a partial search. Only stop when you have either found the object or completed two full passes of the entire receptacle list.

## Sub-Goal Flow

### 1. Parse the task
Identify two entities: the **target object** (what to pick) and the **target receptacle** (where to place it). Keep these in mind throughout.

### 2. Locate the target object

#### 2.1 List all receptacles
Refer to the initial room observation and follow the procedure in **## Exploration Strategy**. Write down the full list.

#### 2.2 Perform an exhaustive, sequential search
Follow the search order described in **## Exploration Strategy – Visit All Visible Receptacles**. The key is to visit every receptacle from the initial observation without skipping any category. Use the checklist approach.

#### 2.3 Use object type to guess likely locations (but only to prioritize within a category)
- Use the guidelines in **Container Prioritization** above.

### 3. Verify and pick up
- Before picking up any object, **confirm that its name exactly matches the target object** (e.g., if task says "cloth", do not pick "handtowel"; if task says "spraybottle", do not pick "soapbottle"). If there is any mismatch, do not take it.
- **Exact match is required** – synonyms are not acceptable. For example, "handtowel" is not "cloth", "towel" is not "cloth", "soapbar" is not "soapbottle", "winebottle" is not "glassbottle". When in doubt, re-read the task description and the observed object name.
- Once confirmed, use `take <object> from <receptacle>` to pick it up.
- If you are already carrying something else and it is not the target, you may drop it (not typical, but avoid carrying wrong items).

### 4. Navigate to the target receptacle
- After successfully picking up the target object, move to the target receptacle (e.g., "sofa 1", "toilet 1", "garbagecan 1") using `go to <receptacle>`.

### 5. Place the object
- When you arrive at the target receptacle, immediately execute `move <object> to <receptacle>`.
- Do **not** perform any other actions (like examining or going away) before placing; placing is the final required action.

### 6. Termination
- After the `move` action, the task is complete. No further actions are needed.

## Common Mistakes to Avoid
- **Wrong action type:** Never use `examine <receptacle>` or `look` to see surroundings. Use `go to <receptacle>` to move – the observation appears automatically. `look` wastes a step and does not move you.
- **Wrong object pickup:** Always re-verify the object name in the observation before using `take`.
- **Incomplete search – skipping an entire category:** Do not start opening drawers until you have visited **all** open surfaces. The object is often on a surface you skipped.
- **Incomplete search – skipping some receptacles within a category:** Even if a few surfaces or containers are empty, continue until every one from your initial list is checked. Stopping early is the most frequent reason for failure.
- **Skipping the target receptacle as a search location:** The object might already be on the target receptacle. Always check it first.
- **Using receptacles not in the initial list:** The initial room observation is the only source of all receptacles. If you start going to a receptacle that was not in that first description, you are wasting steps. Stick to your initial list.
- **Giving up too early:** If you have not found the object after checking many receptacles, do not stop until you have visited every single one on your list. Patience is required.
- **Missing the placement step:** Arriving at the target is not enough; you must explicitly `move` the object.
- **Failing to open closed containers:** When you go to a closed container, you must explicitly use the `open` action. Simply going there does not show the contents.
- **Failure to close containers:** After opening and checking a closed container, it is not necessary to close it, but be aware that some containers may need to be closed before you can interact with them later (unlikely in this task).

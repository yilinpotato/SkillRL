# pick_and_place skill tree

## Goal
Pick up a specific object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search every visible receptacle systematically.
3. **Verify and take** – only take the object if its name matches exactly.
4. **Navigate to target receptacle** and move the object there.
5. **Terminate** after placement.

## Exploration: Systematic Object Search
### Prioritize Surface Search over Container Search
Before opening any closed container, you must have visited every open surface (tables, countertops, shelves, sidetables, etc.). If you arrive at a closed container, do not open it yet – go to an open surface first. Only after all open surfaces have been checked should you start opening closed containers (drawers, cabinets, etc.).

### 1. Create a checklist
From the **first room observation** (after `look` or upon arrival), list every receptacle name exactly as it appears. Write them down. Include ALL furniture: tables, cabinets, drawers, shelves, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubs, holders, etc. Do not skip any.

### 2. Visit receptacles in order
Start with the **target receptacle** (the object might already be there). Then visit **all open surfaces** (tables, shelves, countertops, etc.) before moving to closed containers. For each receptacle:
- Use `go to <receptacle>`. The observation appears automatically.
- If the receptacle is closed, `open <receptacle>` first.
- Read the observation. If you see the target object, `take <object> from <receptacle>` and proceed to step 3.
- If not found, mentally check it off and go to the next.

### 3. After completing the list
If you have visited every receptacle and not found the object, **repeat the entire sequence** once more. Pay special attention to items you might have overlooked. Only give up after two full passes.

## Common Mistakes
- **Skipping any receptacle** – all must be checked, even if unlikely.
- **Using wrong action** – never `examine` or `look` to move; use `go to`.
- **Taking wrong object** – confirm exact name (e.g., "handtowel" ≠ "cloth").
- **Failing to open** closed containers before reading contents.
- **Forgetting to place** – after taking, go to target and `move <object> to <receptacle>` immediately.
- **Wasting time** – do not close containers or perform extra actions.

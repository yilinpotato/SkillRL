# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle. Stop only when counter == 2 or after two exhaustive passes without finding a second object.

## Overall Procedure

### Initial Search (before any placement)
1. **Re-read the initial observation** – the furniture list from the start of the task.
2. **Mentally list every furniture item** in the exact order they appeared. Include all surfaces and containers. Do not skip any type.
3. **Visit each item in that order exactly once.** For each:
   - If closed, open it.
   - Examine contents (surfaces: just look; containers: look inside).
   - If you see an object whose exact name matches the required type, **verify the type**, then **take it immediately**.
   - **After taking a matching object, your very next action MUST be `go to [target receptacle]`.** Do not open, look, or move anywhere else first.
   - Then open the receptacle if closed, and place the object (`move` or `put` action).
   - Increment counter by 1.
   - If counter == 2, stop – task complete.
   - Otherwise, **immediately begin the Post-Placement Search** below (do not finish the current pass).
4. If you finish the list and counter is still 0, perform a **second full pass** – repeat step 3, again visiting every item in the same order.
5. After two full passes, if counter == 0, the task is impossible – stop.

### Post-Placement Search (after placing first object)
- **Reset your mental list** – re-read the initial observation and rebuild the list in the same order.
- **Perform step 3 exactly as above**, starting from the first item and visiting each exactly once.
- If you find a second matching object, take it, go directly to target, place it, increment counter to 2, and stop.
- If you finish the list and counter == 1, perform a **second full pass** (repeat the list again).
- After two full passes with counter still 1, the task is impossible – stop.

## Immediate Rules (Must Follow)
- **Counter:** Start at 0. After each successful placement, increment by 1. If counter == 1, continue. If counter == 2, stop.
- **After picking up a matching object, your very next action MUST be `go to [target receptacle]`.** No exceptions.
- **Do not stop after placing only one object.** Immediately begin the Post-Placement Search.
- **If you accidentally take a non-matching object, drop it immediately** and resume the search from where you left off.

## Failure Prevention
- **Stopping early:** If you catch yourself not searching after placing one object, re-read the initial observation and restart the systematic search from the first furniture item.
- **Looping:** If you revisit the same few locations without taking a target object, stop, re-read the observation, rebuild the mental list, and restart from the first item.
- **Skipping furniture types:** The target object may be on any surface or inside any container. Follow the mental list order; do not only check drawers or only shelves.
- **Opening target receptacle:** When placing, if the target is closed, open it first.

## Stop Condition
- counter == 2 -> success
- counter == 1 after two full passes following first placement -> impossible, stop.
- counter == 0 after two full passes in initial search -> impossible, stop.

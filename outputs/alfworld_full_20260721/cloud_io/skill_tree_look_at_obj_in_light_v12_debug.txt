# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- Search the surfaces you can see at your current location for a desklamp. If you see one, note its location and move there if necessary.
- If no desklamp is visible, move to another surface receptacle (e.g., desk, dresser, sidetable, shelf, bed, etc.) and check its contents. Continue moving among receptacles until you find a desklamp.
- Once you are at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- Important: You may encounter the target object before finding the lamp. If that happens, remember where it is and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Phase 2: Locate and take the target object
- After the lamp is on, your next task is to find the target object. Do **not** waste actions on 'look' or exploring without moving – instead, systematically visit every receptacle you know about.

### Systematic Search Procedure
1. **List all receptacles** from the initial room description (e.g., desk, sidetable, bed, dresser, shelf, drawer, cabinet, etc.). The order among receptacles does not matter as long as you visit each one.
2. **Start with the receptacle that holds the desklamp** – the target may be there.
3. **Visit every other surface receptacle** (open surfaces like desk, sidetable, bed, dresser, shelf, etc.) one by one. At each, read the observation – if the target object is present, take it (action: take <object> from <receptacle>).
4. **If the target is still not found, proceed to containers** (drawers, cabinets):
   - For each container, use the 'open' action (e.g., open drawer 1). Then check its contents in the observation. If the target is inside, take it.
   - Open every drawer and cabinet you have not yet examined. Do not skip any, even if the container is on a receptacle you already visited.
5. **Do not repeat receptacles** – once you have visited a receptacle (and opened any containers on it), move on. If you had already spotted the target object earlier (e.g., during lamp search), go directly to its location and take it.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required.
  (If you wish, you may use the examine action on the object, but it is not necessary for success.)

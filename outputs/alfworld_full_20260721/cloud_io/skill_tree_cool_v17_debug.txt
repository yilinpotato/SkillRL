# Goal: Cool an object and move it to a specified target location.

## Sub-goal 1: Find the object to cool.

### Initial assessment
- Use the `look` command to obtain the full room description. It lists every receptacle by type and number.
- If you have already done this (e.g., from the starting prefix), **re-read it now** to refresh the complete list of surfaces and containers. This list is your definitive guide for where to search.
- Do not assume any receptacle contents are known until you have explicitly looked inside.

### Systematic surface search (mandatory, do not skip)
- The target object is very often on a flat surface (countertop, diningtable, sidetable, shelf, sinkbasin, stoveburner). Check every flat surface listed in the room description **before** opening any closed receptacle.
- **Order of search (strict – do not skip or jump ahead):**
  1. All countertops (numbered instances) – check every instance before moving on.
  2. All diningtables – check every instance.
  3. All sidetables – check every instance.
  4. All shelves – check every instance.
  5. Sinkbasin – check the single instance.
  6. Stoveburners – check every instance.
- **Crucial: Maintain a mental checklist of categories in this order. Do not proceed to a later category (e.g., sinkbasin or stoveburners) until you have finished all earlier categories.** Skipping categories leads to missed objects.
- For each numbered instance:
  1. Go to it.
  2. Read the observation. If the target object is present, take it immediately using `take <object> from <location>`.
  3. If not, move to the next instance.
- **Crucial: Keep a mental record of which instances you have already visited.** Do not revisit a location unless you have a specific reason (e.g., you need to use it later for cooling). Revisiting wastes time and leads to loops.
- **Warning**: Opening a closed receptacle or jumping to a later category before finishing the flat surface scan will cause you to miss the object and often leads to failure. Stick to the order above.

### Search closed receptacles (only after all flat surfaces checked)
- If the target is still not found, search closed receptacles. Start with the fridge (because it may contain items that need cooling).
- **Important**: Use only the `open` action to reveal contents. Do **NOT** use `look` or `examine` – they do not show interior contents. Only `open` on a closed receptacle shows what is inside.
- For each closed receptacle (fridge, cabinets, drawers, microwave):
  1. Go to it.
  2. If closed, open it.
  3. Read the observation. If target present, take it.
  4. If not, move to the next instance.
- Check every numbered instance of each type. Use the room description to know which closed receptacles exist.

### If still not found
- Re-read the room description to ensure you did not overlook any receptacle. Possibly you missed a flat surface or closed receptacle type. Re-check any category you might have skipped.

## Sub-goal 2: Take the object.
- Once you see the target, take it immediately.

### Immediately cool after picking (mandatory)
- As soon as you have taken the object, go to the fridge and cool it before doing anything else. Do not move to the target location first.

## Sub-goal 3: Cool the object using the fridge.
- Ensure you are at the fridge.
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Sub-goal 4: Move the cooled object to the target location.
- Go to the target location (named in the task).
- Use `move <object> to <target>`.

## Completion check:
- The task is complete when the object has been cooled and placed at the target location.

# pick_and_place skill tree

## Goal
Pick up a specific object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search every visible receptacle systematically.
3. **Verify and take** – only take the object if its name matches exactly.
4. **Navigate to target receptacle** and move the object there.
5. **Terminate** after placement.

## Exploration: Systematic Object Search
### Rule: Visit Every Receptacle – No Skipping
From the **first room observation** (after `look` or upon arrival), list every receptacle name exactly as it appears. Include ALL furniture: tables, cabinets, drawers, shelves, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubs, holders, fridges, microwaves, ovens, dishwashers – any container that could hold objects. Do not skip any, even if they seem unlikely. Keep this list in mind and tick off each as you visit it.

### Step-by-step search order
1. **Start at the target receptacle** (the object might already be there).
2. Then visit **all open surfaces** – this includes tables, shelves, countertops, sidetables, **armchairs, sofas, beds, dresser tops, desk tops, and any other furniture that can hold objects on its surface**. These are quick to check and often contain the object.
3. After exhausting open surfaces, **open and inspect every closed container** (drawers, cabinets, fridges, microwaves, ovens, dishwashers, etc.).
4. For each receptacle:
   - Use `go to <receptacle>`. The observation appears automatically.
   - If the receptacle is closed, `open <receptacle>` first.
   - Read the observation. If you see the target object, `take <object> from <receptacle>` and proceed to step 3 of the sub-goal flow.
   - If not found, mentally check it off and go to the next.

### If not found after first pass
- **Immediately repeat the entire sequence** – do not assume the object is absent. Start from the beginning of your list (target receptacle, then open surfaces, then closed containers) and visit each one again. Pay special attention to receptacles you might have overlooked.
- After two full passes, **check all closed containers again**, especially fridges, microwaves, ovens, dishwashers, and any cabinet/drawer not yet opened. These are common hiding spots.
- Re-read your initial observation to ensure you did not miss any receptacle name. If still missing, start a third pass – **do not give up early**.

### Common Mistakes
- **Skipping any receptacle** – all must be checked, even if unlikely. Do not assume a surface is empty without visiting it.
- **Using wrong action** – never `examine` or `look` to move; use `go to`.
- **Taking wrong object** – confirm exact name (e.g., "handtowel" ≠ "cloth").
- **Failing to open** closed containers before reading contents.
- **Forgetting to place** – after taking, go to target and `move <object> to <receptacle>` immediately.
- **Wasting time** – do not close containers or perform extra actions.

### Object Verification
Before using `take`, always verify that the object's name matches the target exactly. Read the observation carefully. If the name is even slightly different (e.g., target is "spraybottle" but you see "tissuebox"), **do not take it**. Picking up the wrong object wastes time and may make the task impossible. If you accidentally pick the wrong object, you cannot place it as required; you must drop it or continue searching – but prevention is far better.

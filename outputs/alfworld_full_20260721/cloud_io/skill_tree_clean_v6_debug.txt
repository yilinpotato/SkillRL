# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]".
- Remember that [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as the nearest sinkbasin or bathtubbasin (usually sinkbasin).

## Phase 1: Locate and Take the Target Object
- You must find and pick up [object] before you can clean it. Do not assume it is in any specific place.

### Systematic Search Strategy
- Immediately after starting, list all receptacle types visible in the initial observation (e.g., cabinet, drawer, fridge, countertop, sinkbasin, bathtubbasin, shelf, dresser, garbagecan, towelholder, etc.).
- **Search strictly in this order**: cabinets → drawers → fridge → countertops → sinkbasin and bathtubbasin → shelves → dressers → any other type (e.g., garbagecan, towelholder, handtowelholder, toiletpaperhanger).
- For each type, visit **every instance** of that type before moving to the next type.
- **Critical rule: Never skip a type or stop early. Only stop searching after you have checked the last type ("any other type") in the order.**

#### Search Checklist (execute step by step)
1. **Cabinets**: For each cabinet number (1, 2, ...), if it is closed, use `open cabinet N` first, then check contents. If object present, take it and proceed to Phase 2. Otherwise, go to next cabinet.
2. **Drawers**: Same process: open each drawer if closed, then check.
3. **Fridge**: Open fridge, check contents. If food object, may be there.
4. **Countertops**: Check each countertop (they are open surfaces; no need to open). Look at observation for items on it.
5. **Sinkbasin / Bathtubbasin**: Check each sinkbasin and bathtubbasin (they are open receptacles).
6. **Shelves**: Check each shelf (open).
7. **Dressers**: Check each dresser (open).
8. **Any other type** (e.g., garbagecan, towelholder, handtowelholder, toiletpaperhanger): Check each instance.

- **After each type, mentally mark it as completed. Do NOT return to it.**
- If you ever become lost or unsure, re-scan the room description for any receptacle type you may have missed.

### Rules for Uninterrupted Search
- **Do not stop** until you have visited every receptacle type in the order and every instance within each type.
- If you find a non-target object, **ignore it**. Do not take it. Continue to the next instance or next type.
- Once you have finished a type (e.g., all cabinets), **do not go back** to that type. Move immediately to the next type in the list.
- If you ever find yourself revisiting a receptacle you already searched, **correct** by moving to the next unchecked type. Do not linger.
- Keep a mental checklist of which numbers you have visited (e.g., if the initial observation listed cabinets 1 through 10, you must visit all of them).

### Object Name Verification
- Before taking an object, verify that its name matches the task's target **exactly** (e.g., "cup" is not the same as "mug"; "apple" is not the same as "tomato").
- If the name matches, use "take [object] from [receptacle]" and proceed to Phase 2.
- If the name does not match, continue searching – do not take it.

### Exhaustive Search Checklist
- **After each type**, check that you have visited every instance (e.g., all cabinets 1..N, all drawers 1..M).
- Once you are carrying [object], proceed to Phase 2.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (typically sinkbasin 1).
- Upon arrival, immediately use "clean [object] with [cleaning_source]".
- Confirm the observation says you cleaned it; if not, retry or check that you are at the correct source.
- **Do not** use "look" or "examine" at the sink – only the clean action works.

## Phase 3: Place the Clean Object at Destination
- After cleaning, go to the [destination] specified in the task (e.g., cabinet, diningtable, microwave).
- Use "move [object] to [destination]" to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

## First Object Search
- Read the room description and list every visible furniture item.
- Visit each furniture item. If closed, open it. Examine contents. If you find an object whose exact name matches the required type, take it.
- Go directly to the target receptacle and place it.

## Critical: After Placing the First Object, Start the Second Search Immediately
- **DO NOT STOP.** You must place a second matching object. The task is only complete when you have placed two.
- If you already know where the second object is (e.g., you saw it earlier), go directly to that location, take it, and place it.
- Otherwise, perform a **full search of all furniture again**, exactly as in the first search. Do not skip any furniture or assume it is empty. Open every closed container again.
- Continue until you have placed the second object. If you find none after a full search, the task may be impossible.

## Exact Type Matching
- Before taking any object, compare its exact name to the required type. Do not take if they differ (e.g., soapbottle vs soapbar). Only take exact matches.

## Placement
- With a matching object in hand, go directly to the target receptacle and use `move <object> to <target>` immediately. No other actions in between.

## Completion
- Keep a counter. After placing the first, set counter=1. After placing the second, set counter=2 and stop.

## Common Failure Pattern (Avoid This)
- **Premature stop**: Placing one object and not continuing. Always perform the second search as soon as the first is placed.

# pick_two_obj_and_place

## Goal
- Put exactly two instances of a specific object into a specified target receptacle.
- Object type must match exactly. Do not pick up objects that are not the exact type.
- You need both. Do not stop after one.

## Critical Initial Steps
- Read the task and note the object type and target.
- If you are in a room, list all furniture items from the description.
- Open all closed containers (drawers, cabinets, dressers, safes, etc.) systematically. Do not skip any.
- Check open surfaces (countertops, tables, shelves, etc.) as you go.

## Search Strategy
- Exhaustive sweep: check every furniture item once. Do not repeat until you have checked all.
- Use object-specific location priors to guide order, but never skip a container type.
- For common object types:
  - Food/consumables: fridge, countertop, diningtable, cabinet.
  - Electronics/remotecontrols: sofa, armchair, tvstand, coffeetable, sidetable.
  - Boxes/packages: dresser, sidetable, armchair, closet.
  - Watches/jewelry: diningtable, sidetable, drawers.
  - Toiletries (tissuebox, soapbottle, toiletpaper, spraybottle): shelf, sinkbasin, countertop, cabinet, handtowelholder, toiletpaperhanger.
  - Books/pens/paper: shelves, desk, sidetable, drawers.
  - Statues, candles, vases, etc.: often on tables, shelves, countertops, or dressers.
- **If you are searching for spraybottle, be sure to check shelves and cabinets, not just countertops and drawers.**

### Systematic Search
- After initial open of containers, check ALL furniture types: tables, cabinets, shelves, beds, dressers, sofas, armchairs, desks, etc. Do not assume the object is only in drawers or shelves.
- If you have only searched one type (e.g., only drawers), immediately expand to other types before re-checking any location.

## Multi-Object Handling
### Finding the First Object
- When you see the object of the required type, take it.
- If the source is closed, open it first.
- Go to the target and move the object there.

### After Placing the First Object
- **Immediately begin a fresh exhaustive search for the second object.** Do not stop, do not get distracted.
- **Do NOT revisit any location you have already searched until you have checked ALL other possible locations in the room.**
- If you start revisiting the same place (like the same countertop or drawer), you are in a loop – force yourself to go to a new furniture type you haven't examined.
- Open every closed container you have not opened yet. If you have already opened a container, do NOT re-open it unless you have no other unsearched locations left.

### Finding and Placing the Second Object
- Use the same search strategy as for the first.
- Once you pick up the second object, go directly to the target and move it there. Do not perform any other actions (opening, taking other objects) in between.

## Completion Detection
- After moving the second object, the environment will indicate success. If not, continue searching – you may have missed one or the object may have been relocated.
- Do not assume success after one placement. Keep searching until you have placed two.

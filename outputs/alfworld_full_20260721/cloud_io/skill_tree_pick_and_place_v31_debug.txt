# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search receptacles, starting with open surfaces, then closed containers.
3. **Take the object** – only if its type matches the task (ignore numerals).
4. **Navigate to target receptacle** and open it if closed, then move the object there.
5. **Terminate** after placement.

## Systematic Search for Target Object
- From the initial observation, note the available receptacles. You do not need to visit every one if you find the object early.
- Check open surfaces first (tables, countertops, shelves, armchairs, sofas, dressers, beds, bathtubs, toilets, etc.). Go to each and read its contents.
- If the target object is present, take it immediately.
- If not found after checking several open surfaces, proceed to closed containers (drawers, cabinets, fridge, microwave, oven, dishwasher, safe, etc.). For each, `go to <receptacle>`, then `open` it and check its contents.
- Continue searching until the object is found. Do not waste time on a rigid order — you may choose a logical starting point.
- If you have checked all receptacles and not found the object, double-check any you may have missed. The object is always somewhere.

## Common Mistakes to Avoid
- **Taking wrong object** – verify the object's type matches the task exactly (base noun level; ignore numerals).
- **Using wrong actions** – never `examine` or `look`; use `go to` to move, `open`/`close` for containers.
- **Stopping early** – only stop after you have placed the object. Keep searching until you find it.

## Object Acquisition
Once you locate an object whose type matches the target, immediately `take <object> from <receptacle>`. Do not perform any other action first.

### Object Type Verification
Compare the object's name (as shown in observation) with the target object type from the task. They must match at the base noun level (e.g., "glassbottle" vs. "winebottle" are different). Ignore numerals (e.g., "book 2" matches "book").

## Placement
After taking the object, go to the target receptacle and `move <object> to <receptacle>` (or `open <receptacle>` first if it is closed). Then terminate.

# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle.

## First Object Search
### Exhaustive Search Procedure
1. **Write down every furniture item** from the initial room description exactly as seen (e.g., cabinet 3, countertop 1, etc.). Do not omit any.
2. **Visit each item in that written list, one by one, in any order.** Do not skip any item.
3. For each item:
   - If it is closed (drawer, cabinet, fridge, microwave, etc.), **open it**.
   - **Examine its contents** (inside if a container, on top if a surface).
   - If you see an object whose exact name matches the required type (e.g., cup, cellphone, spraybottle), **take it** immediately. Do not take non-exact matches.
   - **Optionally check off the item** as visited so you know you have not missed any.
4. Continue until you have visited every item on the list, even if you already found one object. This ensures no second identical object is overlooked.

## Exact Type Matching
- Before taking any object, compare its exact name to the required type. Do not take if they differ (e.g., soapbottle vs soapbar). Only take exact matches.

## Placement (First Object)
- With a matching object in hand, go directly to the target receptacle and use `move <object> to <target>` immediately. No other actions in between.

## Critical: After Placing the First Object, Start the Second Search Immediately
### Second Search Procedure
- **DO NOT STOP.** You must place a second matching object.
- **Repeat the exact same exhaustive search** as in the first search. Use the **same written list** of furniture items from the initial observation.
- Visit each item again, open if closed, examine contents, and take any matching object. Do not assume any item is empty just because you saw it before. Open every closed container again.
- Continue until you have placed the second object. If you have visited all items on the list and found no second matching object, then the task may be impossible — but do not give up early.

## Completion
- Keep a counter: after placing the first, set counter=1; after placing the second, set counter=2 and stop.
- Do not stop before counter=2, even if you think you have searched everywhere. Only stop after placing the second object or after confirming every item on the list (twice) contains no second match.

## Common Failure Pattern (Avoid This)
- **Premature stop**: Placing one object and not continuing. Always perform the second systematic search as soon as the first is placed.
- **Incomplete search**: Not making a written list or not visiting every furniture item leads to missing objects. Always enumerate every item you see at the start and check each one off.

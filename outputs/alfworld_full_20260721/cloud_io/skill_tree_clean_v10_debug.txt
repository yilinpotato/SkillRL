# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Phase 1: Locate and Take the Target Object
- You must find and pick up [object] before you can clean it.

### Systematic Search Order (Critical)
- **Immediately after opening cabinet 1 (which is already done), list all receptacle types present in the initial room description (e.g., cabinet, drawer, fridge, countertop, sinkbasin, shelf, dresser, garbagecan, etc.).**
- **Then search every type in this exact order, without skipping any type and without ever going back to a previously finished type:**
  1. **Cabinets** – open every numbered cabinet, check contents. (You have already opened cabinet 1; continue with cabinet 2, 3, ... until all cabinets are checked.)
  2. **Drawers** – open every numbered drawer, check contents.
  3. **Fridge** – open fridge, check contents.
  4. **Countertops** – check each countertop for items (you can see items on open surfaces without opening).
  5. **Sinkbasin / Bathtubbasin** – check each.
  6. **Shelves** – check each shelf.
  7. **Dressers** – check each dresser.
  8. **Any other receptacle type** (e.g., garbagecan, towelholder, handtowelholder, toiletpaperhanger) – check each instance.
- **After finishing all instances of a type, immediately move to the next type. Do not stop, do not go back.**
- **If you become lost, re-read the current room description to see which receptacle types remain.**

### Container Interaction
- **Always open a container after arriving to inspect its contents.** Do not rely on surface observations – a closed container may have items inside.
- For open surfaces (countertops, sinkbasins, etc.), you can see what is on them directly without opening.

### Object Name Verification
- Before taking an object, verify that its name matches the task target **exactly** (e.g., "cup" ≠ "mug"; "apple" ≠ "tomato"). If it matches, take it and proceed to Phase 2. If not, continue searching.

### Persistence – Do Not Stop Early
- **The search is not complete until you have visited every single instance of every type in the order above.**
- Stopping before finishing all types is the most common cause of failure. Even if many cabinets or drawers are empty, you must continue until the last type is checked.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (typically sinkbasin 1).
- Immediately use "clean [object] with [cleaning_source]".
- Confirm the observation says you cleaned it; if not retry or check you are at the correct source.
- Do not use "look" or "examine" at the sink – only the clean action works.

## Phase 3: Place the Clean Object at Destination
- After cleaning, go to the [destination] specified in the task (e.g., cabinet, diningtable, microwave, toilet).
- Use "move [object] to [destination]" to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

# Goal: Cool an object and move it to a specified target location.

## Object Search and Retrieval

### Surface Search
- First, check all **countertop** instances (any order). For each, go to it and look at the objects listed. If the target object is present, take it and proceed to Phase 2.
- After all countertops, visit **diningtable** instances (all), then **sidetable** instances, then **shelf** instances, then **sinkbasin**, then **stoveburner** instances. For each surface type, check every instance.
- Do not skip any instance; if you accidentally miss one, you can go back later. The goal is to inspect every surface completely.
- If the target object is found, take it and go to Phase 2.

### Closed Container Search
- If the target object was not found on any surface, search **closed receptacles** in this order:
  1. **fridge** (all instances)
  2. **cabinet** (all instances)
  3. **drawer** (all instances)
  4. **microwave** (all instances)
- For each category, visit **every single instance** without exception.
- For each instance: go to it, open it if closed, then look inside. If the target object is present, take it and proceed to Phase 2.
- **Do not stop** until you have opened and checked every instance of every category. Even if you have searched many, continue until the list is exhausted. Premature stopping (e.g., after only a few cabinets) will cause failure.
- You may revisit a category if you realize you skipped an instance, but it is more efficient to check systematically from the start.

## Phase 2: Cool the object using the fridge
- After picking up the object, go directly to the fridge.
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Phase 3: Move the cooled object to the target location
- Go to the target location.
- If the target receptacle is closed, open it first.
- Use `move <object> to <target>`.

## Completion check
- Object is cooled and placed at the target location – task complete.

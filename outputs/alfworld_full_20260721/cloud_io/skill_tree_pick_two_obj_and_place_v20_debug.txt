# pick_two_obj_and_place

## Goal
- Place exactly two instances of a specific object type into a specified target receptacle.

## Initial Observation
- Immediately after the task description, read the room description carefully.
- List every visible furniture item (e.g., cabinet, drawer, shelf, countertop, dresser, sink, fridge, bathtub, toilet, towelholder, etc.). **Write this list down mentally** – it is your master list.

## Search Strategy

### First Object Search
- Visit every item on your master list exactly once. For each:
  - Go to it.
  - If it is a closed container (drawer, cabinet, fridge, etc.), open it.
  - Examine its contents (on surfaces or inside).
- If you find an object whose exact name matches the required type, take it.

### Sequential Search Protocol (Critical)
- After you have placed the **first** object, **do not stop**. You must now perform a **second, identical search** for the remaining object.
- Reset your mental list to the **original master list** (the same list you made at the start).
- Re-visit every item on that list exactly once again. Do **not** skip any furniture type – even if you already checked it and it was empty, check it again (objects may have been moved into it by the environment).
- Open every closed container again.
- Only once you have completed this full second pass and still found no matching object, you may conclude the second object is missing. Otherwise, take it and proceed.

#### Step-by-Step Sweep Procedure
- Immediately after placing the first object, recall the **original master list** from the initial room description. If you are unsure, re-read the initial observation if it is still in your context.
- For each item in that list (in any order, but do not skip any):
  1. Go to that furniture item.
  2. If it is a closed container, open it.
  3. Examine the contents (surface or inside).
  4. If you see an object whose exact name matches the required type, take it and go directly to the target receptacle. Place it immediately.
- Continue until you have visited every item on the list. If you find and place the second object, stop.
- If you finish the list without finding the second object, then you have exhausted all locations. (The task may be impossible, but you have done your best.)

## Object Identification

### Exact Type Matching
- Before taking any object, compare its exact name (as it appears in the observation) to the required object type from the task. Do not take if the names differ (e.g., soapbottle vs soapbar, spraybottle vs bottle). Only take when names match exactly.

## Placement

### Immediate Action at Target
- When you have a matching object in hand, go directly to the target receptacle. Immediately use `move <object> to <target>`.
- Do **not** perform any other actions (e.g., looking, opening other containers) between arriving at the target and moving the object.

## Counting and Completion

### Keep a Counter
- Start a counter at 0.
- After placing the first object, increment counter to 1. **Do not stop until counter is 2.**
- After placing the second object, increment to 2. The task is complete.

## Common Failure Patterns (Avoid These)

- **Premature Stop**: You stopped after one object. Use the Sequential Search Protocol to force a second full search.
- **Incomplete Initial List**: You did not list all furniture at the start. Re-read the initial room description and ensure no item type is missed (e.g., handtowelholder, toiletpaperhanger, stoveburner, sinkbasin, etc.).
- **Wrong Object Taken**: You took an object that partially matches but is not the exact required type. Always verify exact name.
- **Missed Containers**: You forgot to open closed containers before checking their contents. Always open first.

## Critical Warnings
- **List all furniture at the start** – failing to do so leads to missed locations.
- **Do not stop after one object** – always perform a second full search.
- **Open before examining** – "examine" does not open closed containers.
- **Verify exact name** – no partial matches.
- **At target receptacle with correct object, use move action immediately** – no delays.

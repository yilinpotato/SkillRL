# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search all receptacles, starting with open surfaces, then closed containers. Do not stop until the object is found.
3. **Take the object** – only if its type matches the task (ignore numerals).
4. **Navigate to target receptacle** and open it if closed, then move the object there.
5. **Terminate** after placement.

## Systematic Search for Target Object
- From the initial observation, note **every** receptacle listed (e.g., bathtubbasin, drawer, garbagecan, handtowelholder, sinkbasin, countertop, shelf, sofa, armchair, bed, desk, etc.). These are your complete search list.
- **Open surfaces** (tables, countertops, shelves, armchairs, sofas, dressers, beds, bathtubs, toilets, handtowelholders, towelholders, sinkbasins, etc.): Go to each and read its contents. Do not skip any.
- **Closed containers** (drawers, cabinets, fridge, microwave, oven, dishwasher, safe, etc.): For each, go to the receptacle, open it, and check its contents.
- **Do not stop** until the object is found. If you have checked all receptacles and not found it, double-check any you may have missed. The object is always somewhere.

### Comprehensive search of all containers
1. Start with any open surface visible in the initial observation. Visit each one in turn. If the object is not there, move to the next open surface until all open surfaces have been checked.
2. If the object is not on any open surface, proceed to closed containers. You must open **every** closed container listed in the initial observation. Go to each one, open it, and inspect its contents.
3. **Critical rule:** After opening a container and finding it does not contain the target object, immediately move to the next unopened container. **Do not return to any open surface** until every single closed container has been opened and checked.
4. If you have checked every receptacle (both open and closed) and still have not found the object, revisit any that you might have overlooked. The object must be somewhere.

### Example of proper search order
- From the initial list, identify all closed containers (e.g., drawer 1, drawer 2, ..., drawer 8, cabinet 1, ..., etc.). Open them in any order, but do not skip any. Do not go back to an open surface until the last closed container has been opened.

## Common Mistakes to Avoid
- **Taking wrong object** – verify the object's type matches the task exactly (base noun level; ignore numerals).
- **Incomplete container search** – do not stop opening containers after a few; open every single one on the initial list before concluding the object is not in containers.
- **Using wrong actions** – never `examine` or `look`; use `go to` to move, `open`/`close` for containers.
- **Stopping early** – only stop after you have placed the object. Keep searching until you find it.

## Object Acquisition
Once you locate an object whose type matches the target, immediately `take <object> from <receptacle>`. Do not perform any other action first.

### Object Type Verification
Compare the object's name (as shown in observation) with the target object type from the task. They must match at the base noun level (e.g., "glassbottle" vs. "winebottle" are different). Ignore numerals (e.g., "book 2" matches "book").

## Placement
After taking the object, go to the target receptacle and `move <object> to <receptacle>` (or `open <receptacle>` first if it is closed). Then terminate.

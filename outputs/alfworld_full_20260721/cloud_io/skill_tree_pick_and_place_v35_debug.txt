# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle.

## Sub-Goal Flow
1. **Identify target object and target receptacle** from the task description.
2. **Locate the target object** by searching all listed receptacles systematically.
3. **Take the object only if its name exactly matches** the target (base noun, ignore numerals).
4. **Navigate to target receptacle**, open if closed, then place the object there.
5. **Terminate** after successful placement.

## Systematic Exploration Process
- From the initial observation, **write down every receptacle name** (e.g., tables, shelves, drawers, cabinets, dresser, armchair, sofa, etc.). This is your complete search set – do not rely on memory.
- **Visit open surfaces first**: for each open receptacle (tables, shelves, sofa, bed, dresser, etc.), go to it and inspect its contents. Inspect every one without skipping.
- **Then visit closed containers**: for each drawer, cabinet, etc., go to it, open it, inspect its contents, and leave it open (no need to close). Do this for *every* closed container in your list.
- **If after checking all receptacles you still haven't found the object**, re-check your list – you may have missed one. The object is always present somewhere.
- **Avoid revisiting** a location you already inspected until you have completed the entire list. Premature backtracking wastes time.

### Detailed Algorithm for Exhaustive Search
1. From the initial room description, extract all receptacle names (furniture items). Include everything: tables, shelves, drawers, cabinets, armchairs, sofas, dressers, etc.
2. Sort them into two mental groups:
   - Open surfaces (things you can see onto without opening).
   - Closed containers (drawers, cabinets, etc. that require `open`).
3. Begin with open surfaces: for each, issue `go to <receptacle>`, observe its contents. If the target object is there, take it and proceed to placement.
4. If not found after all open surfaces, proceed to closed containers: for each, `go to <container>`, then `open <container>`, observe contents. If target found, take it.
5. After checking all closed containers, if still not found, review your initial list – you likely missed a receptacle. Re-scan the room description and add any missed items.
6. **Never use `examine`, `look`, or `inventory`** – they are not valid for this task. Only `go to`, `open`, `close`, `take`, `move`.

## Object Acquisition
- When you see an object that *might* be the target, **first verify its name** against the task. The exact type must match (e.g., "soapbottle" vs "soapbar" are different; ignore numerals like "book 1" matches "book").
- Only if the name matches, take it with `take <object> from <receptacle>`.
- If the name does not match, continue searching.

## Placement
- After taking the correct object, go to the target receptacle. If it is closed, open it first. Then `move <object> to <receptacle>`.
- Once placed, terminate (the task will be marked complete).

## Common Mistakes to Avoid
- **Taking without verifying** – always check object name before taking.
- **Stopping search early** – do not assume the object is gone until you have checked every receptacle on the initial list.
- **Wrong actions** – use only `go to`, `open`, `close`, `take`, `move`. Never `examine`, `look`, or `inventory`.
- **Skipping open surfaces** – they are quick to check and often contain the target.

# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle.

## Sub-Goal Flow
1. **Identify target object and target receptacle** from the task description.
2. **Locate the target object** by searching all listed receptacles systematically.
3. **Take the object only if its name exactly matches** the target (base noun, ignore numerals).
4. **Navigate to target receptacle**, open if closed, then place the object there.
5. **Terminate** after successful placement.

## Object Search (Mandatory)
- From the initial observation, **list every receptacle noun** (e.g., countertop, cabinet, drawer, table, shelf, etc.). Every noun followed by a number is a receptacle.
- **Count the total receptacles**. You must visit **every single one** before concluding the object is missing.
- **Visit all open surfaces first** (tables, countertops, shelves, beds, etc.). For each, go to it and inspect its contents.
- **Then visit all closed containers** (cabinets, drawers, fridge, microwave, safe, etc.). For each, go to it, open it, inspect contents, and leave it open (no need to close).
- If there are many identical containers (e.g., cabinet 1, cabinet 2, …), visit them in order until you have opened every one.
- If after checking all receptacles you still haven't found the object, **re-check your list** – you may have missed one. The object is always present somewhere.
- **Avoid revisiting** a location you already inspected until you have completed the entire list. Premature backtracking wastes steps.

## Object-Type Location Heuristics
Use these to prioritize the order of search within open surfaces or closed containers, but **never skip a receptacle**.
- Bottles and cans (soapbottle, glassbottle, winebottle, etc.) are often on **countertops**, then shelves or tables.
- Small electronics (cellphone, laptop, alarmclock) are often on **tables, desks, beds, or shelves**.
- Kitchen tools (knife, fork, pan, kettle) are often on **counters, stovetops, or dining tables**.
- Books and papers (book, creditcard) are often on **shelves, tables, or desks**.
- If the object is not in any expected common location, continue with the full systematic search – do not assume it is missing.

## Object Acquisition
- When you see an object that might be the target, **first verify its name** against the task. The exact type must match (e.g., "soapbottle" vs "soapbar" are different; ignore numerals like "book 1" matches "book").
- Only if the name matches, take it with `take <object> from <receptacle>`.
- If the name does not match, continue searching.

## Placement
- After taking the correct object, go to the target receptacle. If it is closed, open it first. Then `move <object> to <receptacle>`.
- Once placed, terminate (the task will be marked complete).

## Common Mistakes to Avoid
- **Taking without verifying** – always check object name before taking.
- **Stopping search early** – do not assume the object is gone until you have checked every receptacle on the initial list.
- **Failing to list all receptacles** – you must actively extract every noun from the initial observation; the object may be on a receptacle not mentioned in the examples.
- **Wrong actions** – use only `go to`, `open`, `close`, `take`, `move`. Never `examine`, `look`, or `inventory`.
- **Skipping open surfaces** – they are quick to check and often contain the target.
- **Revisiting before finishing the full list** – this wastes steps and may cause you to miss the object.

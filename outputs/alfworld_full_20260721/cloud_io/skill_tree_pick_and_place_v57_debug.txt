# pick_and_place skill tree

## Goal
Pick up a specified object and place it into or onto a specified receptacle.

## Sub-Goal Flow
1. **Extract the full list of every receptacle** (noun + number) from the initial observation. If the observation is truncated (ends abruptly), use `look` once *before* any movement to get the full list. Mentally note the list.
2. **Check the target receptacle first** – go to it, open if closed, inspect contents. If the target object is there, take it and skip to Placement.
3. **If not found, systematically visit every other receptacle on your list, one by one, without revisiting any.**
4. **For each receptacle:**
   - If closed, `open` it immediately (next action must be `open`). Do **not** use `examine`, `look`, `inventory`, or any other action first.
   - Inspect contents. If the target is present, take it and go to Placement.
   - Leave it open; do not close.
5. **After visiting all receptacles** and still not finding the object, the object may be in another room – go to a doorway and repeat the search.

## Object Search (Mandatory)

### Step 1: Extract all receptacles (BEFORE any movement)
- Every word followed by a number is a receptacle. Include *all*: bathtubbasin, sinkbasin, handtowelholder, towelholder, toilet, etc. – not just obvious ones.
- **Critical:** If initial observation is cut off (e.g., ends with "a sideta..."), you **must** use `look` once before any `go to` action. Then avoid further `look` or `inventory` during search.

### Step 2: Visit every receptacle in turn
- Create a mental checklist (e.g., "cabinet 1-20, coffeemachine 1, countertop 1-2, fridge 1, ...").
- **Open immediately:** When you arrive at a closed container, your very next action **must** be `open <container>`. Do not `examine`, `look`, `inventory`, or move elsewhere first. Using `examine` instead of `open` is invalid – you must physically open the container to see inside.
- After opening, read the contents. If the target is there, take it and proceed to Placement. Otherwise, move to the next unvisited receptacle.
- **Do not revisit any receptacle** until you have visited every single one on your list. If you catch yourself moving to an already visited place, stop and consult your list to pick the next unvisited one.
- **Common failures:** Skipping unusual receptacles (bathtubbasin, sinkbasin, toilet, etc.) or stopping early after only checking a few types (e.g., only drawers or only shelves). The object can be on any furniture.

### Step 3: If still missing after full list
- Re-examine the initial observation – you may have missed a receptacle (e.g., handtowelholder, garbagecan). If none is missed, move through a doorway to another room and repeat the systematic search.

## Object Acquisition
- **Name match:** Only take an object if its exact base noun (without number) matches the target. "Knife" is not "butterknife".
- **Action:** `take <object> from <receptacle>`.

## Placement
- Go to the target receptacle. If closed, open it. Then `move <object> to <receptacle>`.
- **Stop immediately after the move action** – do not perform any further actions.

## Common Mistakes to Avoid
- **Not extracting all receptacles before moving** – leads to missing entire furniture categories.
- **Not opening closed containers on arrival** – you must open before inspecting; `examine` is not a substitute.
- **Revisiting already-checked receptacles** – wastes steps and causes missed ones.
- **Stopping search early** – only conclude object missing after every receptacle on the list has been visited.
- **Taking without exact name match** – always compare base nouns.
- **Unnecessary `look` or `inventory`** – only use `look` once if initial observation truncated; otherwise stick to `go to`, `open`, `take`, `move`.

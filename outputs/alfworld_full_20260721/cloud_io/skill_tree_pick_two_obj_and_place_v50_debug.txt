# pick_two_obj_and_place

## Goal
Place exactly two instances of a specific object type into a specified target receptacle. Stop only when counter == 2 or after two exhaustive passes without finding a second object.

## Verify object type before picking
- Before taking any object, read its full name from the observation. Compare it exactly to the required object type (e.g., if the task says "soapbottle", you must pick only objects named "soapbottle X").
- If the object name does NOT match exactly, do not take it. Ignore it and continue searching.
- If you accidentally take a non-matching object, drop it immediately (use `drop`) and resume search from where you left off.

## Ensure two objects are placed (counter enforcement)
- **Counter:** Start at 0. After each successful placement, increment by 1. If counter == 1, continue searching. If counter == 2, task complete.
- After picking up a matching object, your very next action MUST be `go to [target receptacle]`. Do not open, look, or move anywhere else first. Then open the receptacle if closed, and place the object.
- Do not stop after placing only one object. Immediately begin systematic search for the second object.

### After placing the first object: systematic search for second object
1. **Re-read the initial observation** (the furniture list from the start of the task).
2. **Mentally list every furniture item** in the exact order they appeared. Include all surfaces (countertop, table, bed, sofa, shelf, sidetable, etc.) and all containers (cabinet, drawer, fridge, dresser, garbagecan, etc.). Do not skip any type.
3. **Visit each item in that order exactly once.** For each:
   - If closed, open it.
   - Examine contents (surfaces: just look; containers: look inside).
   - If you see an object whose exact name matches the required type, verify the type, take it immediately, then go directly to the target receptacle, open if needed, and place it. Increment counter.
   - If counter becomes 2, stop.
   - If no match, move to the next item. Do not revisit any item in this pass.
4. **If you have visited all items and counter is still 1, perform a second full pass** – repeat step 3, again visiting every item in the same order.
5. **After the second pass:** if counter is still 1, the task is impossible. Stop.

## Immediate Rules (Must Follow)
- **Counter:** Start at 0. After each successful placement, increment by 1. If counter == 1, continue searching. If counter == 2, task complete.
- **After picking up an object that matches the target type, your very next action MUST be `go to [target receptacle]`.** Do not open, look, or move anywhere else first. Then open the receptacle if closed, and place the object.
- **Do not stop after placing only one object.** Immediately begin the systematic search described above.

### Multi-object completion
- You must place exactly two matching objects. Placing one does **not** complete the task. After placing the first, you must continue searching and placing until the second is placed. Only after two full passes (following the first placement) with counter still 1 may you conclude the task is impossible.

## Failure Prevention
- **Stopping early:** If you catch yourself not searching after placing one object, re-read the initial observation and restart the systematic search from the first furniture item.
- **Looping:** If you revisit the same few locations without taking a target object, stop, re-read the observation, rebuild the mental list, and restart from the first item.
- **Skipping furniture types:** The target object may be on any surface or inside any container. Follow the mental list order; do not only check drawers or only shelves.
- **Opening target receptacle:** When placing, if the target is closed, open it first.
- **Taking wrong object:** If you accidentally take a non-matching object, drop it (use `drop`) and resume search.

## Stop Condition
- counter == 2 -> success
- counter == 1 after two full passes following first placement -> impossible, stop.

# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Phase 1: Locate and Take the Target Object
- You must find and pick up [object] before you can clean it. Do not assume it is in any specific place.

### Systematic Search Order (Checklist)
- Immediately list all receptacle types visible in the initial observation (e.g., cabinet, drawer, fridge, countertop, sinkbasin, bathtubbasin, shelf, dresser, garbagecan, towelholder, etc.).
- **Search in this exact sequential order. Do not skip any type. Do not stop early. Do not revisit a finished type.**
  1. **Cabinets** – open every numbered cabinet, check contents. If target found, take it and proceed to Phase 2.
  2. **Drawers** – open every numbered drawer, check contents. If found, take and proceed.
  3. **Fridge** – open fridge, check contents.
  4. **Countertops** – check each countertop for items (open surface).
  5. **Sinkbasin / Bathtubbasin** – check each.
  6. **Shelves** – check each shelf.
  7. **Dressers** – check each dresser.
  8. **Any other receptacle type** – check each instance (e.g., garbagecan, towelholder, handtowelholder, toiletpaperhanger).
- **Critical: After finishing all instances of a type, immediately move to the next type. Never go back to a previous type.**
- If you become lost, re‑read the current room description to identify any receptacle type you may have missed.

### Object Name Verification
- Before taking an object, verify that its name matches the task target **exactly** (e.g., "cup" ≠ "mug"; "apple" ≠ "tomato").
- If it matches, use "take [object] from [receptacle]" and proceed to Phase 2.
- If it does not match, do not take it; continue searching.

### Persistence – Do Not Stop Early
- **The search is not complete until you have visited every single instance of every type in the order above.**
- Even if many cabinets or drawers are empty, continue until the last type is checked.
- If you have not yet found the target, you must keep going. Stopping early is the most common cause of failure.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (typically sinkbasin 1).
- Immediately use "clean [object] with [cleaning_source]".
- Confirm the observation says you cleaned it; if not retry or check you are at the correct source.
- Do not use "look" or "examine" at the sink – only the clean action works.

## Phase 3: Place the Clean Object at Destination
- After cleaning, go to the [destination] specified in the task (e.g., cabinet, diningtable, microwave, toilet).
- Use "move [object] to [destination]" to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

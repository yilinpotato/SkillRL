# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin.

## Critical Rules (must be followed without exception)
- **Do not go to any sinkbasin or bathtubbasin until you are holding the target object.**
- **Do not go to the destination receptacle until after cleaning.**
- **Search open surfaces first, then closed containers. Do not skip any open surface – including stoveburners, countertops, diningtable, shelves, towelholders, etc.**
- **If you are already holding something that is not the target, put it down immediately.**
- **After arriving at the cleaning source, perform the clean action immediately – do not examine, look, or inventory before cleaning.**

## Phase 1: Search and Acquire the Target Object
**Prerequisite: None – begin with a fresh `look` to get the room description.**
- **Object Name Matching:** Compare the object name from the task exactly. Do not pick up similar items (e.g., cloth vs towel).

### Systematic Search Procedure

#### Pre-search Planning
- **Before moving anywhere, use `look` to see the initial room description.**
- **Mentally list all open surfaces** (countertops, tables, shelves, stoveburners, diningtables, towelholders, handtowelholders, etc.) from that description. Exclude sinkbasin/bathtubbasin.
- **Mentally list all closed containers** (cabinets, drawers, fridge, microwave, oven, etc.).
- Keep these lists in mind; you will check every single one in order.

#### Execution Order
1. **Visit each open surface in the order they appear in the initial description.** At each, examine contents. If the target is present, pick it up and go to Phase 2.
2. **After all open surfaces are done** (target not found), proceed to closed containers in this fixed order: first all cabinets (numerical order), then all drawers (numerical order), then the fridge (if target is a food item, check fridge first), microwave, oven, etc.
   - For each closed container: `open [container]`, look inside. If target is inside, pick it up.
3. **Do not skip any receptacle.** Even if many cabinets or drawers, check every single one.
4. **If still not found after all closed containers, repeat the cycle** (open surfaces then containers) – this is rare, but do it.

#### Self-Check During Search (critical)
- **Before opening any closed container, stop and recall the list of open surfaces from the initial description. If you have not visited every one of them (including stoveburners, countertops, etc.), do not open a container – go to the next open surface first.**
- If you find yourself moving between locations without a clear plan, **stop**. Write down the list of receptacles from the description and check off which you have visited. Do not proceed until you have a plan.
- **Do not give up** until every receptacle on your list has been checked. If you cannot remember the full list, use `look` again to refresh.

## Phase 2: Clean the Object
- **Prerequisite: You must be holding the target object.** If empty-handed, return to Phase 1.
- Immediately go to [cleaning_source] (sinkbasin or bathtubbasin).
- **Upon arrival, immediately execute `clean [object] with [cleaning_source]`. Do not examine, look, inventory, or move elsewhere until you have performed the clean action and confirmed the observation says cleaned.**
- Confirm observation says cleaned.

## Phase 3: Place the Clean Object at Destination
- Go to [destination]. If it is a closed container, open it first.
- Use `move [object] to [destination]`.
- Confirm the object is now at destination.

## Completion
- Stop as soon as you have placed the clean object. Do not continue.

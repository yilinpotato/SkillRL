# pick_and_place skill tree

## Goal
Pick up a specific object and place it into or onto a specified receptacle (e.g., "put a book in sofa"). The task names both the target object and the target receptacle.

## Sub-Goal Flow
1. **Parse the task** – identify the target object and target receptacle exactly as written.
2. **Locate the target object** – search every visible receptacle systematically.
   - **2a. Create a receptacle checklist** – from the first room observation, list every receptacle name exactly as it appears. Include all furniture: tables, cabinets, drawers, shelves, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubs, holders, fridges, microwaves, ovens, dishwashers, bathtubs, toilets, garbage cans – any container that could hold objects. Do not skip any. This list is your master checklist. Keep it in mind and tick off each receptacle as you visit it.
3. **Verify and take** – only take the object if its type matches the task (ignore numerals).
4. **Navigate to target receptacle** and move the object there.
5. **Terminate** after placement.

## Exploration: Systematic Object Search
### 1. Create and Follow a Complete Receptacle Checklist
Immediately after the initial room observation (the welcome text), mentally list every receptacle. Do not start moving until you have that list. This list is your master checklist. Keep it in mind and tick off each receptacle as you visit it.

### 2. Full Surface Search
Identify all receptacles that are **open surfaces** (tables, shelves, countertops, desks, sidetables, sofas, armchairs, beds, dresser tops, sinkbasins, toilet tops, bathtubs, etc.). Start at the target receptacle if it is an open surface; otherwise start with any open surface. Then systematically visit **every other open surface** from your list using `go to <receptacle>` and reading the observation. Do not skip any, even if unlikely. If the target object is present, immediately `take <object> from <receptacle>`. Do not postpone taking it.

### 3. Closed Container Search
Once every open surface has been checked and the object is not found, move to **closed containers** (drawers, cabinets, fridges, microwaves, ovens, dishwashers, etc.). For each from your checklist: `go to <receptacle>`, `open <receptacle>`, then read contents. If you see the target object, `take <object> from <receptacle>` immediately. Do not close the container.

### 4. Exhaustive Search Strategy (If Not Found)
- **After first pass:** Immediately repeat the entire sequence – start from the beginning and visit each receptacle again. Pay special attention to receptacles you might have overlooked.
- **After two passes:** Check all closed containers again, especially fridges, microwaves, ovens, dishwashers, and any cabinet/drawer not yet opened.
- Re-read your initial observation to ensure you did not miss any receptacle name. If still missing, start a third pass – do not give up early.

### 5. Common Mistakes
- Skipping any open surface – all must be checked.
- Not proceeding to closed containers – after open surfaces, open every closed container.
- Using wrong action – never `examine` or `look` to move; use `go to`.
- Taking wrong object – verify the object's type matches the task exactly. Ignore numerals.
- Failing to open closed containers before reading contents.
- Forgetting to place – after taking, go to target and `move <object> to <receptacle>` immediately.

### 6. Object Verification & Identification
Before taking, verify that the object's **type** matches the task exactly (e.g., "spraybottle" not "soapbottle"). Ignore numeric suffixes. Read the observation list carefully; do not assume based on partial word matches.

### 7. Object Acquisition

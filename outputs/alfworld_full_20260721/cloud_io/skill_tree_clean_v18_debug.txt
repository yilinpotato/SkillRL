# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Phase 1: Locate and Take the Target Object

### Search Open Surfaces First
- Open surfaces (countertops, diningtables, sidetables, shelves, sinkbasins, etc.) are visible without opening. Check these first—they often hold the target object.
- List every open-surface receptacle from the initial description. For each, go to it and read the observation (no need to open). If the target object is present, take it and go to Phase 2.
- If the destination in the task is an open surface (e.g., diningtable, countertop), check that surface early—the object may already be there.

### Search Closed Containers (if not found on open surfaces)
- Only after checking all open surfaces, begin opening closed containers.
- Systematically search **all** instances of these types in this order:
  1. **Cabinets** – go to each, open, inspect contents.
  2. **Drawers** – go to each, open, inspect.
  3. **Fridge** – if present, go to it, open, inspect.
- Continue until the target object is found. Do not stop after the first container type; finish every type.
- **IMPORTANT**: Whenever you move to a closed container (e.g., cabinet 2) and see "The [container] is closed.", **immediately open it** by issuing `open [container]`. Do not walk away without opening it.

### Object Handling Rules (During Search)
- **Object Type Verification**: Before taking any object, verify its name matches the task target exactly (e.g., "soapbar" ≠ "soapbottle"; "pan" ≠ "pot"). If the exact match is present, take it. If only similar objects are present, continue searching.
- **Immediate Pickup of Target Object**: If you see an object that exactly matches the target (e.g., you see a pan and the task says "clean some pan"), pick it up immediately. Do not delay or explore other locations first.

### Navigation and Opening Rules
- Always move to a receptacle before interacting. Sequence: `go to <receptacle>`, then `open <receptacle>` (or `take <object>` if already seen).
- For closed containers, you **must** open them to see contents—`look` or `examine` will not reveal inside.
- If you open a container and see nothing, move to the next container. Persist through all instances.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (usually sinkbasin 1).
- Use `clean [object] with [cleaning_source]`.
- Confirm the observation says you cleaned it; if not, retry or verify you are at the correct source.

## Phase 3: Place the Clean Object at Destination
- Go to the [destination] specified in the task.
- Use `move [object] to [destination]` to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

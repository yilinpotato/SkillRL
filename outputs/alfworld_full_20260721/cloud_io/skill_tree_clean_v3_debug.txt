# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]".
- Remember that [object] must be cleaned before placing at [destination].
- Identify [cleaning_source] as the nearest sinkbasin or bathtubbasin (usually sinkbasin).

## Phase 1: Locate and Take the Target Object
- You need to find and pick up [object] before you can clean it.
- Do not assume [object] is in any specific receptacle; search systematically.

### Systematic Search
- Begin by listing all visible receptacle types from the initial observation (e.g., cabinet, drawer, fridge, countertop, sinkbasin, shelf, dresser, etc.).
- For each receptacle type, visit every instance of that type in the room.
- For closed receptacles (cabinets, drawers, fridge), use "open [receptacle]" first, then check contents.
- If you see [object], use "take [object] from [receptacle]" and proceed to Phase 2.
- If you do not find [object] after checking all instances of one type, **move on to the next receptacle type**. Do not stop early.

### Continue search across all receptacle types
- After checking all cabinets, proceed to check all drawers (open each), then the fridge, then all countertops, then sinkbasin/bathtubbasin, then shelves, dressers, etc.
- Only after you have checked every receptacle type listed can you conclude the object is absent. Then re-scan the room for any missed receptacle.
- Once you are carrying [object], proceed to Phase 2.

## Phase 2: Clean the Object
- While holding [object], go to [cleaning_source] (e.g., sinkbasin 1).
- Upon arriving at [cleaning_source], immediately use "clean [object] with [cleaning_source]".
- Confirm the observation says you cleaned it; otherwise retry or check if you are at the correct source.

### Perform the cleaning action (do not examine)
- **Do not** use "look", "examine", or any other action at the sink. The only action that cleans the object is "clean <object> with <source>".
- If you accidentally move away, return and clean.

## Phase 3: Place the Clean Object at Destination
- After cleaning, go to [destination] (e.g., diningtable, shelf, stoveburner, etc.).
- Use "move [object] to [destination]" to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends when you have successfully placed the clean object. Do not continue searching or moving other objects.

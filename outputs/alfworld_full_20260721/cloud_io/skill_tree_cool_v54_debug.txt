# Goal: Cool an object and move it to a specified target location.

## Phase 1: Find and take the target object

### Object retrieval (prerequisite)
- You **must** be carrying the correct target object before proceeding to Phase 2 (cooling).
- If you are not holding the object, you have not completed Phase 1. Do not attempt to cool or move anything.

### Search Heuristic – prioritize common locations
- Most household objects are found on **countertops**, **diningtables**, or inside the **fridge**.
- Start by checking **every** countertop instance. The consensus step brings you to the first countertop; you must then visit all other countertops in the environment. Do not stop after only one.
- If the target is on any countertop, take it immediately and go to Phase 2.
- If not found on any countertop, **check the fridge** before moving to other surfaces. Open it, look inside. If target present, take it (→ Phase 2). If not, close the fridge and proceed.
- **After the fridge, the next surface type in the strict order is diningtables. Do not skip to sinkbasins or stoveburners.** Skipping any surface type means you will miss the target.
- Only after checking all countertops and the fridge, continue to the other surface types in the strict order below.

### Surface Search – strictly follow this order and check **every** instance of each type
1. **Countertops** – checked already (but if you return here later, check again only if all containers are exhausted).
2. **Diningtables** – check every diningtable.
3. **Sidetables** – check every sidetable. (Do NOT skip to sinkbasins after diningtables.)
4. **Shelves** – check every shelf.
5. **Sinkbasins** – check every sinkbasin.
6. **Stoveburners** – check every stoveburner.
7. **Cabinets (top surface)** – note: cabinets have a top that counts as a surface. Check the top of every cabinet. Also, cabinets have an interior that must be opened (see Container Search).
8. **Drawers (top surface)** – same as cabinets: check the top of every drawer; interior must be opened.

- At each location, read the observation. If the target object is present **on the surface**, take it immediately and go to Phase 2.
- **Never skip a surface type.** If you have not visited every type above (including all instances of each), you are NOT done. Do NOT move to container interiors until all surface types are exhausted.
- **If you find yourself at a container before finishing surfaces, that is a mistake.** Immediately return to the next unvisited surface type. Do not open the container yet.
- **Common mistake:** After the fridge, agents often jump to sinkbasins or stoveburners. This misses diningtables, sidetables, and shelves. Stick to the order exactly.

### Container Search – only after ALL surface types (including cabinet/drawer tops) are exhausted
- After checking every surface type above and still not finding the object, you **must** open and search the interiors of closed containers.
- Search containers **in this exact order**. For each type, check every instance:
  1. **Cabinet** – open each cabinet, look inside. If target present, take it (→ Phase 2). If not, close and move to next cabinet.
  2. **Drawer** – same process.
  3. **Microwave** – same process.
- **Critical: You must open every container to see its contents.** Simply looking at a closed container (or at objects on top of it) reveals nothing about what is inside.
- **After each container type, do NOT return to surfaces.** Continue to the next container type in the list. Only after you have checked **all** container types and still not found the object, then backtrack through the surface list again – you may have missed a location earlier.

### Object Verification Rule
- **Before taking** any object, carefully read its exact name from the observation. Only take an object whose name matches the target object type **exactly**.
- **Immediately after taking** any object (even if you think it is correct), pause and verify the name. If it does not match the target, **put it back on the exact surface you took it from** using `put <object> on <surface>` and resume searching from that same location.
- If you are already carrying an object that does not match the task, put it down immediately and continue searching.

## Phase 2: Cool the object using the fridge
- As soon as you have taken the **correct** target object, your next action **MUST** be to go to a fridge, open it (if closed), and use `cool <object> with fridge`.
- Do NOT examine the object, move anywhere else, or perform any other action in between.
- If you are not carrying the object, go back to Phase 1.

## Phase 3: Move the cooled object to the target location
- Go directly to the target location (e.g., cabinet, diningtable, garbagecan).
- If the target is a closed container, open it first.
- Use `move <object> to <target>`.

## Completion check
- The object is now cooled and placed at the target. Task complete.

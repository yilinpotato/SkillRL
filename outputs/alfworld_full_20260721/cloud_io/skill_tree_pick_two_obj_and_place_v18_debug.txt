# pick_two_obj_and_place

## Goal
- Place exactly two instances of a specific object into a specified target receptacle.

## Multi-object search

### Full Location Coverage
- From the initial room description, list every visible furniture item (e.g., cabinet, drawer, shelf, countertop, dresser, sink, fridge, bathtub, toilet, etc.). Do not skip any type.
- Visit each item exactly once in your first pass. For each:
  - Go to it.
  - If it is a container (closed drawer, cabinet, etc.), open it.
  - Examine its contents (on surfaces or inside).
- Common misses: dressers, garbage cans, bathtub basins, handtowel holders, toiletpaperhangers, stove burners, fridge interiors.
- If after visiting all items you still lack one or both objects, repeat the list but check opened containers again (objects may have been moved).

### Object-Specific Hints
- Some objects are often found near their functional location, e.g., toiletpaper on toiletpaperhanger or nearby cabinet, soapbottle on sink or counter, newspaper on sidetable or sofa.
- Use these hints to prioritize search, but do not skip any furniture type – always eventually check all.

## Counting and collection

### Keep a counter
- Start a counter at 0. After placing the first object, update to 1. Do not stop until counter is 2.
### Verify count before stopping
- After placing an object, immediately check your counter. If it is not 2, begin a fresh, systematic search for the next object. Do not assume the task is complete.

## Object identification

### Exact type matching
- Before taking any object, compare its exact name (as it appears in the observation) to the required object type from the task. Do not take if the names differ (e.g., soapbottle vs soapbar). Only take when names match exactly.

## Procedure (step-by-step algorithm)
1. **Identify task**: Note the required object type and target receptacle.
2. **List all furniture**: From the initial room description, write down every visible furniture item. This is your master list.
3. **First object search**: Follow the Multi-object search section. When you find an object that matches the required type exactly, take it.
4. **Place the first object**: Go directly to the target receptacle. Use "move <object> to <target>" immediately. Do not perform any other actions.
5. **Second object search**: Reset your mental list to the master list. Repeat step 3 exactly, but now you need only one more object. Do not skip any furniture type – re-visit all.
6. **Place the second object**: Repeat step 4. After placing, verify count (see Counting and collection). The task is complete when counter reaches 2.

## Common Failure Patterns
- **insufficient_exploration**: You did not visit every furniture type. Use the Full Location Coverage section to ensure no type is missed.
- **premature_stop**: You stopped after picking or placing one object. Use the Counting and collection section to continue until count is 2.
- **wrong_object**: You took an object that does not match the required type exactly. Use the Exact type matching section before taking.

## Critical warnings (avoid these failures)
- **List all furniture at the start** – failing to do so leads to missed locations.
- **Do not stop after one object** – always search for the second.
- **Open containers before checking** – "examine" does not open.
- **Verify exact name** – no partial matches.
- **At target receptacle with correct object, use move action immediately – no delays.

# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is typically the microwave.

## 2. Locate the object
- Search systematically across all receptacles. The object may be in the fridge, on countertops, in cabinets, or in drawers.
- **Prioritize likely locations based on object type**:
  - Food items (e.g., tomato, egg, apple, lettuce, bread) are often stored in the fridge.
  - Non-food items (e.g., cup, mug, bowl, plate) may be in cabinets, drawers, or on countertops.
- ### Search all receptacles
  - Start with the fridge. Go to fridge, open it, check contents. If the object is inside, take it.
  - If not found, check every countertop (go to each, look at its contents).
  - If still not found, check cabinets and drawers (go to each, open, look inside).
  - Do not skip any receptacle; use 'look' if you lose track of surroundings.

## 3. Heat the object
- Once you have the object in inventory, go to the microwave.
- Open the microwave.
- Move the object from inventory into the microwave (action: 'move <object> to microwave').
- Close the microwave to start heating.
- Open the microwave again; the object is now heated.
- Take the heated object from the microwave (action: 'take <object> from microwave').

## 4. Place the heated object in the target location
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf).
- If the receptacle is a container (cabinet, fridge, drawer), open it first.
- Put the object into/onto the receptacle (action: 'move <object> to <receptacle>').
- Task is complete when the heated object is in the target location.

## 5. Completion check
- After placing, stop. Do not continue searching or heating.

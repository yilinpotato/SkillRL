# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop only when counter == 2.

## Counter
- Start at 0.
- Increment after each successful placement.
- If counter == 2, task complete – stop immediately.
- If counter < 2, you **must** continue searching for the next object.

## Critical Rules (violating any means failure)
- **Always start a search with `look`** to get a full list of furniture. Never move before looking.
- **At every item**: if it is closed, open it before examining contents. Do not skip.
- **After placing the first object, you must immediately search for the second.** Do not stop or loop.
- **Never perform the same action twice in a row without moving** – that is a loop. Force a move to the next item on your search list.

## Confirm Object Identity Before Picking
- Re-read the target object name from the task description before each pick.
- Only pick up an object whose name exactly matches the target type.
- If unsure, use `look` to see the name.
- If you accidentally take a wrong object, `drop` it and continue.

## Search Strategy (for finding objects)
1. **Always begin with `look`** to obtain the ordered list of all furniture in the room. This is your **search list**.
2. Immediately go to the **first** item on that list. Do not `look` again.
3. Visit **every** item **in that exact order**. Do not skip any.
   - Types include: cabinets, drawers, shelves, fridge, dresser, desks, tables, beds, sidetables, sofa, armchair, sinkbasin, bathtubbasin, towelholder, toiletpaperhanger, etc.
4. At each item:
   - **If closed, open it** (e.g., `open drawer 1`).
   - Examine contents. If you see the exact target object, **take it immediately**.
   - Do not pick up any other object.
5. If you complete the list without finding the target, repeat the list **once more**. After two full passes with no target, the object is absent – stop.

## Container Handling
- Whenever you arrive at a closed container (drawer, cabinet, shelf with a door, etc.), you must **open** it before you can see its contents.
- Use the action `open <container>` (e.g., `open drawer 1`). If it is already open, skip this.
- After opening, look inside (the observation will list contents). Then take the target if present.

## Phase 1 – First Object (counter = 0)
- Execute the **Search Strategy** to find and take the first target object.
- After taking it, **go directly to the target receptacle**. Do not place anywhere else.
- At the target receptacle: open if closed, then use `move` to place the object. Counter becomes 1.
- **While holding the object, do not drop it, move it elsewhere, or interact with any other object.**

## Phase 2 – Second Object (counter = 1)
**Immediately after placing the first object, you must find and place the second. Do not stop.** Choose one of two paths:

### Shortcut – Only If Multiple Copies Were at the Same Source
- **Condition:** You saw **more than one** instance of the target object at the exact location where you took the first one (e.g., multiple plates on the same table). If you saw only one copy there, do **not** use this shortcut.
- **Action:** Go back to that same location, take the next copy, go to the target receptacle, and place it. Counter becomes 2. Stop.

### Full Restart (Default Path) – Mandatory If Shortcut Not Applicable
- **Do not repeat the same `look` multiple times.** Exactly one `look` to get a fresh search list.
- Immediately go to the **first item** on that new list. Follow the **Search Strategy** exactly to find the second target.
- When you find it, take it, go to the target receptacle, and place it. Counter becomes 2. Stop.
- If you complete two full passes of the fresh list without finding a second target, task impossible – stop.

### Transition After First Placement – Critical Step
- **Immediately after placing the first object, decide: was there more than one copy where you found it?** If yes, go to **Shortcut**. If no, go to **Full Restart**.
- If you ever do more than one `look` without moving after placing, treat it as a loop – force a move to the first item on a fresh `look` list.

## Loop Detection & Recovery
- Two consecutive actions of the same type (e.g., `look`, `look` or `open`, `open`) without moving = loop.
- Force a change: go to the next item on your current search list. If no list, do a fresh `look` and go to the first item.
- Do not repeat the same action more than once without moving.

## Avoid Taking Non-Target Objects
- Only touch objects whose name exactly matches the target type.
- If you hold an irrelevant object, drop it immediately and resume search.

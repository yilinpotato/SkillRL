# pick_two_obj_and_place

## Goal
Place exactly two instances of a specified object type into a target receptacle. Stop when counter equals 2 or after two exhaustive full passes without finding a second instance.

## Systematic Search Procedure (Unified)
1. **Re‑read the initial observation** – list every furniture item in the exact order they appear. This is your mental list. Do not skip any type (surfaces, containers, shelves, drawers, etc.).
2. **Visit each item in that order exactly once.** For each:
   - If closed, open it.
   - Examine contents: surfaces – just look at what is on them; containers – look inside.
   - If you see an object whose exact name matches the required type, **take it immediately**.
   - **After taking, your next action MUST be `go to [target receptacle]`** – no detours.
   - Open the target if closed, then place the object (`move` or `put`). Increment counter by 1.
   - If counter == 2, stop – task complete.
   - If counter == 1, **immediately restart this procedure from step 1** – do not continue from your current location.
3. If you finish the list and counter == 0, perform a **second full pass** – repeat step 2 from the first item.
4. After two full passes, if counter is still 0, the task is impossible – stop.

## Post‑Placement Behaviour (counter == 1)
- **Do NOT** continue searching from where you just placed the object. Always restart the Systematic Search Procedure from step 1 (re‑read the observation, rebuild the list, start at the first furniture item).
- After the first placement, you are searching for the second object. The search must be exhaustive: visit every item in order, including those you already checked earlier (they may now contain the second object, or you may have missed it).

## Immediate Rules (Must Follow)
- Counter starts at 0. After each placement, increment. If counter == 1, continue; if 2, stop.
- After picking up a matching object, next action MUST be `go to [target]`. No exception.
- If you accidentally take a non‑matching object, drop it immediately and resume the search from the current furniture item.

## Failure Prevention
- **Stopping early:** If you catch yourself not searching after placing one object, re‑read the observation and restart the systematic search from the first furniture item.
- **Looping:** If you revisit the same few locations without taking a target object, stop, re‑read the observation, rebuild the mental list, and restart from the first item.
- **Skipping furniture types:** The target object may be on any surface or in any container. Follow the mental list order; do not only check drawers or only shelves.
- **Opening target receptacle:** When placing, if the target is closed, open it first.

### Multi‑Object Search Strategy
- Always check **all** furniture types in the initial observation – surfaces (countertops, tables, sidetables, coffeetables, etc.) are just as likely as containers (cabinets, drawers, shelves). Do not specialise on cabinets alone.
- If you have not found any object after visiting half the list, continue systematically – the object may be in an item you haven't opened yet.

### Re‑acquisition After First Placement
- After placing the first object, **you must perform a fresh exhaustive search** from the beginning of the mental list. Do not rely on memory of where you found the first object; the second may be in a different location.
- The same systematic procedure applies: visit every furniture item exactly once, in order. If you finish the list without finding the second, do a second full pass before concluding impossibility.

### Object‑specific Storage Knowledge
- Some object types (e.g., tissuebox, newspaper) are more common in certain furniture types (e.g., cabinets, armchairs). However, **never assume** – always check every furniture type in the initial observation. Use this knowledge only as a hint to be thorough, not as a reason to skip other locations.

## Stop Condition
- counter == 2 → success
- counter == 1 after two full passes following first placement → impossible, stop.
- counter == 0 after two full passes in initial search → impossible, stop.

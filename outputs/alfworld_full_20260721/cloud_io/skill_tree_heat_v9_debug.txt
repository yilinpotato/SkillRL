# heat

## 1. Interpret the task
- Identify the object to heat and the target placement location from the task description.
- The heating appliance is the microwave.

## 2. Locate the object
### 2.1 After any move: look
- Perform a 'look' action to refresh the list of all receptacles in the current room.
- Write down every receptacle name you see. Do not skip this.

### 2.2 Exhaustive search of all receptacle types
- Follow this exact order, checking **every single instance** of each type:
  1. **Fridge**: go to it, open, look inside. Take the target object if present. Close after.
  2. **Countertops**: go to each countertop one by one, look at contents, take if found.
  3. **Other flat surfaces**: sidetables, diningtables, shelves (and any other flat surface listed). Go to each, look at its contents.
  4. **Cabinets, drawers, garbagecan, sinkbasin, and all other containers**: open each one, look inside. Do not skip any. Even if you have already opened some, double-check you covered every visible container.
- **Important**: Do not stop after checking only a few items. You must visit every receptacle from your list. If you have not found the object after finishing this list, perform another 'look' (action: look) to see if new receptacles have appeared. Then repeat the search on any that were previously missed or newly appeared.

### 2.3 Object identification and selection
- Before picking up any object, read the task description again to know the exact target object type (e.g., "mug", "cup", "apple", "egg"). 
- Only pick up an object if it **exactly matches** that type. For example, if the task says "cup", do not pick up a "mug" – continue searching.
- If you are unsure, examine the object (action: examine <object>) to see its name.
- After picking up, verify in your inventory that the object is the correct one.

### 2.4 Persistence and common hiding spots
- Small kitchen items (mugs, cups, bowls, etc.) are often stored in cabinets or drawers, not on open surfaces. 
- If you have searched flat surfaces and the fridge without success, immediately focus on opening and looking into every cabinet and drawer. Do not give up after one or two empties.

## 3. Heat the object
### 3.1 Efficient heating method (direct from inventory)
- Once the object is in your inventory, go to the microwave.
- You can heat it while holding it: perform action 'heat <object> with microwave'. This is the simplest method and works reliably.
- If you prefer or if direct heat fails, you can follow the longer sequence: open microwave, move object inside, close, open, take object out, then heat while holding. But direct heat is the first choice.
- After heating, the object is ready. Do not return it to the microwave.

## 4. Place the heated object
- Go to the receptacle specified in the task (e.g., countertop, cabinet, diningtable, fridge, garbagecan, shelf, sidetable, coffeemachine, etc.).
- The destination must be different from the source where the object originally came from.
- If the target receptacle is openable (cabinet, drawer, fridge, garbagecan), open it first.
- Put the object into/onto the receptacle: action 'move <object> to <receptacle>'.
- **Critical**: Do not take the object back after placing it. Stop.

## 5. Completion check and termination
- After placing the object, verify: examine the receptacle (action: 'examine <receptacle>') and check your inventory (action: 'inventory'). Your inventory should be empty, and the object should be visible on/in the receptacle.
- If the object is there, the task is complete. Do not perform any further actions.
- If you ever find yourself holding the object after having placed it, that is a mistake — do not continue; stop and end the episode.
- **Termination rule**: Once placed at the target, stop all actions immediately. No more moving, heating, or searching.

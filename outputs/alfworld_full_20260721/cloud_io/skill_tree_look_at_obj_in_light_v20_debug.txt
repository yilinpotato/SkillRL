# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- Start by moving to a receptacle (e.g., desk, dresser, sidetable) to see its contents. Search surfaces at your current receptacle for a desklamp. If seen, that receptacle now holds the lamp.
- If not visible, move to another surface receptacle (from the initial room description) and check its contents. Continue until you find a desklamp.
- Once you are at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- If you encounter the target object before the lamp, remember its location and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Phase 2: Locate and take the target object (after lamp is on)

### Efficient Search (stop when found)
1. **Check the current receptacle first** – if the target object is on the same receptacle where you turned on the lamp, take it immediately (action: take <object> from <receptacle>).
2. **If not present, systematically visit other receptacles** – use the initial room description as a list of all furniture/receptacles (with numbers). For each receptacle (in any order, but do not skip any):
   - Go to it.
   - Read the arrival observation. If the target object's exact name appears among the items on the surface, take it (action: take <object> from <receptacle>) and stop searching — the task is done after taking.
   - If the target is not on the surface, check if this receptacle has any containers (e.g., a drawer built into a dresser, a cabinet). Open each container (action: open <container>) and inspect its contents. If found, take it and stop.
3. **Exhaustive fallback:** If after visiting all receptacles and opening all containers the target is still missing, re-read the initial description to verify you did not overlook any receptacle or container. Go back and open any containers you missed. Persist.
4. **No unnecessary actions** – do not use 'look' or 'inventory' except as needed to open containers; arrival observations give sufficient information.

### Action Precondition Check
- **Only take an object that is explicitly listed in the current observation.** Never guess or assume an object's location. If the observation does not show the target, do not attempt to take it from that receptacle — continue searching.
- If you try to take an object not present, you will waste an action and potentially break the task. Always verify before acting.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required. (Optionally use examine, but not necessary.)

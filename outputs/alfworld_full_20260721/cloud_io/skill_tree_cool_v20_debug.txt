# Goal: Cool an object and move it to a specified target location.

## Sub-goal 1: Find the object to cool.

### Initial assessment
- **Re-read the room description** from the prompt now. It lists every receptacle by type and number. This list is your definitive guide for where to search. Do not rely on `look` after moving — `look` from a specific spot shows only a localized view, not the full list.
- If the prompt already provided the room description, do not move until you have mentally noted all surfaces and closed receptacles.

### Strict search sequence — follow exactly, do not skip
- The order is: countertops, diningtables, sidetables, shelves, sinkbasin, stoveburners, then closed receptacles (fridge first, then cabinets, drawers, microwave).
- Within each category, check every numbered instance (1, 2, 3, …) in increasing order.
- Do not move to the next category until you have checked every instance of the current category.
- If you realize you have skipped a category, stop and go back to the earliest missed category.

### Systematic surface search (flat surfaces — mandatory, do not skip)
- Check every flat surface listed in the room description **before** opening any closed receptacle.
- **Strict order – follow exactly this sequence:**
  1. **All countertops** – check every numbered instance.
  2. **All diningtables** – check every numbered instance.
  3. **All sidetables** – check every numbered instance.
  4. **All shelves** – check every numbered instance.
  5. **Sinkbasin** – check the single instance.
  6. **Stoveburners** – check every numbered instance.
- For each numbered instance:
  1. Go to it using `go to <location>`.
  2. Read the observation. If the target object is present, take it immediately using `take <object> from <location>`.
  3. If not, move to the next instance in the same category, then to the next category.
- **Crucial: Keep a mental record of which instances you have already visited.** Do not revisit a location unless you have a specific reason (e.g., you need to use it later for cooling).

### Systematic container check (closed receptacles — only after flat surfaces exhausted)
- Search all closed receptacles in this order: fridge, cabinets, drawers, microwave.
- Start with the fridge (it may contain items that need cooling), but then continue to all other closed receptacles.
- **Critical: When you arrive at a closed receptacle, the observation will say it is closed. Your next action MUST be `open <receptacle>` to see inside. Do not move away or do anything else before opening.**
- For each closed receptacle (fridge, cabinets, drawers, microwave):
  1. Go to the instance (e.g., `go to cabinet 1`).
  2. If the observation says the receptacle is closed, **immediately open it** (`open <receptacle>`).
  3. Read the observation after opening. If the target object is present, take it (`take <object> from <receptacle>`).
  4. If not, move to the next instance of the same type (e.g., cabinet 2).
- **Important**: Only `open` reveals interior. Do **NOT** use `look` or `examine` on closed receptacles.
- After checking all instances of one type, proceed to the next type.

### If still not found
- Re-read the room description from the prompt to ensure you did not overlook any receptacle. Possibly you missed a flat surface or closed receptacle type.
- **Systematic re-check**: Go through the categories again in the strict order: countertops, diningtables, sidetables, shelves, sinkbasin, stoveburners, then all closed receptacles. This catches any skipped category.

## Sub-goal 2: Take the object.
- Once you see the target, take it immediately.

### Immediately cool after picking (mandatory)
- As soon as you have taken the object, go to the fridge and cool it before doing anything else. Do not move to the target location first.

## Sub-goal 3: Cool the object using the fridge.
- Ensure you are at the fridge.
- If the fridge is closed, open it.
- Use `cool <object> with fridge`.

## Sub-goal 4: Move the cooled object to the target location.
- Go to the target location (named in the task).
- Use `move <object> to <target>`.

## Completion check:
- The task is complete when the object has been cooled and placed at the target location.

# Goal: Examine or look at a target object using a light source (e.g., desklamp)

## Phase 1: Find and turn on the desklamp
- Search the surfaces you can see at your current location for a desklamp. If you see one, note its location and move there if necessary.
- If no desklamp is visible, move to another surface receptacle (e.g., desk, dresser, sidetable, shelf, bed, etc.) and check its contents. Continue moving among receptacles until you find a desklamp.
- Once you are at the same receptacle as the desklamp, use it (action: use desklamp <number>). The observation will confirm the lamp is on.
- Important: You may encounter the target object before finding the lamp. If that happens, remember where it is and continue searching for the lamp. Do **not** take the object until the lamp is on.

## Phase 2: Locate and take the target object (after lamp is on)

### Object name verification before picking
- When you read the observation at a receptacle, look carefully for the exact name of the target object (e.g., "box" not "tissuebox", "book" not "newspaper"). Do **not** take an object unless its name matches the task exactly. If you are unsure, re-read the task description. A mistake here means you will examine the wrong object and fail.

### Systematic Target Search
1. **Read the initial room description** you were given at the very start. It lists every furniture/receptacle present (e.g., bed, desk, dresser, sidetable, shelf, drawer, cabinet, garbagecan, armchair, coffeetable, sofa, tvstand, etc.). Write **each one** down mentally – ignore the numbers, they are just labels. This is your **complete set** of places to search. If you are unsure, re-read the initial description again now.
2. **Do not assume any receptacle is already searched** just because you visited it while hunting for the lamp. You must check each receptacle for the target object now, even if you have been there before. The only exception is if you already spotted the target earlier and remember its location – in that case, go directly to that receptacle and take it after the lamp is on.
3. **Start with the receptacle that holds the desklamp.** If you are not already at that receptacle, go to it. Inspect its surface and any containers on it (e.g., drawers, if part of that receptacle). If the target object is there, take it immediately.
4. **Then proceed to every other receptacle on your list, one by one. Do not skip any.** For each receptacle:
   - Go to it.
   - Read the observation that appears upon arrival – this tells you what is on its surface.
   - If the target object's exact name is among the items, take it (action: take <object> from <receptacle>).
   - If the target is not on the surface, check if this receptacle has any containers (e.g., a drawer built into a dresser). Open each container and inspect its contents.
5. **Continue until you have visited every receptacle on your list.** 
6. **Exhaustive fallback:** If you have visited every receptacle from the list and opened all containers, and the target is still missing, re-read the initial room description (if available) to check if you overlooked any receptacle or container (e.g., a safe, a cabinet, a drawer on a dresser that you did not open). Go back and open every container you haven't opened yet. Persist – do not stop until the target is found.
7. **Do not waste actions on 'look' or 'inventory'** – the arrival observation gives you all the information you need. Move efficiently from receptacle to receptacle.

## Phase 3: Task completion
- With the desklamp still on and the target object in your inventory, the task is complete. No further action is required.
  (If you wish, you may use the examine action on the object, but it is not necessary for success.)

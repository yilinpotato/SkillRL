# pick_and_place skill tree

## Goal
You must pick up a specific object and place it into or onto a specified receptacle. The task description states both the object and the target (e.g., "put a book in sofa").

## Sub-Goal Flow
### 1. Parse the task
Identify two entities: the **target object** (what to pick) and the **target receptacle** (where to place it). Keep these in mind throughout.

### 2. Locate the target object
- From the initial room observation, **list every receptacle name** (e.g., cabinets, drawers, shelves, tables, countertops, sofas, armchairs, ottomans, dressers, sidetables, desks, sinks, bathtubbasins, handtowelholders, towelholders, toilet, toiletpaperhanger, garbagecan, etc.). Do not assume only a few types; include all.
- For each type, **visit every instance** (e.g., drawer 1, drawer 2, …). Move systematically through the entire list – do not skip any instance or type.
- If a receptacle is closed (cabinet, drawer), **open it** before examining contents.
- Read the observation after opening or arriving: it will list objects inside or on the receptacle.
- If the target object is not in the current receptacle, continue to the next. **Do not stop** after checking only a subset of possible containers – you must cover all receptacles of all types.
- **Common oversight**: focusing only on cabinets and drawers while ignoring tables, countertops, sofas, handtowelholders, toilet, bathtubbasin, or other surfaces. The object may be in plain sight on any surface.

#### Systematic search procedure
- After listing all receptacles, mentally check them off one by one. Do not proceed to pick up any object until you have visited every receptacle on your list. If the target object appears early, you may pick it up, but if you do not find it within the first few receptacles, continue searching exhaustively.
- Pay special attention to receptacles you might overlook: sidetables, armchairs, tvstands, beds, dressers, and any other furniture appearing in the observation.

### 3. Verify and pick up
- Before picking up any object, **confirm that its name exactly matches the target object** (e.g., if task says "cloth", do not pick "handtowel"; if task says "spraybottle", do not pick "soapbottle"). If there is any mismatch, do not take it.
- Once confirmed, use `take <object> from <receptacle>` to pick it up.
- If you are already carrying something else and it is not the target, you may need to drop it (not typical in these tasks, but avoid carrying wrong items).

#### Name matching rule
- Compare the object's full name from the observation to the target task string. Synonyms are not acceptable; the exact name must match. For example, "handtowel" is not "cloth", "towel" is not "cloth", "soapbar" is not "soapbottle". When in doubt, re-read the task description and the observed object name.
- If you see an object with a similar name (e.g., "handtowel" vs "cloth"), do not pick it up – continue searching. Picking the wrong object will end the task in failure.

### 4. Navigate to the target receptacle
- After successfully picking up the target object, move to the target receptacle (e.g., "sofa 1", "toilet 1", "garbagecan 1").
- You can use `go to <receptacle>`.

### 5. Place the object
- When you arrive at the target receptacle, immediately execute `move <object> to <receptacle>`.
- Do **not** perform any other actions (like examining or going away) before placing; placing is the final required action.

### 6. Termination
- After the `move` action, the task is complete. No further actions are needed.

## Common Mistakes to Avoid
- **Wrong object pickup:** Always re-verify the object name in the observation before using `take`. Never take an object unless its name is an exact match.
- **Incomplete search:** Do not skip any receptacle type or instance; the target object may be on any surface, in any drawer, or inside any cabinet. Check all furniture listed in the initial room observation.
- **Missing the placement step:** Arriving at the target is not enough; you must explicitly `move` the object.

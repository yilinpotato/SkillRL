# Clean Task Skill Tree

## Goal Identification
- Parse the task: "clean some [object] and put it in/on [destination]" or "put a clean [object] in/on [destination]".
- The [object] must be cleaned before placing at [destination].
- [cleaning_source] is a sinkbasin or bathtubbasin (typically sinkbasin 1).

## Phase 1: Search and Acquire the Target Object
- **This phase ends only when you are holding exactly the target object.** Do not attempt to clean or place until then.
- If you are already holding something that is not the target, put it down immediately (e.g., `put [object] on/into [receptacle]`).

### Object Name Matching
- Compare the object name from the task with names in your observations. Only an exact string match counts.
- Do not pick up similar items (e.g., cloth vs towel, pan vs pot). If the name differs, keep searching.

### Open Surface Search (mandatory first step)
- From the initial room description, list all **open receptacles**: countertops, diningtables, sidetables, shelves, sinkbasins, bathtubbasins, stoveburners, toilets, garbage cans, carts, handtowel holders, towel holders, and any other receptacle that is not explicitly closed.
- **Go to each individual instance** listed (e.g., countertop 1, countertop 2, …). At each, `examine` or simply observe its contents. Do not skip any instance because you think it might be empty.
- After checking every open receptacle, if you still do not see the target object, proceed to closed containers.

### Closed Container Search
- Systematically check all closed containers in this order:
  1. All cabinets – go to each, open, inspect contents.
  2. All drawers – go to each, open, inspect.
  3. Fridge (if present) – go to it, open, inspect.
  4. Microwave (if present) – go to it, open, inspect.
- Do not return to open surfaces or other locations until every closed container has been examined.
- If the object still not found, re-read the initial description to ensure you did not miss any receptacle.

### Location Hints (use only after systematic search)
- Cookware often on stoveburners or countertops.
- Food items (lettuce, tomato, potato) may be on diningtables, countertops, or in the fridge.
- Utensils (ladle, knife, spoon) are commonly on countertops, diningtables, or in drawers.
- Cleaning items (soapbar, sponge) near sinkbasins or on shelves.
- Dishes/bowls in cabinets or on open surfaces.

## Phase 2: Clean the Object
- **Prerequisite: You must be holding the target object.** If you are empty-handed, return to Phase 1.
- Go to [cleaning_source] (sinkbasin or bathtubbasin).
- Use `clean [object] with [cleaning_source]`.
- Confirm the observation says you cleaned it.

## Phase 3: Place the Clean Object at Destination
- Go to the [destination] specified in the task.
- If the destination is a closed container (e.g., microwave, fridge, drawer, cabinet), open it first.
- Use `move [object] to [destination]` to place it.
- Confirm the observation shows the object is now at the destination.

## Completion
- The task ends as soon as you have placed the clean object. Stop all other actions.
- Do not continue searching or moving other objects.
